# 01. 사업 기획

## 1. 문제 정의

자영업자·중소기업·스타트업은 매달 같은 일을 반복한다.

- 거래처에 전자세금계산서 발급 → 이메일 전송 → 발급분 정리
- 지원사업·입찰·대출·계약 때마다 등본, 납세증명, 지방세 납세증명, 4대보험 완납증명, 건강보험 자격득실, 중소기업확인서를 **다시** 발급
- 매번 인증서 찾기, 보안 모듈 설치, 팝업 차단 해제, 출력 모듈 오류와 싸움

공개 공고문 36건(2026-01~10, 창업지원·소상공인·보증·입찰·민간 금융)을 직접 집계한 결과(07 문서, R9)는 다음과 같다.
- 공고 1건은 평균 **6.4종** 서류를 **3.6곳**에서 떼게 한다(입찰 7.4종·4.9곳).
- 요구 빈도는 사업자등록증명 97%, 법인등기 78%, 국세·지방세 납세증명 44%, 표준재무제표증명 42%다.
- 25/36건이 발급일 조건을 거는데 기준이 제각각이라, 같은 서류를 공고마다 다시 뗀다.
- 행정정보 공동이용으로 제출 생략이 명시된 공고는 6%다(마이데이터 포함 19%).

기존 해법의 한계:

| 해법 | 한계 |
|---|---|
| 전자세금계산서 ASP(팝빌·바로빌·볼타·스마트빌 등) | 건당 90~220원(볼타 90·팝빌 200·스마트빌 220), 최소 사용료는 업체별. **무료 선택지도 있다**(볼타 웹 무료 플랜, 클로브AI, 홈택스 직접 발급). 발급 데이터가 제3자 서버에 집적, 민원서류는 범위 밖 |
| 세무·경리 SaaS(자비스·캐시노트류) | 스크래핑 결과를 **그들 서버**에 보관. 세무사법 광고 규제(2026.6.24 시행)와 개인정보보호법 시행령의 스크래핑 사전협의(공공 2026.8.20)로 부담 증가 중. 국세청은 2024·2025 종소세 기간에 플랫폼 접속을 차단했다 |
| 세무사 사무실 | 신고 대행은 되지만 등본·확인서 같은 '본인만 뗄 수 있는' 서류는 결국 대표가 직접 |
| 일반 RPA | 비싸고, 사이트 개편 때마다 깨지며, 비개발자가 유지 불가 |

## 2. 고객 세그먼트와 우선순위

| 세그먼트 | 월 발급 빈도 | 고통 | 우선순위 |
|---|---|---|---|
| **B2B 거래 중심 소규모 법인/스타트업** (5~30인, 모수는 미확인: 5인 이상 사업체 약 81만이 상한 참조점) | 세금계산서 10~100건, 민원 월 2~5건 | 대표·경영지원 1인이 전담, 지원사업 서류 폭탄 | **1순위** |
| **프리랜서·개인사업자(용역·컨설팅·개발)** | 세금계산서 2~10건, 민원 월 1~2건 | 세무사 없이 직접, 홈택스 UX 공포 | 2순위 |
| 소상공인(요식·소매) | 세금계산서 적음, 민원 많음 | 대출·지원금 서류 | 3순위 (서류 데몬으로 확장) |

위 표는 사업자 유형 기준이다. 서류 묶음·반복 빈도·대체재는 **서류가 필요한 상황**에 따라 더 크게 갈리므로, 상황 축으로 다시 나눈다(07 §3, ADR-018).

| 상황 | 공고당 서류·발급처 | 핵심 서류 | 공동이용·마이데이터 대체(표본) | 우선순위 |
|---|---|---|---|---|
| 창업 지원사업 신청(업력 7년 이내) | 5.8종·3.4곳 | 사업자등록, 법인등기, 납세 2종, 재무·과세표준, 창업기업확인서, 사실증명 | 3/16 | 1순위 |
| 보증·정책자금 신청 | 6.6종·3.0곳 | 표준재무제표, 주주명부, 납세 2종, 사업자등록 | 0/5 | 1순위 |
| 공공 입찰·조달 | 7.4종·4.9곳 | 법인등기, 법인인감(종이), 납세 2종, 직접생산, 신용평가 | 1/7 | 2순위(확장) |
| 소상공인 지원 | 6.0종·3.5곳 | 사업자등록, 납세 2종, 소상공인확인서 | 3/6 | 3순위 |

**타깃은 한 고객군으로 좁히지 않는다(11-03 결정).** 중심은 세금계산서 자동화·관리이고, 스타트업, 중소기업, 자영업자(운송·물류 포함)를 모두 다룬다. 위 두 표의 우선순위는 효과가 먼저 나는 순서일 뿐 "하나만" 고른다는 뜻이 아니다.

두 축을 겹치면 **지원사업과 보증·정책자금을 함께 쓰는 업력 7년 이내 소규모 법인**이 가장 먼저 효과를 본다. 이 두 상황은 대체율이 낮고 핵심 서류가 홈택스 자동화 범위 안에 있다. 결제 의사가 명확하고, "본인 데이터 보유"라는 메시지에 민감하며, 법인 프로필(사업자용 인증서) 수요가 분명하다.

이번 범위는 PC가 있는 사장님이다(제안, 11-05). PC가 없는 사장님(예: 개인 화물차주)은 실제로 있지만 서버 측 브라우저 자동화 금지(02 §12) 때문에 지금 구조로는 받을 수 없다. 인증 ASP API를 거치는 "폰 엔진"을 2단계 후보로 둔다. 이 경우 발급 데이터가 ASP에 남고, 이 시장은 이미 앱(혼적콜 발행 건당 120원, 오초택스 발행·수금 대행 등)이 잡고 있다.

## 3. 가치 제안 (기준 시나리오 기준)

**"내 컴퓨터가 내 경영지원 직원이 된다. 단, 내 인증서와 서류는 내 손 안에."**

운영기관 허락 전(향후 12개월의 가장 그럴듯한 상태)과 허락 후의 가치를 나눠 적는다. 가격·재무는 **기준 시나리오**로 세운다.

| 가치 | 기준 시나리오(정부24 허락 전) | 허락 시나리오 |
|---|---|---|
| 홈택스 세금계산서 | 로그인(간편인증 폰 승인 또는 공동인증서 비밀번호 직접 입력) 후 대화 한 줄 → 확인 카드 → 발급·이메일까지 자동, 발급목록 조회로 확정. 하루 30건 요청률 상한 | 동일 |
| 홈택스 민원증명(사업자등록·납세·과세표준·표준재무제표·사실증명·휴폐업) | 대화 한 줄 → 확인 → 자동 발급·보관·만료 추적(사업자 제출서류 요구의 39%) | 동일 |
| 법인등기(인터넷등기소)·지방세 납세증명(위택스) | 인터넷등기소는 신청까지 자동, 등기 수수료 결제는 사용자(약관 확인과 상한을 올리는 앱 업데이트 전에는 후처리). 위택스는 약관(제17조 ②)상 사전 허락이 필요해 회신 전에는 자동화하지 않고, 지방세 납세증명은 정부24 후처리(G-02)로 받는다(ADR-022) | 위택스도 신청까지 자동(허락 회신과 앱 업데이트 뒤) |
| 민원서류(정부24·SMINFO·4대보험) | 발급 화면 안내 + 저장 파일 자동 분류 + 만료 추적·알림(**발급은 사용자가 직접**) | 자동 발급 |
| 공고문 → 서류 꾸러미(Phase 2) | 공고 조건에 맞춰 보관 서류 재사용 + 부족분 발급 | 동일 |
| 갱신 데몬 | 홈택스 서류는 승인형(폰 승인 두 번), 정부24 서류는 알림 | 정부24도 승인형 |
| 리모트(Phase 2) | 간편인증 프로필의 홈택스 작업 지시·승인·캡차, 보관함 조회 | 정부24 포함 |
| 주권 | 비밀값 로컬 전용, 서류 본문 E2EE, 서버 메타데이터 최소, 감사 로그 열람 | 동일 |

기준 시나리오에서 자동화로 시간이 줄어드는 것은 홈택스 작업이다. 세금계산서(H-01·H-02)와 민원증명 묶음(H-03·H-04·H-08~H-11)이 여기에 들어간다. 공고 표본 기준으로 정부24 전용 서류는 요구의 4%에 그친다. 정부24 민원서류의 가치는 '발급 시간'이 아니라 '정리·만료 추적·재제출 준비'다. 이 차이를 랜딩·온보딩에 그대로 적는다.

## 4. 경쟁 포지셔닝

```
                 데이터가 제3자 서버에 있음   ←→   데이터가 사용자 기기에 있음
업무 범위 좁음        [ASP 세금계산서]                 [수동 홈택스 이용]
업무 범위 넓음        [경리 SaaS / 세무플랫폼]          [★ 소버린 AX 하네스]
```

차별점 요약:
- ASP 대비: 건당 요금 없음, 민원서류까지 한 화면, 발급 데이터 미집적.
- 경리 SaaS 대비: 세무대리 경계 바깥에 서 있어 규제 리스크가 작고, 스크래핑 서버가 없어 보안 사고 표면적이 작다.
- RPA 대비: 플레이북을 우리가 유지보수하고 모델이 예외를 자가 복구한다.

## 5. 가격 (두 가설, 베타에서 비교)

**가설 A(현행 2플랜)** — VAT 포함 표시.

| | 스타터 | 비즈니스 |
|---|---|---|
| 월 요금 | 9,900원 | 29,000원 |
| 등록 프로필 | 1개(개인 **또는** 개인사업자) | 개인 1 + 법인(또는 개인사업자) 1 |
| 전자세금계산서 발급 | 월 30건 | 월 300건(일 30건 요청률 상한. 집행은 클라이언트 카운터 + 서버 모델 계량 대조, 우회 가능성은 잔여 위험) |
| 민원서류 | 보관·만료 추적 무제한(허락 전에는 발급 안내 + 자동 분류) | 동일 |
| 갱신 데몬 | 알림만 | 승인형 갱신(폰 승인) |
| 세무사 꾸러미(Phase 1 베타, 모델 비용 0) | ○ | ○ |
| 급여대장(Phase 1 베타, 모델 비용 0) | — | ○(제안) |
| 모바일 리모트(Phase 2) | ○ | ○ |
| 클라우드 E2EE 백업 | 2GB | 10GB |
| 모델 사용량 | 월 기본 한도 | 월 기본 한도, 초과 시 추가 팩 |

**가설 B(프리미엄형)** — 무료: 보관함·만료 추적(프로필 1, 발급 안내 포함) / 9,900원: 홈택스 자동화(월 100건)·세무사 꾸러미 / 29,000원: 법인 프로필·리모트·승인형 갱신·300건.

**11-05 제품 정의(ADR-031·032)**: (결정)이 붙지 않은 항목은 제안이며 확정 전이다.
- (결정) 세무사 꾸러미는 9,900원 스타터에도 넣는다. 모델 비용이 들지 않게 만들어 변동비를 늘리지 않는다(ADR-032 결정 11).
- 급여대장은 29,000원 비즈니스 플랜에 넣는다. 직원 수 구간 요금은 열어 둔다.
- 9,900원의 근거는 발급이 아니다. 한 달 할 일을 빠짐없이 챙기는 것, 세무사 꾸러미, 줄어든 시간이다. 실증에서 이 셋을 숫자로 잰다.

가격 근거(R5 리서치 반영):
- 세금계산서 발급만 보면 9,900원은 싸지 않다. 월 30건 기준 ASP는 0~11,000원(볼타 웹 무료 / 팝빌 6,000 / 스마트빌 11,000), 홈택스 직접 발급은 무료. 가격의 근거는 **대화 한 줄 발급 + 확인·조회 자동화, 만료 추적, 리모트, 주권**이다. 인터뷰에서 무료 ASP 사용자를 별도 집단으로 분리한다.
- 구독 사다리 비교: 머니핀 9,900, 캐시노트 9,900/16,500/33,000, 이지샵 15,400/24,200, 자비스 AI경리 33,000(VAT 별도). 9,900/29,000은 범위 안.
- 비즈니스 29,000원은 2026 최저임금(10,320원) 기준 약 2.8시간분. '월 3시간 미만 절감이면 손익분기'로 말한다.
- 스타터 '개인 1' 프로필은 세금계산서를 발급할 수 없으므로 스타터 프로필 정의를 '개인 또는 개인사업자 1개'로 고친다.

## 6. 유닛이코노믹스 (사용자 1명/월, 가설)

모델 단가(2026-10): GPT-6.1 Terra 입력 $1/출력 $5/캐시 입력 $0.05 per 1M 토큰. Decisions API는 정식 출시되었고 입력 $0.10 per 1M 토큰, 출력 무료(공식 가이드 기준, 캐시 적중 시 입력 할인).

| 항목 | 가정 | 월 비용(USD) |
|---|---|---|
| 플레이북 실행 (토큰 0) | 발급 25회 | 0 |
| 화면 판정·의도 라우팅 (Decisions API) | 약 350회 질문 묶음, 평균 3.5k 입력(고정 접두 2k + 화면 1.5k), 출력 무료 | ≈ 0.12 |
| 대화형 지시·요약 (Terra, effort low) | 40회 × 6k 입력/0.8k 출력(추론 포함) | ≈ 0.40 |
| 예외 복구 (Terra, effort medium, 마스킹된 접근성 트리 포함) | 3회 × 2턴 × 20k 입력/3k 출력 | ≈ 0.21 |
| 프롬프트 캐시 효과 | 보수적으로 0 (캐시 쓰기가 비캐시보다 비싸므로 명시 모드 적중 시에만 절감) | 0 |
| **모델 합계** | | **≈ 0.73 USD ≈ 1,050원** |
| 클라우드 저장·릴레이·인프라 | 10GB 상한, 트래픽 소량 | ≈ 300~500원 |
| 결제 수수료 | 3.5% | 350~1,000원 |
| **변동비 합계** | | **≈ 1,700~2,550원** |

스타터 9,900원 기준 매출총이익률 74~83%, 비즈니스 29,000원 기준 90% 이상. 핵심 레버는 **Terra 개입률**(플레이북과 Decisions 판정만으로 끝나는 비율)이다. 목표: 실행 100건당 Terra 호출 15건 이하.

모델 선택 원칙:
- 선택지가 정해진 판단(이 화면이 무엇인가, 성공했는가, 어느 플레이북인가)은 전부 Decisions API. 출력이 선택지 밖으로 나갈 수 없어 플레이북의 결정성을 지키고, 공급사 주장 기준 생성형 호출보다 약 10배 빠르다.
- 열린 문제(셀렉터 복구, 자연어 요약)만 Terra. effort는 low 기본, 복구만 medium.
- 공급사 간 다단 캐스케이드는 만들지 않는다. 캐시가 쪼개지고 운영 복잡도만 오른다. Decisions는 출력이 무과금이라 질문을 많이 묶어도 비용이 입력 토큰에만 비례한다.

## 7. GTM (시장 진입)

**메시지**: "본인의 데이터는 본인이 갖고 있어야 한다." 기술 설명이 아니라 **감사 로그 화면**과 **"우리 서버에는 이것밖에 없습니다" 페이지**로 증명한다.

채널 (순서대로):
1. **스타트업 생태계**: 액셀러레이터·공유오피스 입주사 단체 라이선스(10석 단위 할인). 지원사업 서류 시즌(1~3월, 6~8월)에 맞춰 "서류 데몬" 캠페인.
2. **개발자·프리랜서 커뮤니티**: 로컬 우선·오픈 프로토콜을 기술 블로그로 공개. 플레이북 포맷 일부 공개로 신뢰 확보.
3. **자영업 커뮤니티(카페·유튜브)**: "홈택스 20초 발급" 짧은 영상.
4. **세무사 사무실과의 비경쟁 제휴**: 사장님이 세무사에게 서류와 자료를 넘길 때 쓰는 도구로 포지셔닝. 세무사의 일을 뺏지 않는다는 점을 명확히. **tex는 사장님 편 도구이고 파트너 세무법인과는 별개다(11-05 결정, ADR-032).** 세무사는 판단하고 신고하며, tex는 사장님 PC에서 발급하고 모으고 정리해서 세무사 꾸러미로 넘긴다. 파트너 세무법인의 역할은 실증 고객 연결, 세무사 꾸러미 엑셀 양식 자문, LOI다. 제휴 사실 표시는 세무사법 광고규정의 표시 규정을 따르고, 허위 제휴 표시는 금지 표현 목록에 포함.
5. **정부 지원사업**: 자금원(초기창업패키지 최대 1억 원, 2026 접수 마감 → 2027 공고 대기; TIPS는 운영사 투자 선행)과 판로(바우처 공급기업 등록)를 구분한다. 데이터바우처는 데이터 상품 요건이라 부적합 추정, 비대면 서비스 바우처는 2026 공고 미확인, 클라우드·AX 바우처는 공급기업 요건 확인 필요.

전환 퍼널 KPI: 설치 → 프로필 등록 → 첫 발급 성공(활성화) → 2주 내 5회 이상 사용 → 유료 전환.

## 8. 법적·규제 경계 (제품 설계 규칙으로 번역)

| 리스크 | 설계 규칙 |
|---|---|
| **세무사법 (세무대리 금지, 2025.12.23 개정·광고규정 2026.6.24 시행)** — 신고·신청 대리, 장부 작성 대행, 세무 상담, **오인 우려 광고** | 신고세액 계산·절세·공제 판단·신고 대리 없음(세금계산서의 부가세 10% 분리는 홈택스 '계산' 버튼과 같은 산술로만 제공하고 과세유형은 사용자가 고른다. 급여의 원천징수액과 4대보험 근로자 부담분은 공식 표를 적용하는 계산 보조로 제공한다, ADR-031). 간편장부·장부 작성 대행 없음. 세무 질문에는 일반 정보만, 개인화 조언은 거절하고 세무사 상담 안내. 모든 발급·전송은 사용자 승인 후 사용자 명의로 사용자 기기에서 실행. **금지 표현 목록**: 세금환급·세금신고 대행·절세전문·기장대행·급여 대행, 세무사/세무법인/세무대리 유사 표현, 세무사 제휴 허위 표시, 환급 보장·성공률. 랜딩·영상 제목에서 '환급·신고 대행·절세·세무'를 제거. 위반 시 1년 이하 징역·1천만 원 이하 벌금. 2026.10 비즈넵 형사고발 등 서버형 플랫폼 제재가 계속되고 있다 |
| **전자세금계산서 발급 시스템 사업자 지위** | 우리 서버는 홈택스에 접속하지 않는다. 사용자가 홈택스 화면을 본인 기기에서 조작하는 것을 돕는다. 발급 시스템 등록 대상 아님(법률 검토로 확정). |
| **개인정보보호법** | 서버가 받거나 거쳐 가는 항목은 D09 §1.1이 정본이다: 계정 이메일, 결제 참조(PG 위탁), 계량, 서류 메타데이터(서버 색인을 켠 종류·발급 월·만료일, Phase 2), 발급 활동 표시(업무 키 HMAC·상태·일, Phase 2에서 PC를 두 대 이상 연결하고 백업을 켠 계정만, ADR-024), 진위확인 때 프록시를 거쳐 가는 거래처 사업자번호, 모델 공급사(국외)로 가는 마스킹된 화면 텍스트·대화 지시·서류 날짜 후보 주변 텍스트. 서류 본문·주민번호는 서버에 평문으로 두지 않는다(E2EE 블롭은 저장되나 복호화 불가). 처리방침이 짧아지는 것 자체가 마케팅 자산. |
| **전자서명법 / 인증서 이용약관** | 인증서는 사용자 기기 원위치에 두고 사용자 비밀번호로 사용자 세션에서만 서명. 공동·금융인증서 비밀번호는 **저장하지 않고 자동 입력하지 않는다**(사용자가 브라우저 창에 직접 입력, ADR-020 결정 2). 보안카드를 고른 사용자의 번호와 홈택스 아이디·비밀번호는 PC 안에서만 암호화해 보관한다(ADR-020 결정 3, 허용 여부는 법률 질의 Q6). |
| **정부24 이용약관(2026.3.9 시행) 제14조 ④ 9호·10호** | 9호는 **사전 허락 없는 자동화 수단(매크로·스크래핑) 로그인 자체를 금지**하고 10호는 IP 변경 접속·캡차 외부 우회를 금지한다. 매크로 제재는 1회 1개월·2회 3개월·3회 영구 정지(2024.10.15 공지). 따라서 정부24는 **요청률 상한 설계가 아니라 사전 허락(공문 회신)이 선행 조건**이다. 회신 전 정부24 플레이북은 **후처리 모드**(로그인·클릭은 사용자, 하네스는 저장·메타데이터·만료 추적)로 시작한다(05 문서 §7). 홈택스는 열람한 이용 규정에 자동화 금지 명문이 없으나 국세청이 전자정부법 근거로 IP별 대량 접속을 차단하고 2025.5부터 안티 스크래핑을 운영하므로, 요청률 상한·차단 신호 즉시 중단 + 공문으로 간다 |
| **개인정보보호법 시행령(2026.2.19 개정, 공공 2026.8.20 시행) 본인전송요구권·대리인 스크래핑 사전협의** | 대리인이 자동화 도구로 공공 시스템에서 정보를 가져오려면 공공기관과 사전협의가 필요하고, 대리인은 전송만 하며 자체 서버에 저장·분석할 수 없다. 우리는 인증정보를 서버로 보내지 않고 사용자가 자기 기기에서 실행하므로 '대리인' 비해당 가능성이 있으나 **공개 해석이 없다**. 개인정보위(온마이데이터·국민신문고)에 해당성 질의 → 해당 시 사전협의 신청, 비해당 시 서면 회신 확보. 신용정보법의 스크래핑 금지는 마이데이터 사업자·금융 접근매체 한정이라 직접 적용 가능성이 낮다(금융 데이터는 범위 밖) |
| **정보통신망법** | 접근 권한 있는 본인의 조작. 과도한 트래픽 유발 방지 설계. |

## 9. 재무 가설 (12개월, 기준 시나리오)

기준 시나리오 = 정부24 허락 없음(후처리), 홈택스 자동화, 승인형 갱신. 정부24 허락은 상방 옵션으로 둔다.

| 월 | 유료 사용자 | ARPU(원) | MRR(원) | 비고 |
|---|---|---|---|---|
| M4 (베타) | 50 | — | 0 | 무료 베타, 축소 설명 기준 지불의사 인터뷰 20건 |
| M6 (정식) | 200 | 14,000 | 280만 | 비즈니스 비중 20% 가정(전체 기능 가정 300명에서 하향) |
| M9 | 700 | 14,500 | 1,015만 | 단체 라이선스 시작, 리모트 출시 |
| M12 | 1,800 | 15,000 | 2,700만 | 손익분기 미달(5인 기준 약 2,800명 필요) |

민감도: 비즈니스 비중 30%·ARPU 16,000원이면 M12 MRR 2,880만, 정부24 허락 시 전환율 +30% 가정으로 M12 2,500명·3,800만(이전 가설). 초기 비용은 5인 팀 월 4,000~5,000만 원 + 법률 자문 + 인프라 소액, 12개월 소요 약 6~7억 원. 시드 투자가 주 자금원이고 초기창업패키지·TIPS는 2027년 공고 대기.

## 10. 왜 지금인가

- 홈택스 무료 사업자용 간편인증이 2026.4.14 적용됐다(IBK·KB·카카오뱅크, 앱 푸시/QR, 유효 3년). 폰 승인 기반 발급이 가능해져 리모트 시나리오의 기술 장벽이 내려갔다. 세금계산서 발급까지 가능한지는 정부 보도에 명시가 없어 S2에서 확인한다.
- 서버 집적형 세무 플랫폼이 광고 규제·스크래핑 사전협의·국세청 차단의 부담을 받는 반면, 로컬 우선 모델은 그 부담이 작을 **가능성**이 있다. 다만 정부24 약관은 행위 기준이고 '대리인' 범위는 미정이라 '규제 바깥'이라고 단정하지 않는다.
- OpenAI Decisions API(2026-10 정식)와 GPT-6.1 Terra(2026-10-26, 입력 $1/출력 $5)로 사용자당 월 모델비가 1,000원 아래로 내려왔다. 구독 번들의 마진이 처음으로 넉넉해졌다.
- '데이터 주권'이 중소기업에도 체감 이슈가 되었다(유출 사고 반복).
- 국세청은 오픈API(조회용, 2027 완료 목표)를 추진 중이다. 조회·수집은 공식 경로로 옮겨갈 수 있고 발급은 여전히 화면 조작이 필요하다. 오픈API가 열리면 H-02·H-07(조회)은 API로 전환하는 선택지를 설계에 둔다.
