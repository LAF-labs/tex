## 한 줄 정의

자영업자·중소기업·스타트업이 **본인 컴퓨터에서, 본인 인증수단으로** 홈택스(전자세금계산서)와 정부24(민원서류) 업무를 처리하도록 돕는 **로컬 에이전트 하네스**. 비밀값(인증서 개인키·비밀번호·보안카드)은 기기 밖으로 나가지 않고, 발급된 서류는 로컬 보관 + 종단간 암호화 클라우드 백업, 모델은 월 구독으로 제공한다.

## 설계를 지배하는 6가지 원칙

1. **플레이북 우선, 모델은 예외 처리용.** 반복 작업은 결정적(deterministic) 플레이북이 토큰 0으로 수행한다. 선택지가 정해진 판단(화면 상태·성공 여부·의도 분류)은 OpenAI Decisions API, 열린 문제(복구·요약)만 GPT-6.1 Terra. 이것이 가장 싸고 가장 빠르다.
2. **비밀값은 기기 밖으로 절대 나가지 않는다.** 개인키·비밀번호·보안카드는 OS 키체인과 금고 프로세스에만 존재한다. 우리 서버, 모델 공급사 모두 볼 수 없고, 정상 경로에서는 엔진 프로세스에도 닿지 않는다(금고 중계 허용 목록·비밀 창). 같은 PC의 악성코드와 관리자에 대해서는 경계가 아니라고 고지한다.
3. **업무 데이터는 최소 노출.** 모델로 나가는 모든 내용은 로컬 마스킹 계층을 통과한다. 게이트웨이는 본문을 저장하지 않고 계량 레코드만 남긴다(결제 레코드는 월 단위, 호출 단위 계정 연결 레코드는 35일, 운영 통계는 계정 비연결로 13개월).
4. **최종 실행 버튼은 항상 사용자.** 발급·전송·서명은 사용자 승인(로컬 또는 폰) 뒤에만 일어난다. 이것이 세무대리가 아닌 '도구'임을 지키는 선이다.
5. **꺼져 있어도 답할 수 있어야 한다.** 서류 메타데이터(종류는 옵트인·발급 월·만료일)는 클라우드에서 조회 가능하게 하고, 본문은 사용자 키로만 열린다. 조회 질문만 모델에 가고 메타데이터 행은 서버가 조회한다.
6. **허용은 받고, 탐지 신호는 만들지 않고, 위조·은폐는 하지 않는다.** 정부24 약관은 사전 허락 없는 자동화 로그인을 금지하므로 허락 회신 전 정부24는 후처리 모드(사용자가 조작, 하네스는 보관·만료 추적)로 출시한다. Playwright 구동 Chrome의 `navigator.webdriver=true` 표식은 그대로 둔다. 사용자 본인 IP·본인이 설치한 실제 Chrome·본인 인증수단·요청률 상한과 고정 간격 입력으로만 동작하고, 운영기관에 자동화 접근 허용 공문을 보낸다. 캡차·추가 인증은 10초 안에 사용자(데스크톱 또는 폰)에게 넘겨 사람이 풀고 작업은 이어진다. 자동 해독·지문 위조·흔적 삭제는 만들지 않는다.

## 확인된 외부 사실 (2026-10 기준, 설계에 반영)

- 홈택스는 2026.4.14부터 **무료 사업자용 간편인증**(카카오뱅크·IBK·KB국민, PC에서 PUSH/QR/클라우드)으로 전자세금계산서 건별·수정·반복·복사 발급이 가능하다(매뉴얼 명시, 일괄발급·민원증명은 미확인). 정부24 간편인증은 주민번호 기반만 되어 법인은 공동·금융인증서 또는 법인 아이디가 필요하다. 공동인증서는 사업자범용·전자세금계산서용·ASP용 중 하나여야 하며, '브라우저 인증서' 모드(signCert.der+signPri.key를 브라우저에 저장, 가상키패드 필수)로 설치 없이 동작한다. 서명 모듈은 드림시큐리티 MagicLine. 보안카드는 홈택스 온라인 신청 후 지정 세무서 수령, 홈택스·손택스·ARS에서만 사용.
- 정부24 서류 저장은 공식 안내가 상충한다(2021-09 공지·등본 FAQ는 가상 프린터·파일 저장 불가, 2023-12 공지는 Microsoft Print to PDF 안내). 출력 모듈은 ezCertForClient·ezPDFReader·AnySign4PC, 발급불가 프린터 34종. **서류별 실측(S3)이 필수**이며, 허락 회신 전 후처리 모드에서는 사용자가 출력하고 하네스가 저장 파일을 감지한다. 전자문서지갑은 모바일 앱 중심.
- 중소기업확인서는 중소기업현황정보시스템(SMINFO)에서 **사용자 본인이 자료제출 → 신청서(유형 1~7) 작성·제출**한다(로그인은 ID/PW 통합회원, 자료제출 프로그램이 필요한 유형 있음). '2026년 직접 신청 방식 변경'은 공식 근거가 없는 2차 자료 주장이라 삭제. 유효기간은 공식 2026.04.01~2027.03.31(직전 사업연도 말일 + 3개월부터 1년 규칙과 일치). 세무대리인이 대신 받기 어려운 서류라 '본인 기기에서 직접' 모델의 강점이 드러나는 사례.
- 세무사법 개정 이후 한국세무사회가 세무 플랫폼 전반에 시정 계고를 보낸 상태. **"세무대리 흉내"로 보이는 기능·문구를 처음부터 배제**해야 한다.
- 홈택스·정부24 이용약관의 자동화 접근 조항, 공동인증서 자동 서명의 법적 위치는 공개 검색으로 확정되지 않았다. **법률 검토 + 운영기관 공문**으로 확정한다(04 문서 R-1, 05 문서).
- **정부24 이용약관(2026.3.9 시행) 제14조 ④ 9호**는 사전 허락 없는 자동화 수단(매크로·스크래핑) 로그인을 금지하고 10호는 IP 변경·캡차 외부 우회를 금지한다. 매크로 제재 1회 1개월·2회 3개월·3회 영구(2024.10.15 공지). 홈택스 이용 규정(열람본)에는 자동화 금지 명문이 없으나 국세청은 2024·2025 종소세 기간에 세무 플랫폼 접속을 차단했고 2025.5부터 안티 스크래핑을 운영한다. 국세청 오픈API(조회용)는 2027 완료 목표.
- **개인정보보호법 시행령**(2026.2.19 개정, 공공 2026.8.20 시행)은 대리인의 자동화 수집에 공공기관 사전협의를 요구한다. 우리가 '대리인'인지는 공개 해석이 없어 개인정보위 질의가 필요하다. 신용정보법의 스크래핑 금지는 마이데이터 사업자·금융 접근매체 한정.
- **세무사법** 개정(2025.12.23 공포, 광고규정 2026.6.24 시행)으로 오인 우려 광고까지 금지된다. 2026.10 비즈넵 형사고발 등 서버형 플랫폼 제재가 이어진다.
- **시장·가격**: 가동사업자 1,032만(2025.12), 법인 130~136만. 전자세금계산서 발급만 보면 무료 대체재(볼타 웹 무료, 클로브AI, 홈택스 직접)가 있어 9,900원의 근거는 민원서류·만료 추적·리모트·주권이다. 한국 데스크톱 OS는 Windows 88.4%(StatCounter 2026-09).
- 국세청 사업자등록정보 진위확인 API(공공데이터포털)는 **서비스 키가 필요**하다(키 없이 401). 한도 표기는 1회 100건·일 100만 건(포털) vs 일 1만 건(서드파티)으로 불일치. 기본은 게이트웨이 프록시, 설정에서 자기 키.
- 홈택스 운영 도메인은 난독화된 클라이언트 보안 스크립트(에버스핀 추정)와 NetFunnel 대기열을 쓴다. 정부24+에는 캡차 페이지 라우트가 있다. 개편은 홈택스 2025.1 전면, 정부24 2025.7(정부24+)·2026.12(AI정부24)로, 분기 1회 이상 플레이북 파손을 가정한다.
- **플랫폼 사실(R3 실험)**: Playwright가 파이프로 구동한 설치 Chrome은 `navigator.webdriver=true`가 그대로다. 헤드풀 `page.pdf()`와 `--kiosk-printing`+Save as PDF는 Chrome 156에서 동작한다. 키보드 보안 모듈은 커널 드라이버라 합성 키 입력이 닿지 않을 수 있어 해당 칸은 사용자 직접 입력이다. 비밀 저장은 `@napi-rs/keyring`(Credential Manager 항목당 2,560바이트), 같은 OS 사용자의 악성코드에는 프로세스 분리가 경계가 되지 않는다.
- OpenAI **Decisions API**(`POST /v1/decisions`, 모델 `gpt-6-luna`)는 정해진 선택지에서 답을 고르는 전용 엔드포인트로, `predicate`·`choice`·`score` 질문 타입과 확률·신뢰도를 반환하며 `refusal` 응답 타입이 있다. **정식 출시**. 입력 $0.10 per 1M 토큰, 출력 무료, 요청당 질문 1~400개, 공유 입력 끝에 암묵 캐시 브레이크포인트(1,024토큰 이상). 이미지는 base64 또는 공개 URL, `file_id` 미지원. 캐시 쓰기($0.125/1M)는 비캐시 입력보다 비싸므로 명시 캐시 모드로 고정 접두에만 건다. ZDR은 적격이나 영업 승인 필요. 한국 리전은 저장만, 처리는 미국·EU.
- OpenAI **GPT-6.1 Terra**(`gpt-6.1-terra`)는 2026-10-26 출시, 입력 $1/출력 $5/캐시 입력 $0.05 per 1M 토큰, 1M 컨텍스트, Responses API 도구 호출, 컴퓨터 사용 도구 선택 가능(우리는 미노출), effort `none/low/medium(기본)/high/xhigh/max`. 공급사는 프롬프트 인젝션 저항과 범위 준수 개선을 주장한다.

## 기획 v1.0에서 내린 결정 (상세: 06 문서 6절)

- Decisions API는 정식 출시(입력 $0.10/1M, 출력 무료)로 확정, 사용자당 월 $0.10 캡.
- 공문은 Phase 0 1주차에 국세청·행정안전부로 발송한다.
- 정부24 PDF 저장 불가 서류는 '출력 전용'으로 표시해 출시한다.
- 데몬의 무인 자동 모드는 보류한다(홈택스 로그인이 사람 없이 끝나지 않음). Phase 2는 알림·반자동(폰 승인)만.
- 가격은 9,900 / 29,000원을 유지하고 베타에서 대안을 A/B 한다.
- macOS는 MVP에서 제외하고 Phase 3에 넣는다.
- Decisions confidence 임계값은 0.85, 비가역 직전은 0.95로 시작한다.
- 정부24 플레이북은 사전 허락 회신 전 후처리 모드(사용자 기본 브라우저, 하네스는 보관·만료 추적)로 출시하고, 운영 수준(postprocess/assisted/auto)은 서명된 운영 정책으로 포털별 전환한다. 스파이크에서도 정부24는 자동화하지 않는다.
- 가격·재무는 기준 시나리오(정부24 허락 없음)로 세우고, 정부24 허락은 상방 옵션이다. 스타터 프로필은 '개인 또는 개인사업자 1개', 발급 상한은 일 30건·월 300건(집행: 클라이언트 카운터와 정책 `limits`, 서버 모델 계량 대조. 변조 클라이언트의 우회 가능성은 잔여 위험, D11 §8).
- 금고가 Chrome 파이프를 소유하고 엔진은 중계 CDP만 쓴다. 비밀 보호는 위생 장치이며 같은 PC 악성코드에 대한 경계가 아님을 고지한다.
- 테스트 발급은 '0원·취소 가능'이 아니라 관계사 간 실거래 소액 2~3건 + 게이트 직전 드라이런. 적법성은 법률 질의로 확인.
- `navigator.webdriver` 표식은 그대로 둔다. 일반 입력은 `fill()`, 키 이벤트는 보안 모듈·비밀 입력에만.
- 개인정보위에 '대리인' 해당성을 질의하고, 마케팅 문구는 세무사법 광고규정 금지 표현을 제거한다.

## 설계 v1.3에서 내린 결정 (공격표면 감사, 상세: design/19)

- 핫픽스는 비커밋 항목의 셀렉터 후보만 바꿀 수 있고, 클릭·입력마다 실제 접근성 이름을 사전과 대조한다(ADR-012). 정부24 자동화·캡차 중계는 서명된 운영 정책으로도 켤 수 없다(앱 내장 상한).
- 금고 중계는 기본 거부 허용 목록이며 요청 바디·접근성 값·스크린샷에서 비밀을 정리하고, 비밀이 입력되는 모든 구간은 비밀 창으로 보호한다(ADR-005 v3). docparse는 Chromium 렌더러 샌드박스, 로컬 비가역 승인은 main 승인 창(ADR-014).
- 플레이북·정책은 2-of-3 임계 서명 + 투명성 로그(Phase 2) + 키 세대·폐기 채널로 배포하고, 서명 키는 클라우드 KMS가 아니라 국내 자체 HSM에 둔다(ADR-013).
- 계정 신뢰 앵커는 복구 문구에서 나오는 AIK다. 기기 목록은 AIK 서명, 즉시 삭제·백업 접근은 AIK 인증 기기만, 원격 비가역 승인은 하드웨어 키(P-256)만, 디바이스 플로우·매직링크는 폐기(ADR-016).
- 서버 메타데이터는 종류(옵트인)·발급 월·만료일만 남기고 크기·초 단위 시각·중복 토큰을 지운다. 조회 에이전트는 질문만 모델에 보낸다(ADR-006 개정).
- 소버린 전환: 모델은 OpenAI를 유지하되 `decide()`를 System One 계약까지 일반화하고 Upstage `solar-decide`를 S7에서 병행 평가한다. "국내 처리" 옵션은 5조건(한국 리전 GA·정확도·무보존 계약·L2 호출 100% 국내 리전과 처리 위치·호스팅 법인 서면 확인·국내 법인 운영 인프라) 충족 시. 인프라는 공급사 중립 설계 + 조달·계약 트리거. 로컬 판정 모델은 규칙 L0 확대 뒤 Phase 3 재검토. "완전 소버린" 표기는 하지 않고 남는 외국 의존(APNs/FCM·App Attest·Play Integrity·Microsoft·앱 스토어·코드서명·npm/GitHub·레지스트리 CDN·전용 Chrome의 Google 서비스 등, 정본 목록은 ADR-015 결정 6)을 공개한다(ADR-015).

## 서류 카탈로그 v0.1에서 내린 결정 (2026-10-30, 상세: 07 문서·ADR-018)

- 모두의창업 1라운드 심사의견(시장 세분화, 세그먼트별 필요성·차별화)에 답하려고 공개 공고문 36건의 제출서류를 직접 집계했다(R9). 공고당 6.4종·3.6곳, 사업자등록증명 97%, 법인등기 78%, 납세증명 44%. 공동이용 생략 명시는 6%다.
- 세분화 축은 '서류가 필요한 상황'이다. 첫 타깃은 지원사업과 보증·정책자금을 함께 쓰는 업력 7년 이내 소규모 법인이다.
- 요구 서류의 39%는 홈택스 민원증명이고 정부24 전용은 4%다. 그래서 Phase 1 코어를 홈택스 자동 6종(H-01·H-03·H-04·H-05·H-08·H-09)으로 바꾸고, 정부24 후처리는 출시 조건에서 뺀다.
- 법인등기 S-03(결제는 사용자)과 위택스 지방세 W-01은 Phase 1 베타로 넣는다. 둘 다 약관 확인 후 `auto`로 켠다. 공고문 → 서류 꾸러미(K-01)는 Phase 2다.
- 법인인감(종이)·신용평가(민간 유료)·주주명부 작성은 범위 밖이며 보관·만료 추적만 한다.
