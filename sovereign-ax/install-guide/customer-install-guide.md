# 소버린 AX 설치·첫 사용 안내 (PoC 고객용)

> 이 문서는 PoC에 참여해 주시는 사장님께 드리는 안내입니다. 설치부터 첫 세금계산서 발급까지 순서대로 적었습니다.
> 막히는 곳이 있으면 억지로 넘기지 마시고 [7. 막혔을 때 보내 주세요](#7-막혔을-때-보내-주세요)대로 보내 주세요. 그게 저희에게 가장 큰 도움입니다.
> 화면 문구는 2026-11-11 판(0.1.8 이후) 기준입니다. 판이 바뀌면 일부 문구가 다를 수 있습니다.

## 0. 시작 전에 확인해 주세요

| 확인할 것 | 필요한 것 |
|---|---|
| Windows PC | **Windows 10(22H2) 또는 Windows 11, 64비트** |
| Mac | **macOS 13(Ventura) 이상**. Apple 칩(M1~M4)과 Intel Mac 모두 됩니다(한 파일에 둘 다 들어 있습니다) |
| **Google Chrome 먼저 설치** | 앱이 홈택스 일을 할 때 Chrome을 따로 하나 띄워서 씁니다. Chrome이 없으면 발급을 시작할 수 없습니다. https://www.google.com/chrome 에서 설치해 주세요. Mac은 **응용 프로그램** 폴더(또는 내 홈의 응용 프로그램 폴더)에 있어야 합니다 |
| 인터넷 | 처음 켤 때와 로그인할 때 인터넷이 필요합니다. **회사 보안망(프록시)을 쓰는 PC에서는 동작하지 않을 수 있어요.** 회사 전산 담당자께 `tax.laf-co.com`, `rooms.tax.laf-co.com`(443 포트) 허용을 부탁해 주시고, 미리 저희에게도 알려 주세요 |
| 이메일 | 로그인할 때 이 주소로 6자리 코드가 옵니다. **PoC 담당자에게 미리 알려 주신 이메일**을 써 주세요 |
| 홈택스 인증 | **이 PC에 저장된 공동인증서**, 또는 **사업자 간편인증(카카오뱅크·IBK·KB 앱)** |
| 공동인증서 종류 | 세금계산서 발급에는 **사업자범용** 또는 **전자세금계산서용** 공동인증서만 쓸 수 있습니다. **개인용·은행(금융기관)용 인증서로는 발급되지 않습니다** |
| 홈택스 보안 프로그램 | 공동인증서를 쓰시려면 이 PC에 **홈택스 통합설치 프로그램(인증서 모듈)**이 깔려 있어야 합니다. 평소 쓰시는 Chrome에서 홈택스에 공동인증서로 로그인이 되면 이미 깔려 있는 것입니다. 안 되면 홈택스 첫 화면의 안내대로 설치해 주세요 |

인증 관련해서 지금 판에서 안 되는 것:
- **USB에만 있는 공동인증서**와 **금융인증서**는 아직 목록에 나오지 않습니다. 홈택스에서 인증서를 PC로 복사해 두시거나 간편인증을 써 주세요. 앱이 찾는 위치: Windows `C:\Users\<사용자>\AppData\LocalLow\NPKI`, Mac `라이브러리/Preferences/NPKI`.
- **보안카드**는 지원하지 않습니다.

설치 파일을 받으실 때 담당자가 **SHA-256 값**(64자리 영문·숫자)을 함께 드립니다. 받은 파일이 저희가 만든 그 파일인지 확인하는 값입니다([6](#6-받은-파일이-맞는지-확인하기-sha-256)).

## 1. Windows에 설치하기

### 1-1. 내려받기
담당자가 드린 링크에서 `SovereignAX-Setup-<판>.exe`(약 120MB)를 받습니다.
- 브라우저가 "일반적으로 다운로드되는 파일이 아닙니다"처럼 경고하면 [유지] 또는 [계속]을 누릅니다(Edge는 [⋯] → [유지] → [자세히 표시] → [그래도 계속]).

### 1-2. "Windows의 PC 보호" 창에서 실행하기
받은 파일을 두 번 누르면 파란 창 **"Windows의 PC 보호"**가 뜹니다. 아직 Microsoft 서명을 받지 않은 PoC 판이라 그렇습니다.
1. 창 안의 **[추가 정보]**를 누릅니다.
2. "게시자: 알 수 없는 게시자"가 보이면 아래 **[실행]**을 누릅니다.

관리자 암호를 묻는 창은 뜨지 않습니다(이 PC 사용자 폴더에만 설치합니다). [실행] 버튼이 아예 없으면 회사 보안 정책으로 막힌 것이니 캡처해서 보내 주세요.

### 1-3. 설치
따로 누를 것 없이 1분 정도 설치되고 앱이 저절로 켜집니다. 바탕화면과 시작 메뉴에 **"소버린 AX(가칭)"** 바로가기가 생깁니다.
- 설치 위치: `C:\Users\<사용자>\AppData\Local\Programs\SovereignAX`
- 앱 자료(장부·서류 보관함·기록): `C:\Users\<사용자>\AppData\Local\SovereignAX` — 앱을 지워도 남습니다.

처음 켤 때는 첫 화면까지 **20초쯤** 걸릴 수 있습니다(PC에 따라 다름). 두 번째부터는 빨라집니다.
화면 위쪽에 **"미서명 빌드"** 표시가 보이는 것은 정상입니다(서명 전 PoC 판이라는 뜻).

이제 [3. 처음 켜기](#3-처음-켜기-약관--로그인)로 가세요.

## 2. Mac에 설치하기

### 2-1. 내려받기·옮기기
1. 담당자가 드린 링크에서 `SovereignAX-<판>-universal.dmg`(약 250MB)를 받습니다.
2. 받은 `.dmg`를 두 번 누르면 창이 열립니다. **SovereignAX** 아이콘을 옆의 **Applications(응용 프로그램)** 폴더로 끌어 놓습니다.
3. 창을 닫고, Finder 왼쪽의 디스크 옆 꺼내기(⏏)를 누릅니다.

### 2-2. 처음 열기
응용 프로그램 폴더에서 SovereignAX를 두 번 누릅니다. 담당자가 판마다 둘 중 어느 경우인지 알려 드립니다.

**(가) Apple 공증을 받은 판** — "'SovereignAX'은(는) 인터넷에서 다운로드한 앱입니다. 열겠습니까?" → **[열기]**. 끝입니다.

**(나) 공증 전 판** — Mac이 한 번 막습니다. 아래처럼 한 번만 열면 다음부터는 그냥 열립니다.
- macOS 15(Sequoia) 이상
  1. "Apple은 'SovereignAX'에 … 악성 코드가 없음을 확인할 수 없습니다" 같은 창이 뜨면 **[완료]**를 누릅니다(**[휴지통으로 이동]은 누르지 마세요**).
  2. 사과 메뉴 → **[시스템 설정]** → **[개인정보 보호 및 보안]**.
  3. 아래로 내려 "보안" 칸의 "'SovereignAX'이(가) … 차단되었습니다" 옆 **[그래도 열기]**.
  4. Mac 로그인 암호(또는 Touch ID)를 넣고, 다시 뜨는 창에서 **[그래도 열기]**.
- macOS 13·14
  1. SovereignAX를 **Control 키를 누른 채 클릭**(또는 오른쪽 클릭) → **[열기]**.
  2. 뜨는 창에서 다시 **[열기]**.
- "손상되었기 때문에 열 수 없습니다"라는 다른 문구가 뜨면 휴지통으로 옮기지 말고 캡처해서 보내 주세요.

### 2-3. 키체인 허용 창
앱은 장부 열쇠를 Mac 키체인에 둡니다. 다음 경우에 Mac이 "이 열쇠를 써도 되느냐"고 묻습니다.
- 처음 설치할 때: 보통 뜨지 않습니다.
- **새 판으로 바꾼 뒤 처음 켤 때**: (나) 공증 전 판은 매번, (가) 공증 판은 공증 판으로 처음 바꿀 때 한 번 뜹니다.

창이 뜨면 이 순서로 해 주세요.
1. "'SovereignAX…'이(가) 키체인에 저장된 'SovereignAX'의 … 정보를 사용하려고 합니다" 같은 창이 뜹니다. 앱 화면은 이때 멈춘 것처럼 보입니다(창이 앱 뒤에 숨어 있을 수 있으니 Dock이나 다른 창을 살펴 주세요).
2. **암호** 칸에 Mac 로그인 암호를 넣습니다.
3. **[항상 허용]**을 누릅니다([허용]만 누르면 다음에 또 묻습니다).
4. 창이 2~3번 이어서 뜨면 매번 2~3을 합니다.
5. **[거부]**를 누르면 앱이 장부를 열지 못합니다. 실수로 눌렀다면 앱을 끄고(⌘Q) 다시 켜서 [항상 허용]을 눌러 주세요.

화면 위쪽에 **"미서명 빌드"** 표시가 보이면 (나) 공증 전 판입니다. 정상입니다.

## 3. 처음 켜기: 약관 → 로그인

1. 첫 화면 "시작하기 전에 약관과 처리방침을 확인해 주세요." → 내용을 읽고 **[동의하고 시작]**.
   - "약관 전문과 개인정보 처리방침 전문은 곧 여기서 열어 볼 수 있어요."라고 나옵니다. PoC 기간의 약관·개인정보 안내는 담당자가 따로 드립니다.
2. **로그인** 화면("앱을 쓰려면 먼저 로그인해 주세요. 이메일이 아이디예요")
   - 처음이시면 **[계정 만들기]** 또는 **[이메일 코드로 로그인]** → 이메일 입력 → **[코드 받기]**.
   - 메일함에 온 **6자리 코드**를 넣고 **[확인]**. 메일이 안 보이면 스팸함도 봐 주세요. 5분 넘게 안 오면 캡처해서 보내 주세요.
   - 로그인은 이 PC에 남아서, 앱을 껐다 켜도 다시 하지 않아도 됩니다.

## 4. 사업자·인증 등록

로그인하면 대화창에서 앱이 차례로 묻습니다.

1. **사업자 등록**: [사업자등록증 올리기](PDF·사진) 또는 [사업자번호로 입력].
   - 등록증을 올리면 이 PC 안에서만 읽어 칸을 채웁니다. 틀린 칸은 고쳐 주세요.
   - 사업자 상태 칸에 **"조회하지 못했어요"**, 안내에 "국세청 확인을 하지 못했습니다. 번호가 맞는지 확인해 주세요."가 나옵니다. 지금 판은 국세청 상태조회를 아직 하지 않아 **늘 이렇게 나옵니다.** 번호가 맞으면 **[맞습니다]**를 누르고 넘어가세요.
2. **발급 인증**: "세금계산서를 발급할 때 어떤 인증을 쓰세요?"
   - **공동인증서**: 이 PC에서 찾은 인증서 목록에서 고릅니다. 비밀번호는 저장하지 않고 **발급할 때마다 앱의 금고 창에 직접** 넣습니다.
   - **사업자 간편인증**: 발급할 때마다 폰 앱(카카오뱅크·IBK·KB)에서 승인합니다.
   - **보안카드**: 지원하지 않습니다("이 빌드에서는 아직 보안카드를 등록할 수 없어요").
   - "이 PC에서 공동인증서를 찾지 못했어요"가 나오면 [0](#0-시작-전에-확인해-주세요)의 인증서 위치를 확인해 주세요.
3. **AI 모델 동의**: "대화는 AI 모델로 해석해요." → **[동의하고 계속]**(필수).
4. **사용 기록**: [켜기] 또는 [끄고 계속] — PoC 중에는 [켜기]를 눌러 주시면 문제를 찾는 데 도움이 됩니다.
5. **맡길 업무**: **세금계산서 발급·메일 전송**을 고릅니다.
6. **거래처 등록**: 세금계산서를 보낼 거래처의 사업자번호(또는 등록증), 받는 이메일, **자주 쓰는 품목**을 넣습니다. 품목이 비어 있으면 발급 준비 중에 멈출 수 있으니 꼭 넣어 주세요.
7. "등록 내용을 확인해 주세요." 요약을 보고 마칩니다.

## 5. 첫 세금계산서 발급

첫 발급은 담당자와 통화하면서 함께 해 주시면 좋습니다.

1. 대화창에 예를 들어 **"○○상사에 세금계산서 발급해 줘, 컨설팅 100만 원"**처럼 칩니다.
2. 앱이 거래처·금액·품목을 카드로 보여 줍니다. 맞으면 **[홈택스에서 준비]**를 누릅니다.
   - "홈택스에서 준비하고 있어요. 승인하기 전에는 아무것도 발급하지 않아요." — 이때 Chrome 창이 하나 따로 뜹니다. **이 Chrome 창은 앱 전용**이니 다른 사이트를 열거나 Google 계정에 로그인하지 마세요.
3. 홈택스 로그인
   - 공동인증서: 앱의 **금고 창**이 떠서 "공동인증서 비밀번호"를 묻습니다. 여기에만 넣으세요(앱은 대화창에서 비밀번호를 묻지 않습니다).
   - 간편인증: 폰 앱에 온 요청을 승인합니다.
4. 앱이 홈택스에 값을 다 넣으면 **승인 카드**가 뜹니다. 공급받는자·품목·합계·받는 이메일을 확인하고
   - 맞으면 마우스로 **[승인하고 발급]**을 누릅니다(키보드 Enter로는 승인되지 않습니다). "승인하면 바로 발급되고 메일로 가요. 되돌릴 수 없어요."
   - 이상하면 **[중지]**. 아무것도 발급되지 않습니다.
5. 발급이 끝나면 대화창에 결과가 남습니다.

멈추거나 "예상한 홈택스 화면이 아니에요"처럼 나오면 그대로 두고 화면을 캡처해서 보내 주세요. 홈택스에서 직접 마치셨다면 [직접 발급함]을 눌러 주세요.

## 6. 받은 파일이 맞는지 확인하기 (SHA-256)

담당자가 설치 파일과 **따로**(문자·카카오톡 등) 보내 드린 64자리 값과 아래 결과가 같아야 합니다. 다르면 설치하지 마시고 알려 주세요.

**Windows**: 시작 메뉴에서 "PowerShell"을 열고
```
Get-FileHash $HOME\Downloads\SovereignAX-Setup-<판>.exe -Algorithm SHA256
```
**Mac**: 응용 프로그램 → 유틸리티 → 터미널을 열고
```
shasum -a 256 ~/Downloads/SovereignAX-<판>-universal.dmg
```
(대문자·소문자 차이는 상관없습니다.)

## 7. 막혔을 때 보내 주세요

아래 세 가지를 담당자에게 보내 주시면 됩니다.

1. **화면 캡처** — 막힌 화면 전체. 주민번호·계좌번호가 보이면 가려 주세요.
   - Windows: `Windows 키 + Shift + S`, Mac: `⌘ + Shift + 4`
2. **무엇을 하다가** — 몇 번째 단계에서, 무엇을 눌렀을 때, 언제(대략 시각)
3. **기록 파일(logs 폴더)** — 폴더째 압축해서 보내 주세요.
   - Windows: 파일 탐색기 주소창에 `%LOCALAPPDATA%\SovereignAX\logs` 를 붙여 넣고 Enter → `main.log`, `engine.log`, `vault.log`
   - Mac: Finder에서 `⌘ + Shift + G` → `~/Library/Application Support/SovereignAX/logs` → 같은 세 파일
   - 이 기록에는 **무슨 일이 언제 일어났는지(결과 코드·시각)만** 남습니다. 비밀번호·인증서·이메일·이름·거래 내용 같은 **값은 적지 않도록** 만들었습니다(한글·이메일 모양·긴 글자는 `[dropped]`로 지워서 적습니다).
   - **다른 폴더(db, vault, chrome-profile, userData 등)는 보내지 마세요.** 장부·로그인 정보·브라우저 자료가 들어 있습니다.

그리고 어떤 판을 쓰시는지 알려 주세요(받은 설치 파일 이름의 숫자, 예: 0.1.8).
- Windows: 설정 → 앱 → 설치된 앱 → "소버린 AX(가칭)"에 판이 보입니다.
- Mac: 응용 프로그램에서 SovereignAX를 Control-클릭 → [정보 가져오기] → "버전".

## 8. 새 판으로 바꾸기

지금 판에는 자동 업데이트가 없습니다. **새 판 받기 = 새 설치 파일을 받아 다시 실행**이고, **로그인·사업자·거래처·서류는 그대로** 남습니다. 담당자가 새 설치 파일 링크와 SHA-256 값을 드립니다([6](#6-받은-파일이-맞는지-확인하기-sha-256)으로 확인).

- **Windows**
  1. 앱을 끕니다(창 닫기).
  2. 새 `SovereignAX-Setup-<판>.exe`를 두 번 누릅니다. "Windows의 PC 보호" 창이 다시 뜨면 [추가 정보] → [실행].
  3. 그 위에 그대로 설치되고 앱이 켜집니다.
- **Mac**
  1. 앱을 끕니다(⌘Q).
  2. 새 `.dmg`를 열어 SovereignAX를 응용 프로그램으로 끌어 놓고, "이미 있습니다" 창에서 **[대치]**.
  3. 앱을 엽니다. 2-2의 (가) 또는 (나)가 다시 나옵니다.
  4. **키체인 허용 창**이 뜨면 2-3대로 암호 → **[항상 허용]**(여러 번이면 매번).

- Mac: 응용 프로그램에서 SovereignAX를 휴지통으로
- 둘 다 **앱 자료 폴더는 남습니다**(실수로 지워도 다시 설치하면 이어 쓸 수 있게). 자료까지 지우고 싶으시면 담당자에게 말씀해 주세요. 같이 정리해 드립니다.
