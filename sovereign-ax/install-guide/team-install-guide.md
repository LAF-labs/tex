# 소버린 AX 팀원 설치 안내 (Mac)

설치부터 첫 발급 준비까지 한 장에 적었습니다. 막히면 8번을 봐 주세요.

## 1. 준비
- **Mac**: macOS 13(Ventura) 이상. Apple 칩(M1~M4)과 Intel Mac 모두 됩니다(한 파일에 둘 다 들어 있습니다).
- **Google Chrome**: 앱이 홈택스 일을 할 때 Chrome을 따로 띄워 씁니다. https://www.google.com/chrome 에서 받아 **응용 프로그램** 폴더에 둡니다.
- **본인 이메일**: 로그인 코드가 이 주소로 옵니다. **대표 이메일로 로그인하지 마세요.** 계정 하나는 PC 한 대에만 연결됩니다.

## 2. 받기
https://tax.laf-co.com/download 를 열고 [Mac용 내려받기]를 누릅니다. `SovereignAX-<판>-universal.dmg`(약 265MB)가 내려받아집니다. 바로 받는 주소는 https://tax.laf-co.com/download/mac 이고, 늘 최신 판을 줍니다.

## 3. 설치
1. 받은 `.dmg`를 두 번 누릅니다. **SovereignAX**를 옆의 **Applications** 폴더로 끌어 놓습니다.
2. Finder 왼쪽 디스크 옆 꺼내기(⏏)를 누릅니다.
3. 응용 프로그램에서 **SovereignAX**를 엽니다. "인터넷에서 다운로드한 앱입니다" 창이 뜨면 [열기]를 누릅니다.

새 판은 앱이 알아서 받아 다음 실행 때 바뀝니다. 다시 깔 필요가 없습니다.

## 4. 첫 실행
1. **약관·AI 모델 안내**: 한 화면입니다. [동의]를 누릅니다.
2. **로그인**: 본인 이메일을 넣고, 메일로 온 6자리 코드를 넣습니다. 처음이면 이때 계정이 만들어집니다.
3. **사업자**: 상호와 사업자번호를 넣고 [맞아요]를 누릅니다.
4. **홈택스 인증서**: 이 Mac에서 찾은 공동인증서 목록에서 고르고 [이 인증서로]를 누릅니다. 목록이 비어 있으면 6번대로 옮긴 뒤 다시 엽니다.
5. **첫 발급 제안**: 여기까지 오면 준비가 끝났습니다. 인증서 비밀번호는 첫 발급 때 금고 창에서 한 번만 넣습니다. 그다음부터는 앱이 기억합니다.

## 5. 사업장: 라프를 같이 쓸지, 각자 쓸지
앱은 사업장 정보와 인증서를 **각 Mac에만** 둡니다. 서버에서 나눠 쓰지 않습니다. 발급 기록도 각자 Mac에 남습니다.
- **라프를 같이 쓸 때**: 4-3에 라프 사업자번호를 넣습니다. 라프의 **사업자범용(또는 전자세금계산서용) 공동인증서**를 대표에게 받아 6번대로 넣습니다. 비밀번호도 대표에게 받습니다.
- **각자 사업장일 때**: 본인 사업자번호와 본인 사업자 인증서를 씁니다.
- 개인용·은행용 인증서로는 세금계산서가 발급되지 않습니다.

## 6. 공동인증서를 Mac으로 옮기기
앱은 이 세 곳에서 인증서를 찾습니다: `~/Library/Preferences/NPKI`, `~/Documents/NPKI`, `~/NPKI`.
1. 원래 PC에서 **NPKI 폴더 전체**를 USB나 메신저 파일로 가져옵니다.
   - Windows: `C:\Users\<사용자>\AppData\LocalLow\NPKI`
   - 다른 Mac: `~/Library/Preferences/NPKI`
   - USB에만 있으면: USB 안의 `NPKI` 폴더
2. 이 Mac의 Finder에서 [이동] → [폴더로 이동]에 `~/Documents`를 넣고, 그 안에 `NPKI` 폴더를 통째로 붙여 넣습니다. 안에 `signCert.der`와 `signPri.key`가 같이 있어야 합니다.
3. 앱을 다시 열고 4-4로 갑니다.

## 7. 홈택스 보안 프로그램(MagicLine4NX)
공동인증서로 홈택스에 로그인·서명하려면 이 프로그램이 있어야 합니다. 없으면 인증서 화면 위에 **"홈택스 공동인증서 프로그램이 이 PC에 없어요"** 상자가 뜹니다.
1. [설치 파일 받기]를 누릅니다. 홈택스 공식 설치 파일(`MagicLine4NX.pkg`)이 내려받아집니다.
2. 받은 파일을 열어 설치합니다(Mac 암호를 물으면 넣습니다).
3. 앱에서 [다시 확인]을 누릅니다. 상자가 사라지면 됩니다.

## 8. 막힐 때
| 증상 | 할 일 |
|---|---|
| 로그인 코드 메일이 안 옴 | 스팸함을 봅니다. 5분 뒤 다시 보냅니다(이메일 하나에 한 시간 5번까지). 그래도 안 오면 대표에게 이메일 주소를 알려 주세요. 메일 발송 쪽에 주소 등록이 필요할 수 있습니다 |
| "이 계정에는 이미 등록된 PC가 있어요" | 대표 이메일 등 다른 Mac에 연결된 계정입니다. 본인 이메일로 로그인합니다 |
| "Apple이 악성 코드가 없음을 확인할 수 없습니다" 창 | 공증 전 판입니다. 열지 말고 대표에게 새 링크를 받습니다 |
| 인증서 목록이 비어 있음 | 6번 위치에 `NPKI` 폴더가 있는지, 안에 `signCert.der`·`signPri.key`가 있는지 봅니다 |
| "Chrome이 설치돼 있어야 해요" | 1번대로 Chrome을 응용 프로그램 폴더에 깔고 [다시 준비]를 누릅니다 |
| 그 밖 | 화면 캡처와 함께 `~/Library/Application Support/SovereignAX/logs` 폴더를 대표에게 보냅니다 |
