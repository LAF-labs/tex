# 데이터 위계

화면의 모든 값은 여섯 단계 중 하나에 속한다. 단계가 크기·굵기·색·서체를 정하고, 컴포넌트는 단계를 고를 뿐 스타일을 새로 만들지 않는다. 같은 단계의 값은 어느 화면에서나 같은 모양이다.

## 여섯 단계

| 단계 | 무엇 | 스타일 | 색 | 예 |
|---|---|---|---|---|
| D1 결정 값 | 행동하기 전에 사용자가 반드시 확인할 값 | `figure-lg` | `ink` | 합계 3,300,000원 · 유효 D-30 |
| D2 식별 | 누구·무엇에 대한 일인가 | `title-card`, 서류는 `doc-name` | `ink` | 세금계산서 · A상사 · 사업자등록증명 |
| D3 근거 값 | D1을 이루거나 설명하는 값 | 수치 `figure`, 글자 `value` | `ink` | 공급가 3,000,000원 · 품목 컨설팅 |
| D4 식별 번호 | 다른 곳과 대조할 번호 | `id`(고정폭) | `ink-2` | 123-45-67890 · 승인번호 |
| D5 라벨 | 값의 이름 | `label` | `ink-3` | 공급받는자 · 받는 이메일 |
| D6 출처·메타 | 값이 어디서, 언제 왔는가 | `meta` | `ink-3` | 홈택스에서 되읽음 · 10:43 |

- D1은 카드·패널·창마다 **하나까지**다. 두 값이 똑같이 중요하면 카드를 나눈다. 서류 카드처럼 결정할 값이 없으면 D1을 두지 않는다.
- 값을 더 눈에 띄게 하려면 단계를 올린다. 같은 단계 안에서 굵기·색·크기를 바꾸지 않는다. 색은 `accent`·`attention`의 뜻으로만 쓴다.
- 값에는 항상 D5 라벨을 붙인다. 형식이 뻔한 사업자번호도 라벨이 있다. 예외는 대화 문장 속 값이다.
- 수치는 오른쪽 정렬, 고정폭 숫자다. 라벨은 왼쪽, 폭은 `field-label-width`다.

## 값의 확실성

단계와 별개로, 값마다 얼마나 확실한지를 보여 준다. 사용자가 "앱이 정한 값"과 "내가 확인한 값"과 "홈택스가 확정한 값"을 구별할 수 있어야 승인할 수 있다.

| 상태 | 뜻 | 표시 |
|---|---|---|
| 비어 있음 | 아직 없는 값 | "—" `ink-4`. 필수 값이면 라벨 옆 `attention` "입력 필요" |
| 추정 | 앱이 채웠고 사용자가 아직 확인하지 않은 값(저장된 기본값, 문장 해석) | `ink-2` + `line-strong` 점선 밑줄 + `meta` "추정" |
| 확인함 | 사용자가 입력하거나 확인한 값 | `ink`, 장식 없음 |
| 확정 | 홈택스에서 되읽었거나 조회로 확인한 값 | `ink` + `meta` "✓ 홈택스 확정" |
| 불일치 | 되읽은 값이 초안과 다름 | `attention` 실선 밑줄 + `meta`에 초안 값(취소선) |

- 추정 값이 남은 초안 카드는 주요 버튼 옆에 "추정 값 n개"를 `meta`로 쓴다. 사용자가 그 칸을 누르면 확인함으로 바뀐다.
- 승인 대기 카드와 작업 패널에는 확정 값만 들어간다. 불일치가 있으면 그 행에 초안 값을 함께 쓴다.

## 표기 형식

| 데이터 | 형식 | 예 |
|---|---|---|
| 금액 | 천 단위 쉼표 + "원". 분해는 "+"로 잇는다 | 3,300,000원 · 공급가 3,000,000 + 세액 300,000 |
| 사업자번호 | 3-2-5 하이픈, 고정폭 | 123-45-67890 |
| 법인등록번호·주민등록번호 | 뒷자리를 가린다 | 110111-••••••• |
| 승인번호·발급번호 | 포털이 준 형식 그대로, 고정폭 | 20261030-41000012-00000123 (예시) |
| 날짜 | 값은 YYYY-MM-DD. 대화 날짜 구분선만 "10월 30일 목요일" | 2026-10-30 |
| 시각 | 24시간 HH:MM | 10:43 |
| 남은 기간 | D-n. 7일 이하면 `attention` | D-30 · D-3 |
| 빈 값 | "—" | — |

## 배치 순서

- **작업 패널(확인 카드)**: D2 제목 + 상태 칩 → D1 → D3 목록(KeyValue) → D6 출처 한 줄.
- **대화 속 작업 카드**: D2 + 상태 칩 → D1 → 차례 안내 → 버튼. D3 목록은 작업 패널에만 둔다.
- **승인 대기**: 카드는 D2 + 상태 칩 → D1 → 결과 문장 → "화면 아래쪽 [승인하고 발급]에서 값을 한 번 더 확인하고 눌러 주세요". 확정 값 목록(D3, 합계 행만 굵게)은 작업 패널에 두고, 그 아래 승인 바에 D2 공급받는자(상호·D4 사업자번호)·D1 합계와 세액·받는 이메일과 "승인하고 발급"을 한 버튼으로 둔다(ADR-021).
- **서류 카드**: D6 종류 → D2 서류 이름(`doc-name`) → D3 세 칸(발급일, 용도, 유효) → 버튼.
- **목록 화면(문서함·거래처·활동 기록)**: 열 순서는 D2 → D1·D3 → D4 → D6. 수치 열은 오른쪽 정렬.
