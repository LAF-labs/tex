# TaskCard

대화 속에서 작업 하나를 처음부터 끝까지 보여 주는 카드다. 상태가 바뀌면 새 카드를 만들지 않고 이 카드가 바뀐다.

- 구성(데이터 위계 순서): D2 제목 + StatusChip → D1 Amount → 안내 줄(필요할 때) → 버튼.
- 넘겨줄 것: 작업 이름과 거래처, 상태, D1 값과 분해, 안내 문장, 버튼 1~3개, 추정 값 개수.
- 상태별: 내 차례는 `sx-card is-turn`과 파랑 안내 줄(`sx-note`), 승인 대기는 `sx-card is-turn` + `is-waiting` 칩 + "아래 [승인하고 발급]에서 값을 한 번 더 확인하고 눌러 주세요" 안내 + [중지](PC의 [승인하고 발급]은 ApprovalBar에만 있다, ADR-021), 확인 중(응답이 끊겨 앱이 발급목록을 다시 조회)은 기본 테두리, 확인 필요(앱이 풀 수 없을 때만)는 `sx-card is-attention`과 `sx-note is-attention`.
- D3 목록은 카드에 넣지 않는다. 카드를 누르면 작업 패널에 KeyValue로 열린다.
- 초안 상태의 세금계산서 카드에는 [홈택스에서 준비] [부가세 포함하기] [금액 수정] [취소]를 둔다(ADR-020).
- 모양(v1.2): `surface` 바탕, `line` 1px, 모서리 12(`radius-lg`), 안쪽 16, 요소 사이 12. 내 차례·승인 대기는 테두리만 `accent`로 바뀐다. 결과 카드의 "어디로 무엇이 갔는지"는 접힘 영역(점진 공개)이며 머리 줄은 `ink-2` 글자와 꺾쇠, 펼치면 `line-soft` 선 아래 목록이다.
- 하지 말 것: 왼쪽 색 띠, 그림자, 카드 안의 승인 버튼(PC, ADR-021).
