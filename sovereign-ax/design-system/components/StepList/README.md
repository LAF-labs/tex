# StepList

작업 패널에서 실행 단계를 위에서 아래로 보여 주는 목록이다. 진행 중 표시는 회전 아이콘이 아니라 현재 단계의 점이다.

- 단계 상태: 끝남 `is-done`(채운 점), 현재 `is-now`(파랑 고리), 확인 필요 `is-attention`(황토 고리), 아직 기본(빈 점, `ink-3`).
- 현재 단계 아래에 `small`로 지금 사람이 할 일이나 기다리는 것을 한 줄 쓴다.
- 넘겨줄 것: 단계 이름 목록(플레이북이 정함), 현재 단계, 안내 한 줄.
- 움직임(v1.2): 현재 단계의 파랑 고리는 `motion-pulse`(2.4초) 주기로 불투명도 1 → 0.45 → 1로 숨 쉰다. 앱에서 유일한 반복 움직임이며 회전·튀는 효과는 없다. 동작 줄이기 설정이면 멈춘다.
