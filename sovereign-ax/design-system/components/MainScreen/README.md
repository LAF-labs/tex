# MainScreen

PC 메인 화면(M-01)의 조립 예다. 레일·대화·작업 패널 3단에 위 컴포넌트를 데이터 위계대로 배치한다.

- 치수는 `titlebar-height`, `rail-width`, `panel-width`, `chat-max`를 따른다.
- 대화에는 TaskCard와 ChoiceCard, 작업 패널에는 같은 작업의 D2 제목 + StatusChip, D1 Amount, KeyValue, StepList 순서로 둔다.
- 이 예에서 파랑은 오늘 요약의 숫자, 두 개의 "내 차례" 칩, 작업 카드 테두리와 안내 줄, 현재 단계 점에만 있다. 파랑으로 채운 면은 없다.
- 오늘 요약은 대화 맨 위 한 줄이며 숫자 타일로 만들지 않는다.
