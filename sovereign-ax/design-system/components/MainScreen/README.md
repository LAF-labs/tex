# MainScreen

PC 메인 화면(M-01)의 조립 예다. 레일·대화·작업 패널 3단에 위 컴포넌트를 데이터 위계대로 배치한다.

- 치수는 `titlebar-height`, `rail-width`, `panel-width`, `chat-max`를 따른다.
- 대화에는 TaskCard와 ChoiceCard, 작업 패널에는 같은 작업의 D2 제목 + StatusChip, D1 Amount, KeyValue, StepList 순서로 둔다.
- 대화 열 아래, 입력창 위는 승인 카드 자리다. 승인 대기일 때만 main이 대화창과 따로 그린 승인 카드(금액, 되읽은 값 전체, 비가역 한 줄, [중지]·[승인하고 발급])가 이 자리에 뜨고, 렌더러의 작성 카드는 "작성 완료" 한 줄로 접힌다. 대화 화면은 main이 정한 카드 높이만큼 자리를 비운다(ADR-021 결정 7).
- 이 예에서 파랑은 오늘 요약의 숫자, 두 개의 "내 차례" 칩, 작업 카드 테두리와 안내 줄, 현재 단계 점에만 있다. 파랑으로 채운 면은 없다.
- 오늘 요약은 대화 맨 위 한 줄이며 숫자 타일로 만들지 않는다.
- 모양(v1.2): 제목줄·레일·패널은 `surface`이고 구분은 `line` 하나다. 레일의 선택 항목과 hover는 `surface-tint`(모서리 8). 검색 칸은 테두리 없는 `surface-tint`에 `ink-3` 글자와 단축키 표시. 오늘 요약은 상자가 아니라 아래 선(`line`) 하나의 한 줄이다. 패널 안쪽 16, 요소 사이 12, 섹션 라벨 12px 500 `ink-3`(자간 없음). 토스트는 `ink` 채움에 `on-ink` 글자, `shadow-overlay`.
