# ApprovalBar

PC에서 되돌릴 수 없는 발급·전송을 승인받는 유일한 자리다(ADR-021). 대화창과 따로, 앱이 스크립트 없는 정적 화면으로 그린다. 그래서 대화창이 악성 내용에 장악돼도 이 바를 누른 것처럼 꾸밀 수 없다.

- 자리: 작업 패널 하단, 창 오른쪽 아래. 폭은 `panel-width`, 창이 좁으면 창 하단 전체 폭 띠. 대화 열 하단 띠 안은 PoC-9에서 비교한다. 대화 화면은 이 자리를 비워 둔다.
- 구성: 요약 줄 3줄(라벨 칸 고정 + 값 한 줄) → 동작 글자. **바 전체가 버튼 하나**이고, 바 안에 작은 버튼을 따로 두지 않는다.
  - H-01: 공급받는자(상호 · 사업자번호), 합계금액 · 세액, 받는 이메일.
  - 민원증명(H-03·H-04 등): 서류명 · 부수, 발급 대상(상호 · 사업자번호), 용도·제출처 · 주민등록번호 공개 범위.
- 값 줄이기: 사업자번호·금액·이메일 `@` 뒤는 줄이지 않는다. 상호와 이메일 `@` 앞만 말줄임(…)으로 줄인다. 줄이지 않는 값이 안 들어가면 "창을 넓혀 주세요" 상태가 된다.
- 모양: 직각 모서리, 그림자 없음(앱 화면 밖에 그릴 수 없고 둥근 모서리도 클릭을 받기 때문이다). 서체는 시스템 서체(tokens `승인 바`). 파랑(`accent`) 채움은 승인 상태에만 쓴다.

| 상태 | 요약 줄 | 동작 글자 | 색 | 누를 수 있나 |
|---|---|---|---|---|
| 무장 전(0.6초) | 있음 | 승인하고 발급 | 흐린 파랑 | 아니요. 누르면 "잠시 뒤 다시 눌러 주세요" |
| 승인 | 있음 | 승인하고 발급 | 파랑 | 예 |
| 처음 거래·처음 보내는 주소 | 해당 줄 끝에 표시 | 승인하고 발급 | 파랑 | 예 |
| Hello 다시 시도 | 있음 | Windows Hello 다시 시도 | 파랑 | 예 |
| Hello 면제 | 있음 | 이번만 Hello 없이 승인 | 파랑 | 예(알림이 남는다) |
| 폰이 먼저 결정 | 없음 | 폰에서 이미 승인했어요 | 무채색 | 아니요. 2초 뒤 내려간다 |
| 창을 넓혀 주세요·값 확인 필요 | 넘친 칸 표시 | 창을 넓혀 주세요(또는 고칠 칸 이름) | 무채색 | 아니요 |
| InDoubt 증언 | E-13 고정 문구 | 홈택스 발급목록에 없음을 확인했어요 | 황토(`attention`) | 예 |
| Hello 설정 | 없음 | 발급 전 Windows Hello 확인 켜기(끄기) | 무채색 테두리 | 예 |

- 무장 전 흐림은 CSS 애니메이션으로 0.6초 뒤 풀린다. 상태가 바뀌거나 다시 무장할 때 앱이 화면을 다시 불러온다.
- 대화 카드의 안내 문구는 "화면 아래쪽 [승인하고 발급]에서 값을 한 번 더 확인하고 눌러 주세요"로 통일한다. "승인 바"라는 말은 사용자 화면에 쓰지 않는다.
- 하지 말 것: 바 안의 작은 버튼, 값의 끝 자르기, 그림자·둥근 모서리, 키보드 포커스 링으로 승인하는 동작(키보드 승인 없음).
