# Amount

금액을 D1 결정 값으로 보여 주는 표기다. 큰 합계 한 줄과 그 아래 분해 한 줄로 이뤄진다.

- 쓰는 곳: 대화 속 작업 카드, 작업 패널 맨 위, 모바일 승인 시트.
- 넘겨줄 것: 합계(원 단위 정수), 분해(공급가·세액) 또는 보조 정보 한 줄.
- 표기: 천 단위 쉼표, 숫자 뒤 "원"은 `sx-unit`(작게, `ink-2`). 분해는 "공급가 3,000,000 + 세액 300,000". 금액은 고정폭 숫자다.
- 카드·패널·창마다 하나만 쓴다. 표 안의 금액은 Amount가 아니라 KeyValue 값(D3)이다.
- 모양(v1.2): 합계 24/30 600, 자간 -0.015em. 단위 "원"은 16px 500 `ink-2`. 분해 줄 13/20 `ink-2`. 합계와 분해 사이 2px.
