# SecretField

이 PC에만 저장하는 비밀 값을 받는 입력 묶음이다. 대표 예는 보안카드 등록 모달(T-06)의 카드 번호 30칸이다.

- 창(ADR-022·023, 2026-11-03): 비밀 입력은 대화창 안 모달로 그리지 않는다. main이 만든 OS 테두리 창("금고 · …" 제목, 화면 캡처 차단, 대화상자 차단)으로 띄우고, 금고가 그 실행·종류·칸에 묶어 요청할 때만 열린다. 대화창이 같은 모양을 그려도 OS 제목 줄과 창 테두리가 없어 구별된다. 창의 안쪽 모양은 아래 규칙 그대로다.

- 마크업: `sx-secret` 안에 머리 줄 `sx-secret-hd`(D5 라벨 + `sx-reveal` 버튼)와 칸 그리드 `sx-secret-grid`. 칸은 `sx-secret-cell`(위에 칸 번호, 아래 입력)이다. 칸 번호와 값은 `font-mono`다.
- 칸은 기본으로 가린다(`type="password"`). 입력 중인 칸은 `focus-ring` 2px 테두리, 숫자 네 자리가 아닌 칸은 `attention` 테두리(`is-attention`)다.
- 보기 버튼은 묶음마다 하나, 머리 줄 오른쪽에 둔다. 눈 아이콘과 "번호 보기", 켜면 빗금 눈과 "번호 가리기"로 바꾸고 `aria-pressed`로 상태를 알린다. 색은 `ink-2`이며 파랑을 쓰지 않는다.
- 켜면 모든 칸이 보이고 버튼 옆에 "30초 뒤 다시 가려요"를 `sx-meta`로 쓴다. 30초가 지나거나 모달을 닫으면 다시 가린다. 카드 사진으로 채운 값을 카드와 대조할 때 쓴다.
- 값은 금고 프로세스만 다룬다. 대화, 활동 기록, 미리보기 이미지에 값을 남기지 않는다(08 §9, ADR-020).
- 하지 말 것: 칸마다 보기 버튼, 보이는 상태를 기본값으로 두기, 30초 자동 가림 없이 켜 두기.
