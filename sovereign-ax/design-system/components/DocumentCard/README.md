# DocumentCard

발급된 서류 하나를 보여 주는 카드다. 서류 이름만 세리프(`doc-name`)로 써서 서류다운 인상을 준다.

- 구성: D6 종류 → D2 서류 이름 → D3 세 칸(발급일, 용도, 유효) → 버튼. 사용자가 승인해 발급한 서류에는 오른쪽 위에 승인 도장(`sx-seal`)을 둔다.
- 넘겨줄 것: 종류, 서류 이름, 발급일, 용도·제출처, 남은 유효기간(D-n), 승인 여부.
- 유효가 7일 이하면 그 칸 값에 `is-attention`.
- 승인 도장은 파랑(`accent`)이며 "사용자가 승인했다"는 기록이다. 직접 추가한 서류에는 두지 않는다.
