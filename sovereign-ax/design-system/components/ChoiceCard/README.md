# ChoiceCard

정해진 선택지 중 하나를 묻는 대화 카드다. 대표 예는 온보딩의 발급 인증 선택(O-03)이다.

- 넘겨줄 것: 질문 한 줄, 선택지 2~5개(이름 한 줄 + 설명 한 줄), 미리 고른 값, 고른 뒤의 상태.
- 마크업: `sx-card` 안에 `sx-opt`, 고른 것은 `is-on`. 선택 표시는 `ink`이며 파랑을 쓰지 않는다.
- 모양(v1.2): 선택지는 `line` 테두리, 모서리 8, hover에 `surface-tint`와 `line-strong`, 고른 것은 `ink` 테두리.
- 고르면 카드 오른쪽 위에 "골랐어요"를 `sx-meta`로 쓰고, 선택지는 그대로 남긴다(고친 이력이 보이게).
- 세금계산서 금액의 부가세 별도/포함은 ChoiceCard로 묻지 않는다. 입력창 토글(Composer)과 초안 카드의 [부가세 포함하기]로 정한다(ADR-020).
- 과세유형처럼 앱이 추측하면 안 되는 값은 미리 고르지 않는다.
