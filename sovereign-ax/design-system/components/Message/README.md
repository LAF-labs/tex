# Message

메인 대화의 메시지들이다. 사용자 말은 말풍선, 앱의 말은 말풍선 없는 글이며, 날짜 구분선과 출처 표시("폰에서", "서버 답변")가 있다.

- 사용자 말 `sx-me`(오른쪽), 앱의 말 `sx-app`(왼쪽, 짧은 해요체 한두 문장), 날짜 구분선 `sx-day`("10월 30일 목요일").
- 폰에서 보낸 말과 PC가 꺼져 있을 때 서버가 한 답에는 `sx-origin`을 붙인다(ADR-019).
- 앱의 말에는 값을 길게 나열하지 않는다. 값은 카드(TaskCard, ChoiceCard)로 보여 준다.
