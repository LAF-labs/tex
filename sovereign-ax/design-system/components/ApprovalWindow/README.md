# ApprovalWindow

**폐지(ADR-020, 2026-10-30).** PC 승인은 대화 열 하단 승인 바(ApprovalBar)의 `sx-btn-approve`로 했고(ADR-021, 2026-10-31), 2026-11-06부터는 main이 그리는 승인 카드([ApprovalCard](../ApprovalCard/README.md), ADR-021 결정 7)다. 승인 바는 이 창의 규칙(정적 HTML, 클릭만, 600ms 무시, 포커스 비탈취)을 창 대신 앱 안의 작은 화면에 적용한 것이다. 아래는 이전 설계의 기록이다.

되돌릴 수 없는 발급·전송을 승인받는 PC의 별도 창(T-03)이다. 앱 본체와 다르게 생겼고, 앱이 정적 HTML로 만든다.

- 앱(main 프로세스)이 고정 문구와 홈택스에서 되읽은 값만으로 만든다. 스크립트·외부 서체·이미지가 없으므로 `font-system`과 CSS만으로 완성한다(ADR-014).
- 구성: 제목줄 → 파랑 띠(`accent`, 이 창에만 있다) → 질문(D2를 넣은 문장) → 출처(D6) → 확정 값 표(합계 행 `is-total`) → 결과 문장 → [취소] [승인하고 발급] → 안내.
- 넘겨줄 것: 작업 이름, 되읽은 값 전부, 결과 설명(무엇이 어디로 가는지), 되돌릴 수 없다는 문장.
- 승인은 마우스 클릭만 받는다. 창이 뜨고 600ms 동안의 입력은 무시하고, 포커스를 빼앗지 않는다.
- 불일치 값이 있으면 그 행의 값 뒤에 초안 값을 `sx-was`로 쓴다.
