# StatusChip

작업 하나의 상태를 한 단어로 보여 주는 칩이며, 열한 가지 상태 중 셋에만 색이 붙는다.

- 상태와 클래스: 작성 중·준비 중·발급 중·확인 중·처리 대기(기본), 내 차례(`is-turn`), 승인 대기(`is-waiting`), 확인 필요(`is-attention`), 완료(`is-done`), 중지됨(`is-stopped`), 실패(`is-fail`).
- 카드 제목 오른쪽에 하나만 둔다. 같은 작업의 대화 카드와 작업 패널은 같은 칩을 보여 준다.
- 색은 `accent`(내 차례·승인 대기)와 `attention`(확인 필요)뿐이다. 완료는 체크, 실패는 `ink` 테두리로 구분한다.
- 하지 말 것: 칩을 장식이나 분류 태그로 쓰기, 칩 여러 개 나란히 두기.
