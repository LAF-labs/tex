# Identifier

사업자번호·승인번호·발급번호 같은 대조용 번호(D4)를 고정폭으로 보여 주고, 필요하면 복사 버튼을 붙인다.

- 넘겨줄 것: 번호 문자열(포털이 준 형식 그대로), 가릴지 여부.
- 마크업: `<span class="sx-id">`, 복사는 `<button class="sx-copy">복사</button>`.
- 주민등록번호·법인등록번호는 뒷자리를 가린다(`110111-•••••••`). 가린 번호에는 복사 버튼을 두지 않는다.
- 하지 말 것: 번호를 굵게 하거나 `ink`로 올리기. 번호는 D4라 `ink-2`다.
