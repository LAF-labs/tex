# Button

행동 버튼이다. 주요 행동은 `ink`로 채우고, 파랑으로 채운 버튼은 비가역 승인에만 쓴다.

- 종류: 주요 `sx-btn sx-btn-primary`(카드마다 하나), 보조 `sx-btn`, 조용한 `sx-btn sx-btn-quiet`(중지, 닫기), 승인 `sx-btn sx-btn-approve`(PC는 main이 그리는 승인 카드, 모바일은 승인 시트에만).
- 모양(v1.2): 높이 32, 모서리 8, 글자 13px. 주요는 `ink` 채움에 600, 보조는 `line-strong` 테두리에 500, 조용한은 테두리 없이 `ink-2`, 승인은 `accent` 채움에 600. hover는 보조·조용한이 `surface-tint`, 주요는 `ink-2`, 승인은 `accent-strong`이고, 누름은 `surface-sunken`이다. 색 변화는 `motion-fast`(120ms). 복사·빠른 실행·필터처럼 작은 보조 버튼은 `line` 테두리를 쓴다(글자가 있어 테두리가 유일한 식별 수단이 아니다, WCAG 2.2 1.4.11). 비활성은 `line` 테두리와 `ink-4` 글자.
- 글자는 동사로 끝낸다: "홈택스에서 준비", "다시 조회", "승인하고 발급".
- 승인 버튼은 키보드로 눌리지 않는다(입력창 Enter·단축키 없음). PC의 승인 버튼은 main이 따로 그리는 승인 카드 안에만 있고, 카드의 기본 포커스는 옆에 떨어뜨려 둔 [중지]다(ADR-021 결정 7). 카드가 나타나거나 내용이 바뀐 뒤, 그리고 앱 창이 옮겨지거나 다시 보이거나 앞으로 온 뒤 600ms 동안은 흐리게 보이며 눌리지 않는다(앱이 흐린 화면과 무장된 화면을 바꿔 불러온다, 스크립트 없음). 그동안 누르면 "잠시 뒤 다시 눌러 주세요"를 보인다. 앱이 연 인계에서 120초 안에 돌아온 첫 클릭만 예외로 받는다(ADR-027). 상태별 모양은 ApprovalCard. 설정에서 Windows Hello 확인을 켜면 누른 뒤 한 번 더 확인한다(ADR-020·021).
- 하지 말 것: 대화 카드 안의 승인 버튼(PC, ADR-021), 한 카드에 주요 버튼 두 개, "확인"·"다음" 같은 글자.
