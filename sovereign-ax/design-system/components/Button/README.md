# Button

행동 버튼이다. 주요 행동은 `ink`로 채우고, 파랑으로 채운 버튼은 비가역 승인에만 쓴다.

- 종류: 주요 `sx-btn sx-btn-primary`(카드마다 하나), 보조 `sx-btn`, 조용한 `sx-btn sx-btn-quiet`(중지, 닫기), 승인 `sx-btn sx-btn-approve`(PC는 작업 패널 하단 승인 바, 모바일은 승인 시트에만).
- 글자는 동사로 끝낸다: "홈택스에서 준비", "다시 조회", "승인하고 발급".
- 승인 버튼은 키보드로 눌리지 않는다(입력창 Enter·단축키 없음). PC의 승인 버튼은 앱이 따로 그리는 승인 바 안에만 있고, 요약 줄과 함께 바 전체가 한 버튼이다. 바가 나타나거나 내용이 바뀐 뒤, 그리고 앱 창이 옮겨지거나 다시 보이거나 앞으로 온 뒤 600ms 동안은 흐리게 보이며 눌리지 않는다(앱이 흐린 화면과 무장된 화면을 바꿔 불러온다, 스크립트 없음). 그동안 누르면 "잠시 뒤 다시 눌러 주세요"를 보인다. 바를 눌러 앱 창을 앞으로 가져온 첫 클릭은 예외로 받는다. 상태별 모양은 ApprovalBar. 설정에서 Windows Hello 확인을 켜면 누른 뒤 한 번 더 확인한다(ADR-020·021).
- 하지 말 것: 대화 카드 안의 승인 버튼(PC, ADR-021), 한 카드에 주요 버튼 두 개, "확인"·"다음" 같은 글자.
