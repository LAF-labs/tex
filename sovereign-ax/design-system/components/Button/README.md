# Button

행동 버튼이다. 주요 행동은 `ink`로 채우고, 파랑으로 채운 버튼은 비가역 승인에만 쓴다.

- 종류: 주요 `sx-btn sx-btn-primary`(카드마다 하나), 보조 `sx-btn`, 조용한 `sx-btn sx-btn-quiet`(중지, 닫기), 승인 `sx-btn sx-btn-approve sx-btn-lg`(승인 창·모바일 승인 시트에만).
- 글자는 동사로 끝낸다: "홈택스에서 준비", "다시 조회", "승인하고 발급".
- 승인 버튼은 Enter·Space로 누를 수 없게 구현한다(ADR-014). 마우스 클릭만 받는다.
- 하지 말 것: 대화 카드에 승인 버튼, 한 카드에 주요 버튼 두 개, "확인"·"다음" 같은 글자.
