소버린 AX 디자인 방향

Claude Design에 넘기기 전에 톤, 분위기, 디자인 토큰, 핵심 화면의 생김새를 정한다. 방향은 세 가지를 비교했고, 공공 서류와 도장이라는 이 분야의 재료에서 출발한 A안 "서류와 도장"을 권한다. 이 페이지도 A안의 색과 서체로 만들었다.

결정 (2026-10-30) A안의 구조(서류의 재료, 서식의 선, 승인 도장)를 따르되 강조색은 파랑 계열 하나로 바꾸고 색 사용을 최소화한다. 이 페이지의 인주 빨강은 검토 당시의 제안이다. 확정된 색·서체·데이터 위계는 소버린 AX 디자인 시스템이 기준이다.

1 · 누구를 위한 화면

불안한 일을 맡기는 사람에게 통제감을 주는 화면

첫 타깃은 경리 담당 없이 대표가 직접 서류를 챙기는 소규모 법인이다. 지원사업과 보증 신청 때마다 사업자등록증명, 납세증명서, 표준재무제표증명을 다시 뗀다(07 문서). 이 사람에게 홈택스는 팝업과 보안 프로그램이 많은 피곤한 곳이다. 인증서와 비밀번호를 프로그램에 맡기는 일 자체도 불안하다. 화면은 이 불안을 줄이는 쪽으로 설계한다. 화려함보다 "지금 무엇이 일어나고, 무엇이 내 승인을 기다리는지"가 한눈에 보여야 한다.

차분함무채색 화면, 넓은 여백, 움직임 최소. 알림과 강조는 사람이 할 일이 있을 때만 나온다.
정확함금액·사업자번호·승인번호가 세로로 맞는다. 숫자는 고정폭, 서식은 실제 서류처럼 표로 정리한다.
통제감승인은 내 도장이다. 승인이 필요한 곳과 승인한 기록만 빨간색이라 "내가 허락한 것"이 눈에 남는다.
회백색 종이먹색 글자인주 빨강서식의 가는 선고정폭 숫자조용한 비서

빨간색 규칙

  • 빨강은 "사용자의 도장"이다. 승인이 필요한 곳(내 차례, 승인 대기)과 승인한 기록(승인 도장)에만 쓴다.
  • 실패·오류는 빨강을 쓰지 않는다. 먹색 테두리 칩과 원인 문구로 보여 준다. 그래야 빨강을 보면 "내가 할 일"로만 읽힌다.
  • 한 화면에 빨강은 한 곳만 강하게 쓴다. 오늘 요약의 "확인 필요" 숫자와 해당 카드가 함께 빨개지는 정도까지 허용한다.
  • 로고, 일러스트, 장식에는 빨강을 쓰지 않는다.

왜 다르게 생겼나

대화 카드가 승인 창을 흉내 내지 못하게, 승인 창만 위쪽 인주 띠와 회색 제목줄을 쓴다. 앱 본체의 어떤 카드도 이 띠를 쓰지 않는다.

이 창은 앱이 고정 문구와 홈택스에서 되읽은 값만으로 만든다. 외부 서체·이미지를 불러올 수 없으므로 시스템 서체와 CSS만으로 완성되게 디자인한다(ADR-014).

"승인하고 발급"은 화면에서 유일하게 빨간 면으로 칠한 버튼이다. 작업 표시줄에만 뜨고 포커스를 빼앗지 않는다.

7 · Claude Design 요청문

A안으로 첫 화면을 만들 때 붙여 넣을 문장

방향이 정해지면 이 문장으로 PC 메인부터 시작한다. 화면 구성은 화면 기획 08 §5, 카드 순서는 08 §12를 함께 넘긴다.

자영업자·소규모 법인이 세금계산서와 홈택스 증명서 발급을 맡기는 Windows 데스크톱 에이전트 앱의 메인 화면을 디자인해 줘. 디자인 방향은 "서류와 도장"이다.

레이아웃: 왼쪽 60px 아이콘 레일(대화·문서함·거래처·내 사업장·활동 기록, 아래 설정), 가운데 단일 대화 타임라인(콘텐츠 최대 600px), 오른쪽 340px 작업 패널. 위에 44px 제목줄(회사 전환, 검색 Ctrl K, 금고 상태, 폰 연결).

색: 바탕 회백 #F5F5F2(크림 아님), 카드 흰색, 글자 먹색 #1A1C1E, 보조 #565B62, 선 1px #E2E2DC. 강조색은 인주 빨강 #C9372C 하나이고 "사용자의 승인이 필요하거나 승인한 곳"(내 차례, 승인 버튼, 승인 도장)에만 쓴다. 확인 필요·만료 임박은 황토 #9A6210, 완료는 솔잎 #2E6A4E. 오류에는 빨강을 쓰지 않는다. 다크 모드도 같은 이름으로 만든다.

서체: 본문 IBM Plex Sans KR, 사업자번호·승인번호는 IBM Plex Mono, 서류 이름에만 Noto Serif KR. 금액은 고정폭 숫자, 천 단위 쉼표, "원".

모양: 카드 모서리 10, 버튼·입력 8, 칩은 알약형. 구분은 1px 선으로 하고 그림자는 떠 있는 것에만. 아이콘은 1.5px 선.

첫 화면 상태: "A상사에 330만원 세금계산서 끊고 메일 보내 줘" 요청 → 금액 해석 선택 카드(합계 3,300,000원 선택됨) → 작업 카드 "내 차례: 카카오뱅크 앱에서 간편인증을 승인해 주세요". 작업 패널에는 확인 카드 값(공급자, 공급받는자, 공급가, 세액, 합계, 품목, 작성일자, 받는 이메일)과 실행 단계 6개(첫 단계가 현재). 입력창 위에 빠른 실행 칩 4개.

문구는 짧은 해요체. 이모지·마스코트·그라데이션·숫자 타일 대시보드는 쓰지 않는다. 앱 이름은 미정이라 로고 자리는 임시 표기로.
8 · 정할 것

Claude Design 전에 정할 네 가지

  • 방향: A안 "서류와 도장" (권장) · B안 · C안정해지면 이 토큰으로 디자인 시스템을 만들고 Claude Design에 넘긴다.
  • 서체: IBM Plex Sans KR (권장) · PretendardPlex는 서류다운 개성이 있고 Mono와 짝이 맞는다. Pretendard는 국내 앱에서 익숙하고 UI 가독성이 검증됐지만 흔하다. 둘 다 앱에 넣어 배포할 수 있는 라이선스(OFL)다.
  • 도장 모티프를 어디까지 쓸지권장은 승인 기록(승인 도장)과 승인 창의 인주 띠까지. 로고나 빈 화면 장식으로는 쓰지 않는다.
  • 기본 테마: 시스템 설정 따름 (권장) · 라이트 고정사무실 PC는 라이트가 대부분이라 라이트를 먼저 다듬고, 다크는 같은 토큰으로 맞춘다.
근거: 화면 기획 08, ADR-014(승인 창 제약), ADR-016(원격 승인), ADR-018(서류 범위), ADR-019(단일 메인 세션). 시안의 회사명·금액·번호는 모두 예시다.
