# 02. 제품 명세

## 1. 제품 구성 요소

| 구성 요소 | 형태 | 역할 |
|---|---|---|
| **로컬 하네스** | 데스크톱 앱 (Windows 우선, macOS 후속) | 작업 UI, 플레이북 실행, 로컬 금고, 데몬, 리모트 수신 |
| **모바일 앱** | iOS/Android | 리모트 지시·승인, 간편인증 PUSH 수신, 클라우드 조회 에이전트 UI |
| **클라우드** | 우리 서버 | 계정·구독, 모델 게이트웨이, 릴레이, E2EE 블롭 저장, 메타데이터 인덱스 |

## 2. 첫 실행 (온보딩)

1. 계정 가입(이메일) → 구독 선택 → 앱 설치.
2. **프로필 등록** (계정당 최대 2개: 개인 1 + 법인/개인사업자 1)
   - 개인: 간편인증(카카오·네이버·PASS 등, 정부24 간편인증은 주민번호 기반) 연결 또는 공동인증서(NPKI 폴더 자동 탐지) 선택.
   - 법인/개인사업자: 전자세금계산서용·사업자범용 공동인증서 선택, 또는 홈택스 사업자용 간편인증(카카오뱅크·IBK·KB, PUSH/QR/클라우드, 건별·수정·반복·복사 발급 가능) 등록 안내. **정부24는 사업자번호로 간편인증 로그인이 안 되므로 법인 서류는 공동·금융인증서 또는 법인 아이디가 필요**함을 안내. 선택적으로 보안카드 등록(홈택스 온라인 신청 후 지정 세무서 수령).
   - 인증서 비밀번호 저장 여부를 **명시적으로** 묻는다. 저장 시 OS 키체인(Windows DPAPI/Credential Manager, macOS Keychain). 저장하지 않으면 작업 때마다 로컬에서 입력.
3. **내 사업자 정보 입력**: 상호·사업자번호·대표자·업태·종목·주소·이메일. 로컬에만 저장. 홈택스 로그인 후 자동 채움 제공.
4. **서류 보관함 위치** 지정(기본: 사용자 문서 폴더 아래) + 클라우드 백업 ON/OFF.
5. 첫 작업 추천: "거래처 1곳 등록하고 세금계산서 1건 발급해 보기".

## 3. 홈 화면

```
┌──────────────────────────────────────────────────────────┐
│ [개인 ▾] [㈜우리회사 ▾]                 ● 로컬 금고 잠김/열림 │
├──────────────────────────────────────────────────────────┤
│ 자주 쓰는 작업                                              │
│  ⚡ 세금계산서 발급     ⚡ 등본 발급     ⚡ 납세증명(국세)      │
│  ⚡ 지방세 납세증명     ⚡ 건강보험 자격득실                   │
├──────────────────────────────────────────────────────────┤
│ 홈택스                         │ 정부24 · 기타 포털         │
│  · 전자세금계산서 발급         │  · 주민등록 등·초본          │
│  · 발급분 조회/다운로드        │  · 토지·건축물대장           │
│  · 사업자등록증명              │  · 지방세 납세증명           │
│  · 납세증명서(국세)            │  · 건강보험 자격득실확인서    │
│  · 거래처 사업자 상태 확인     │  · 중소기업확인서(SMINFO)    │
├──────────────────────────────────────────────────────────┤
│ 만료 임박  ⚠ 중소기업확인서 D-12  ⚠ 지방세 납세증명 D-3       │
│ 최근 작업  ✓ 10/26 세금계산서 → ㈜거래처 (3,300,000원) 이메일 전송 │
└──────────────────────────────────────────────────────────┘
│ 💬 "거래처 A에 330만원 세금계산서 끊고 메일 보내줘"            │
```

- 상단 프로필 스위치로 개인/법인 전환. 작업 카드는 선택된 프로필에 맞는 것만 활성.
- 하단 대화창은 **의도 → 플레이북 매핑**용. 자유 문장을 받아 플레이북과 인자를 채운 뒤 **확인 카드**를 띄운다. 모델은 여기서만 개입하고 실행은 플레이북이 한다.

## 4. 핵심 흐름 A — 전자세금계산서 발급 + 이메일

입력: 거래처(사업자번호 또는 저장된 거래처), 공급가액(또는 합계), 품목, 작성일자, 이메일(저장값 자동).

1. 사용자가 거래처 사업자등록증 이미지를 끌어다 놓거나 사업자번호 입력 → **로컬 OCR/텍스트 추출**로 번호·상호·대표자·주소 후보 생성 → 국세청 사업자등록정보 진위확인 API(공공데이터포털, 서비스 키 필요: 기본은 우리 게이트웨이 프록시, 설정에서 자기 키 사용)로 상태 확인.
2. 금액 입력: "330만원"처럼 쓰면 공급가액 3,000,000 / 세액 300,000 분리 제안. 영세·면세 여부 선택.
3. **확인 카드**: 공급자·공급받는자·금액·품목·이메일을 한 화면에. 여기서 사용자가 "발급" 누르기 전까지 어떤 외부 전송도 없다.
4. 플레이북 실행: 홈택스 로그인(공동인증서 로컬 서명 또는 간편인증 PUSH → 폰 승인) → 건별발급 화면 → 항목 입력 → 발급(전자서명/보안카드 입력 프롬프트는 로컬 또는 폰에서) → 승인번호 획득.
5. 후처리: 발급분 PDF 저장 → 보관함에 `세금계산서/2026/10/㈜거래처_20261027_승인번호.pdf` → 이메일 전송(홈택스 자체 전송 기능 사용, 또는 사용자 메일 계정 로컬 연동) → 거래처 장부(로컬)에 기록.
6. 결과 카드 + 감사 로그 한 줄: "어떤 값이 어디로 갔는지".

예외 처리: 셀렉터 실패·팝업·세션 만료 시 플레이북이 체크포인트로 복귀 → 3회 실패 시 모델에게 **마스킹된 접근성 트리**를 주고 복구 시도 → 그래도 실패하면 사용자에게 화면 핸드오프.

## 5. 핵심 흐름 B — 민원서류 발급 (정부24)

1. 서류 선택 + 옵션(등본의 경우 세대원 포함 여부, 주민번호 뒷자리 표시 여부 등은 **기본 최소 노출**).
2. 로그인(간편인증 PUSH 또는 공동인증서).
3. 신청 → 발급 → **출력 단계**: 정부24 공식 안내는 상충한다(2021-09 공지·등본 FAQ는 가상 프린터·파일 저장 불가, 2023-12 공지는 Microsoft Print to PDF를 정상 방법으로 안내). 서류별로 S3에서 실측하고, 우선순위는 원본 PDF(다운로드·전자문서지갑) → `--kiosk-printing`+Save as PDF → 헤드풀 `page.pdf()` → Microsoft Print to PDF → 사용자 핸드오프. 전자문서지갑은 모바일 앱 중심이라 폰 연동과 묶어 Phase 2에서 설계. 허락 전 후처리 모드에서는 사용자가 출력하고 하네스는 저장 파일을 감지한다.
4. 저장 파일에서 로컬 텍스트 추출 → 발급일·유효기간 메타데이터 생성 → 보관함 + (옵션) E2EE 백업.
5. 사용처 전달: "메일로 보내기", "폴더 열기", "폰으로 보내기(E2EE)".

## 6. 서류 데몬 (주기적 최신화)

- 서류별 **유효기간 규칙표**(예: 납세증명 30일, 중소기업확인서 발급 기준 1년, 건강보험 자격득실 통상 제출처 기준 1~3개월)를 내장하고 사용자가 조정.
- 두 가지 모드:
  - **알림 모드(스타터)**: 만료 D-7, D-1에 데스크톱·모바일 알림. 사용자가 "지금 갱신" 탭.
  - **자동 모드(비즈니스)**: 사전 동의한 서류는 무인 갱신. 무인 갱신은 **공동인증서 + 저장된 비밀번호**가 있을 때만 가능. 간편인증만 등록된 프로필은 폰 PUSH 승인을 요청하는 반자동으로 동작.
- 실행 창: 사용자가 정한 시간대(예: 평일 09:00~18:00), PC가 켜져 있고 유휴일 때. 꺼져 있어 놓친 작업은 모바일로 알린다.
- 데몬은 절대 '새 종류의 작업'을 만들지 않는다. 사용자가 명시 등록한 서류만 갱신.

## 7. 모바일 리모트 컨트롤 (PC 켜짐)

- 페어링: 데스크톱에 QR 표시 → 모바일 스캔 → 기기 간 키 교환(E2E). 릴레이 서버는 암호문만 중계.
- 모바일 화면: 자주 쓰는 작업 + 대화창. "거래처 B에 55만원 세금계산서" → 로컬 하네스가 플레이북 준비 → **확인 카드가 폰에 뜸** → 승인 → 실행 → 간편인증 PUSH(홈택스 앱) 승인 → 완료 알림 + PDF 미리보기(E2EE 전송).
- 보안카드·인증서 비밀번호가 필요한 단계: 폰에서 입력 → E2E 채널로 로컬에 전달 → 메모리에서만 사용 → 즉시 폐기. 릴레이·서버는 평문을 볼 수 없다.
- 로컬 하네스는 리모트 명령을 **같은 플레이북 화이트리스트**로만 받는다. 임의 브라우저 조작 명령은 받지 않는다.

## 8. 클라우드 조회 에이전트 (PC 꺼짐)

- 서버에는 **메타데이터 인덱스**만 평문: 서류 종류, 발급일, 만료일, 파일 해시, 프로필 종류(개인/법인), 크기. 상호·사업자번호·주민번호·금액은 없음.
- 답할 수 있는 질문: "지난달 납세증명 받았어?", "중소기업확인서 언제 만료돼?", "10월 세금계산서 몇 건 발급했지?"(건수·날짜만).
- 본문이 필요한 질문("그 등본 보여줘"): 모바일 앱이 E2EE 블롭을 내려받아 **폰에서 복호화**해 보여준다. 모델에게 본문을 보내야 하는 요약 요청은 사용자가 그 자리에서 허용할 때만, 마스킹 후 전송.
- 발급 자체는 불가(PC가 꺼져 있으므로). "PC 켜지면 실행" 예약은 가능.

## 9. 신원·프로필 모델

```
계정(이메일, 구독)
 ├─ 프로필 A: 개인      — 인증수단: 간편인증 | 공동인증서(개인)   — 작업: 정부24, 홈택스(개인)
 └─ 프로필 B: 법인/개인사업자 — 인증수단: 사업자용 공동인증서 | 사업자 간편인증 | 보안카드 — 작업: 홈택스(사업자), SMINFO, 정부24(법인)
```

- 서버는 "프로필 A 존재, 종류 개인" 수준만 안다. 인증수단 종류조차 서버에 보낼 필요 없음.
- 계정당 2개 초과 등록 불가(기획 요구). 세무사·경리대행이 다수 고객을 한 계정에 묶는 **대리 사용을 구조적으로 차단**하는 장치이기도 하다.

## 11. 감사 로그와 투명성 화면

- 모든 작업: 시각, 프로필, 플레이북 버전, 접속 포털, 입력값 요약, 결과, **모델 호출 여부와 전송된 바이트 수(마스킹 후)**.
- "우리 서버에 있는 내 데이터" 페이지: 서버가 보유한 레코드를 그대로 보여주고 내보내기·삭제.
- 모델 전송 미리보기: 예외 복구 때 모델로 나가는 마스킹된 내용을 사용자가 열어볼 수 있다(기본 접힘).

## 12. 하지 않는 것 (제품 규칙)

- 세액·공제 계산, 신고서 작성, 세무 상담 답변.
- 사용자 승인 없는 발급·전송·결제.
- 서버 측 브라우저 자동화.
- 다수 고객 대행용 멀티 테넌트 계정.
- 캡차 자동 해독, 지문 위조, 흔적 삭제, 비정상 속도의 반복 요청. 캡차는 사용자가 데스크톱 또는 폰에서 직접 푼다.

## 13. 포털별 운영 수준과 후처리 모드

운영기관의 허락 상태에 따라 포털별로 `postprocess`(후처리) / `assisted`(보조) / `auto`(자동) 수준이 서명된 운영 정책으로 배포된다(접근 허용·봇탐지 문서 §7). 정부24는 사전 허락 회신 전 후처리 모드가 기본이다.

후처리 모드의 사용자 경험:
1. 작업 카드를 누르면 하네스가 사용자 Chrome에 정부24 페이지를 열고 옆에 단계 안내 패널을 띄운다(로그인 → 메뉴 → 입력값 → 발급 → 출력).
2. 사용자가 직접 로그인·입력·발급·출력(PDF 저장)한다. 패널의 '복사' 버튼으로 사업자번호·주소 등을 붙여넣을 수 있다.
3. 저장된 PDF가 감지되면 하네스가 보관함으로 옮기고 메타데이터(발급일·유효기간)를 추출해 만료 추적·백업·알림에 올린다.
4. 감사 로그에는 '후처리 모드 실행'으로 기록된다.

홈택스 이중로그인: 실행 전 "다른 기기에서 홈택스에 로그인하면 작업이 중단됩니다" 안내, 세션이 끊기면 재개 여부를 묻는다.

## 14. 전자세금계산서 기한 알림 (Phase 2 후보)

발급기한은 공급시기(월합계는 다음 달 10일), 전송기한은 발급 다음 날이다. 가산세는 미발급 2%, 지연발급 1%, 지연전송 0.3%, 미전송 0.5%, 종이발급 1%. 세무 상담이 아니라 **기한 캘린더**로서 "이번 달 발급 미완료 거래처"와 D-day 알림을 제공한다. 세액·공제 판단은 하지 않는다.
