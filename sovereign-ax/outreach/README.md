## 이 초안에서 지킨 원칙

- 하지 않는 기술을 한다고 쓰지 않고, 하는 일을 숨기지 않는다. 보안카드 자동 입력, 아이디 자동 로그인, 자동화 표식 노출, 파이프 제어, 마스킹된 화면 텍스트의 해외 모델 전송, 진위확인 프록시, 데몬 시작 시각 분산, 캡차 폰 중계, PoC 진행을 모두 적었다([06 §2](06-design-crosscheck.md#2-하는-일과-하지-않는-일-공개-점검)).
- 기능은 단계를 붙여 쓴다. **PoC**(2026-10-29~11-26, 진행 중), **1단계**(MVP, Windows, 베타), **2단계**(모바일·데몬·백업, 예정). 예정 기능을 지금 하는 것처럼 쓰지 않는다.
- 수치는 D03 §7 정책 초안 값이고 "현재 기준"으로 적는다. S8 등 검증과 운영기관 요청에 따라 보수 쪽으로 조정할 수 있다.
- '사람 수준', '자동화 플래그 미사용' 같은 표현을 쓰지 않는다(D03 §7·§10). 스텝 간 지연은 '요청률 상한'이다.
- 법적 판단을 단정하지 않는다. 우리 이해는 "확인을 요청하는 이해"로만 적는다(D11 §6).
