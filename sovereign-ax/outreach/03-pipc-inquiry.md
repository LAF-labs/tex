# 질의 3. 개인정보보호위원회: 본인전송요구권 '대리인' 해당성

**제목**: 사용자 PC에서 사용자가 직접 실행하는 로컬 자동화 도구의 배포자가 개인정보 보호법령상 '대리인'에 해당하는지 질의

**질의인**: {{회사명}} (사업자등록번호 {{사업자등록번호}}), 담당 {{성명·직위}}, {{전화}}, {{이메일}}

## 1. 질의 요지

사용자가 자기 PC에서 직접 실행하는 로컬 자동화 도구가 있습니다. 이 도구의 배포자는 사용자의 인증정보를 넘겨받지 않고, 포털에서 조회·발급한 결과의 원문도 배포자 서버로 받지 않습니다. 다만 식별 정보를 지운 화면 텍스트 일부는 인공지능 판정을 위해 배포자의 게이트웨이를 거칩니다(3항).

이 도구를 배포하는 당사가 개인정보 보호법 제35조의2(개인정보의 전송 요구)와 같은 법 시행령(2026. 2. 19. 개정, 공공 분야 2026. 8. 20. 시행)에서 말하는 '대리인'(법 제38조 제1항, 시행령 제45조)에 해당하는지 여쭙습니다. 특히 자동화된 도구를 이용해 전송을 요구하는 대리인(시행령 제42조의6 제3항 제1호 나목 [조문 확인])에 해당하는지, 그리고 그 판단 기준을 여쭙습니다. 해당한다면 공공기관과의 사전협의 절차를, 해당하지 않는다면 그 취지의 서면 회신을 요청드립니다.

## 2. 도구의 구조

가. **무엇을 하는가**: 사업자가 자기 명의로 홈택스 전자세금계산서와 민원증명을 발급하고, 발급한 서류를 자기 PC에 보관하며 만료일을 알림받도록 돕는 데스크톱 프로그램입니다(가칭 「소버린 AX」, 개발 중, 출시 전).

나. **누가 접속하는가**: 사용자 PC에 설치된 사용자의 Chrome 브라우저가 사용자 PC의 인터넷 주소(IP)에서 접속합니다. 당사 서버는 홈택스·정부24·위택스에 접속하지 않습니다(공공데이터포털 진위확인 API 호출은 3항). 앞으로 다른 공공 포털(인터넷등기소, 중소기업현황정보시스템, 4대사회보험 포털 등)을 더할 때도 같은 구조를 쓰며, 해당 운영기관에 따로 알립니다.

다. **인증**: 사용자 본인의 인증수단(사업자용 간편인증, 공동·금융인증서, 홈택스 보안카드)으로 사용자가 로그인합니다.
- 간편인증은 사용자가 휴대폰에서 승인합니다.
- 인증서 비밀번호는 사용자가 화면에 직접 입력합니다.
- 보안카드를 고른 사용자는 홈택스 아이디·비밀번호와 보안카드 번호를 자기 PC 안에 암호화해 저장할 수 있고, 프로그램이 이를 입력합니다.
- 인증정보는 인공지능 모델로 보내지 않고, 당사가 볼 수 있는 형태로 당사 서버에 보내지 않습니다. 2단계의 휴대폰 원격 기능에서 사용자가 휴대폰에 입력한 보안카드 번호·비밀번호는 PC만 열 수 있는 종단간 암호문으로 당사 중계 서버를 거칩니다.

라. **결과는 어디에 있는가**: 포털 화면에서 얻은 정보와 발급 서류(PDF)는 사용자 PC에 저장합니다. 당사 서버가 받거나 거쳐 가는 항목은 아래 3항에 모두 적었습니다.

마. **정부24·위택스**: 정부24 이용약관 제14조 제4항 제9호와 위택스 이용약관 제17조 제2항에 따라, 행정안전부의 사전 허락을 받기 전에는 자동화하지 않습니다. 그동안 사용자는 기본 브라우저에서 직접 발급하고, 프로그램은 사용자가 저장해 고른 파일만 정리합니다. 사전 허락은 행정안전부에 요청하고, 홈택스 이용 방식은 국세청에 따로 알리고 질의합니다.

바. **누구를 위한 것인가**: 사용자는 자기 명의의 업무만 처리합니다. 계정 하나에 프로필은 2개(개인 하나, 사업자 하나)까지입니다. 여러 고객의 업무를 한 계정에 묶어 대신 처리하는 대리 사용은 출시 때 이용약관에 금지 조항을 둘 예정입니다. 당사는 고객의 업무 데이터를 서버에 모아 분석하거나 판매하지 않습니다.

## 4. 질의 사항

가. 위 구조의 도구를 배포하는 당사가 개인정보 보호법 제35조의2와 같은 법 시행령 제42조의6 제3항 제1호 나목 [조문 확인]에서 말하는, 자동화된 도구를 이용하는 '대리인'에 해당합니까? 해당 여부를 판단하는 기준(예: 인증정보를 넘겨받는지, 정보가 배포자 서버를 거치는지, 도구를 누가 실행하는지)도 함께 알려 주십시오.

나. 해당한다면 사전협의를 해야 하는 공공기관(국세청, 행정안전부(정부24·위택스) 등)과 그 절차, 협의에서 정해야 할 항목(전송 항목 범위, 위임 확인 방식, 자동화 도구의 접근 방식과 인증 수준, 보호조치)을 알려 주십시오. 국세청과 위택스는 개인정보처리방침에서 대리인의 사전협의 창구를 안내하고 있습니다.

다. 해당하지 않는다면 그 취지의 서면 회신을 주실 수 있습니까? 당사는 이 회신을 공공기관에 보내는 공문과 개인정보 처리방침에 인용하려고 합니다.

라. 아래 요소 가운데 '대리인' 판단을 바꾸는 것이 있다면 알려 주십시오.
   1) 화면 상태 판정과 복구, 서류 날짜 확인, (2단계) 서류 요약을 위해 식별 정보를 지운 화면·서류 텍스트를 해외 인공지능 모델 공급사로 보내는 것
   2) 거래처 사업자번호가 진위확인을 위해 당사 프록시를 거쳐 가는 것(저장하지 않음)
   3) 사용자가 켠 경우 서류를 암호문으로만 백업하는 것(당사는 열 수 없음, 2단계)
   4) 사용자가 켠 경우 서류의 종류·발급 월·만료일과, PC를 두 대 이상 연결한 경우의 발급 활동 표시를 보관하는 것(2단계)
   5) 사용자가 휴대폰에서 발급을 승인하면 사용자 PC가 발급하는 것, 그 과정에서 휴대폰에 입력한 비밀 값이 종단간 암호문으로 당사 중계 서버를 거치는 것(2단계)
   6) 사용자가 자기 PC에 홈택스 아이디·비밀번호와 보안카드 번호를 저장하고 프로그램이 이를 입력하는 것
   7) 당사가 이 도구를 유료 구독으로 제공하는 것

마. 법인 명의 서류(법인 사업자의 사업자등록증명 등)와 개인사업자·개인 명의 서류를 다르게 보아야 하는지 알려 주십시오.

## 5. 당사의 이해(확인을 요청드리는 것이며, 단정하지 않습니다)

당사는 사용자가 자기 기기에서 직접 실행하고 당사가 인증정보를 넘겨받지 않는 구조이므로, 당사가 '대리인'에 해당하지 않을 수 있다고 이해하고 있습니다. 또한 대리인에 해당하더라도, 대리인은 전송받은 정보를 자체 서버에 저장하지 않고 본인에게 전달해야 한다는 요건과 당사 구조가 같은 방향이라고 봅니다. 다만 위 4항 라.의 요소들이 있어 판단을 받고자 합니다. 해당한다는 회신을 받으면 안내에 따라 사전협의를 신청하겠습니다.

- 화면 텍스트 "최대 30일"과 처리 국가는 D11 §6(ZDR 승인 전, 공급사 고지 기준)이다. 공급사가 바뀌면(ADR-015) 고친다.
- 서류 날짜 후보 문맥(±40자, 최대 8개)은 D04 §3 `doc_meta_check_v1`이다. 금액 원값은 `amount_parse_check_v1`에만 간다(D04 §3).
- 발급 활동 표시는 D03 §4·D09 §6이다(Phase 2, 데스크톱 2대 이상·'백업(메타데이터 동기화)' 스위치를 켠 계정만, ADR-024). 1단계 경고는 발급 직전 홈택스 발급목록 기준선(D02 §4.4, `$dup.portalExisting`)으로 하며 서버로 가는 것이 없다. 서류 메타 색인 기본값은 D07 §3 표다.
- 진위확인 대표자 성명·개업일자는 공공데이터포털 `/validate` API의 입력 항목이다(D09 §4.1). 상태조회(`/status`)만 쓰면 사업자번호만 간다. 어느 쪽을 쓰는지 구현 때 확정한다.
- 시행령 조문(제42조의6 제3항 제1호 나목 등)은 리서치 서브에이전트의 조회 결과다. 발송 전에 국가법령정보센터 원문과 대조한다([06 §5](06-design-crosscheck.md#5-조문-확인-상태)).
