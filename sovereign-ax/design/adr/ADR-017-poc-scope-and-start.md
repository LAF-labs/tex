# ADR-017. PoC 범위와 착수 결정 — 공문 회신 없이 홈택스 범위로 4주 PoC

> 상태: 채택(2026-10-28) · 관련: ADR-011, ADR-015, D14 §0, 04 §1, 06 Q17

## 맥락

- 1개월 안에 PoC로 수요검증과 기술 검증을 끝내야 한다. 운영기관 공문(국세청 통지, 정부24 사전 허락 요청)은 발송 예정이지만 회신 시점을 알 수 없다.
- 홈택스 이용 규정(열람본)에는 자동화 금지 명문이 없다. 정부24 이용약관 제14조④9호는 사전 허락 없는 자동화 로그인을 금지하고 제재는 1·3개월·영구 정지다. 개인정보보호법 시행령의 '대리인' 해당성은 개인정보위 질의 중이다.
- 테스트 전용 법인 설립과 인증수단 조달은 리드타임이 길어 1개월 PoC에 맞지 않는다.

## 결정

1. **착수 조건에서 공문 회신을 뺀다.** 홈택스 작업은 본인 IP·본인 인증수단·요청률 상한·차단 신호 즉시 중단 조건으로 진행한다. 공문은 통지·질의이며 허가 신청이 아니다.
2. **정부24는 "무응답 = 허락"으로 보지 않는다.** PoC에서 정부24 기능(G-01~03, S3)을 제외한다. 허락 회신 전 금지 규칙(ADR-011, 보드 프로젝트 규칙)은 그대로다. 수요검증에서 정부24 자동 버전은 목업 화면으로만 보여 준다.
3. **PoC 범위(4주, 2026-10-29~11-26)**: 사업자 계정(프로필) 저장, 거래처 저장, 전자세금계산서 발행 + 이메일 전송(H-01), 홈택스 민원증명 발급(H-04 납세증명·사업자등록증명). 리모트·백업·데몬·비밀 옵트인 저장·외부 사용자 베타는 제외한다. 작업분해는 D14 §0(PoC-1~12).
4. **PoC 코드는 폐기 전제**(스파이크 코드와 같은 지위)이되, 금고 경계(비밀은 엔진 프로세스 밖)·커밋 게이트·원장은 설계대로 처음부터 넣는다. 이 셋은 나중에 끼워 넣는 비용이 가장 크다.
5. **테스트 계정**: 테스트 전용 법인 대신 관계사 법인 1곳을 PoC 전용으로 지정하고, 그 계정의 정지 위험을 대표가 수용한다(기록). 실발급은 관계사 간 실거래 소액 2~3건만, 인증서 비밀번호는 저장하지 않고 매번 입력한다. 법률 질의 5건은 발송하되 회신을 기다리지 않는다.
6. **수요검증**은 데모·인터뷰 20건·랜딩으로 한다. 외부 사용자가 본인 인증서로 직접 돌리는 베타는 처리방침·동의가 갖춰지는 Phase 1 이후다.
7. **G0는 2026-10-28 판정**, G1은 PoC-12(11-27)에서 판정한다. 06 §5 Go 조건 중 S3 수동 실측은 G1 조건에서 빼고 Phase 1 정부24 후처리 착수 전 조건으로 옮긴다.

## 대안과 기각 이유

| 대안 | 기각 이유 |
|---|---|
| 공문 회신까지 착수 보류 | 회신 시점을 통제할 수 없고 1개월 PoC가 불가능 |
| 무응답을 정부24 허락으로 간주하고 자동화 | 약관 위반 상태로 사용자 계정 정지 위험. 허락은 명시적이어야 한다 |
| 테스트 전용 법인을 기다림 | 리드타임이 PoC 기간을 넘는다 |
| 외부 베타로 수요검증 | 개인정보 고지·동의·처리방침이 선행되어야 해 1개월 안에 불가 |

## 결과

- D14 §0 PoC WBS, 04 §1 게이트 일정, 06 Q17, 아티보드 PoC-1~12 태스크.
- Phase 0 스파이크 표(D14 §1, 04 Phase 0)는 PoC 태스크에 흡수되고 측정 항목 참조용으로 남는다.
- 잔여 위험: 관계사 계정 정지, 법률 회신이 PoC 결과와 어긋날 가능성(테스트 발급 적법성), 정부24 가치 검증이 목업에 의존.

## 조건

- 정부24 허락 회신이 PoC 기간 중 오면 Phase 1 범위에 G-01~03 `assisted`/`auto`를 되돌린다.
- 홈택스에서 차단·제재 신호가 1회라도 오면 PoC를 중단하고 운영기관에 연락한다(05 문서).

## 개정 메모 (2026-11-02)

- 결정 5의 "법률 질의 5건"은 EX-1 스레드(10-31)와 ADR-020 결정 2에 따라 **6건**이 됐다. Q6 보안카드 번호와 홈택스 아이디·비밀번호의 저장·자동 입력을 더했고, Q4 '인증서 비밀번호 저장'은 '공동·금융인증서 비밀번호 사용자 직접 입력 구조의 적법성'으로 바꿨다(outreach/04).
- 결정 3의 "H-04 납세증명·사업자등록증명"은 서류 두 종을 뜻한다. 플레이북 ID로는 H-04 납세증명서와 H-03 사업자등록증명이다(02 §10, ADR-018 결정 2).
