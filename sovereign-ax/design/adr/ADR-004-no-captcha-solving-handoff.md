# ADR-004 캡차 자동 해독 금지, 10초 핸드오프

상태: 채택 · 2026-10-28

## 맥락
캡차·추가 인증은 포털이 "사람인가"를 묻는 지점이다. 우리는 운영기관에 자동화 접근 허용 공문을 보내고, 탐지 신호를 만들지 않으며, 위조·은폐를 하지 않기로 했다. 동시에 캡차가 떠도 작업이 멈추지 않아야 한다.

## 결정
- 캡차는 **사람이 푼다**. 엔진은 `human(kind=captcha)` 스텝으로 데스크톱 전면 또는 폰(E2E)으로 10초 안에 넘기고, 입력 후 그 자리에서 이어간다.
- 모델로 캡차를 해독하는 코드 경로는 만들지 않는다. 캡차 이미지는 모델 입력 타입에서 제외된다(마스킹 계층이 거부).
- 캡차 빈도는 운영 지표로 추적하고, 치솟으면 운영 정책을 자동 보수화한다.

## 대안
- 비전 모델로 자동 해독: 기술적으로 가능하나 공문의 약속과 정면 충돌하고 '우회 사업자'로 분류될 근거를 준다. 기각.
- 캡차가 뜨면 무조건 중단: 작업이 끊겨 가치가 떨어진다. 기각.

## 결과
- 리모트 시나리오에서 폰 캡차 UI가 필수 기능이 된다.
- 운영기관 회신에 따라 캡차 면제·식별자 등록이 가능하면 그 절차를 따른다.
