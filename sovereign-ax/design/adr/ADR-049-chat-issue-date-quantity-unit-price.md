# ADR-049. 대화로 작성일자 정하기(소급·월합계)와 수량×단가

> 상태: 제안(2026-11-17, yulmu 결정 카드 "작성일자·수량×단가부터") · 1단계(대화·카드·엔진 입력) 구현 예정 · 2단계(홈택스 칸 채우기)는 실화면 확인 뒤
> 근거: 02 §4 흐름 A 입력("작성일자" 포함), 08 §6 승인 카드 정밀도(작성일자는 늘 보임, ADR-021 결정 7), D-20(N-26), ADR-027, R14 I-1(기한 경과는 막지 않고 경고), 02 §14(기한 표시는 법률 의견 대상)
> 관련: `@sax/chat-core` `CHAT_AGENT_TOOLS`(PC·폰 대화가 같은 표), `packages/engine/src/runs.ts` `draft()`, H-01 패키지 `hometax.invoice.issue` 2.3.8, PR #394(대화 에이전트 실모델 평가)

## 맥락

- 대화로 만드는 카드는 작성일자가 늘 오늘(KST)이다. 엔진 `draft()`가 `issueDate = kstDay(now)`로 정하고, H-01 패키지는 홈택스 작성일자 칸을 채우지 않는다(포털 기본값이 오늘). `s19e`가 되읽은 작성일자를 `$inputs.issueDate`와 대조한다(N-26).
- 그래서 사장님이 자주 하는 두 가지를 대화로 못 한다.
  - "지난달 납품분 이번에 끊어 줘", "10월 거 월합계로": 작성일자를 지난 날로 둬야 한다. 월합계는 한 달 공급분을 그달 말일(또는 그 기간 안의 날)을 작성일자로 묶어 다음 달 10일까지 발급한다(법 §34③, 02 §14).
  - "원두 10kg에 kg당 12,000원": 사장님은 공급가액이 아니라 수량과 단가로 말한다. 지금은 모델이 곱하거나 사장님이 계산해서 다시 말해야 한다. 모델은 산수를 하지 않는다는 규칙(chat-core 슬롯 규칙, real-run-2)과 맞지 않는다.
- 수량·단가는 세금계산서 필요적 기재사항이 아니다(부가세법 §32①: 공급자 등록번호·성명, 공급받는자 등록번호, 공급가액·세액, 작성 연월일). 비워 두고 공급가액만 넣어도 발급된다.
- 홈택스 작성일자 칸과 품목 행의 수량·단가 칸 선택자는 H-01 패키지에 없다. 실화면에서 확인하지 않은 id를 짐작해 넣지 않는다(작업 노트 1.1).
- 대화 도구 표는 PC와 폰이 같이 쓴다(ADR-047 결정 4). 도구 인자를 바꾸면 폰 대화(`chat_phone`)도 같이 바뀐다.

## 결정(제안)

### 1. 도구 인자: 모델은 날짜·곱을 계산하지 않고 말한 그대로 넘긴다

`invoice_draft`와 `draft_edit`에 인자 셋을 더한다(모두 nullable, 없으면 지금과 같다).

| 인자 | 모양 | 뜻 |
|---|---|---|
| `date` | `{month_offset: 0 \| -1, day: 1~31 \| "last"} \| null` | 작성일자. 이번 달 0, 지난달 -1. "말일"·"월합계"는 `"last"`. 오늘이면 null |
| `quantity` | 문자열(숫자) \| null | 수량. 정수만 1단계에서 받는다 |
| `unit_price` | 문자열(금액 토큰 `[AMT_n]` 또는 숫자) \| null | 단가(공급가 기준) |

- 머리말(`chat_agent.ko.txt`, `chat_phone`)에 규칙을 넣는다: 날짜는 `오늘:` 줄을 보고 month_offset·day로만 쓴다(연월일을 직접 쓰지 않는다), 수량과 단가를 말하면 `amount`는 null로 두고 둘을 넘긴다.
- 기기(PC main·폰)가 값을 만든다. 날짜는 KST 오늘에서 계산하고, 공급가액은 `수량 × 단가`(정수 곱, 1e15 상한)로 계산한다. `amount`와 수량·단가가 같이 오면 곱이 `amount`와 같을 때만 받고 다르면 금액을 되묻는다(`ask: amount`).
- 부가세 규칙은 그대로다. 단가는 공급가 기준이다. "부가세 포함 단가"라고 하면 합계 기준으로 계산하고 `vat: included`로 둔다.

### 2. 작성일자 허용 범위(기기 규칙, 모델 아님)

| 작성일자 | 처리 |
|---|---|
| 오늘 | 지금과 같다 |
| 이번 달 지난 날 | 받는다 |
| 지난달(오늘이 1~10일) | 받는다. 월합계의 보통 경우 |
| 지난달(오늘이 11일 이후) 또는 그 전 | 받되 카드에 한 줄: "국세청 안내 발급기한(공급한 달 다음 달 10일)이 지났어요. 가산세가 붙는지는 세무사에게 확인해 보세요." (R14 I-1과 같은 원칙: 막지 않고 경고, 가산세율·금액은 보이지 않는다) |
| 미래 | 받지 않는다. "작성일자는 오늘이나 지난 날로만 정할 수 있어요." |
| 없는 날(2월 30일 등) | 받지 않고 날짜를 되묻는다(새 되묻기 칸 `date`) |

- 지난 확정신고기한을 넘긴 날(지난 과세기간)은 2단계 실화면 확인 전까지 받지 않는다. 홈택스가 막는지, 막는다면 어떤 문구인지 모른다.

### 3. 카드·승인

- 작성 카드에 작성일자를 늘 보인다(08 §6). 오늘이 아니면 "작성일 10월 31일"처럼 강조한다.
- 수량·단가가 있으면 금액 줄 아래에 "10개 × 12,000원"을 보인다. 공급가액은 기기가 계산한 값이다.
- 승인 대조 값(`draftKey`)에 작성일자는 이미 들어 있다. 수량·단가는 2단계에서 홈택스에 넣을 때 대조 값에 더한다. 1단계에서는 홈택스에 넣지 않으므로 대조하지 않는다.
- 작성일자를 정한 카드는 다시 게이트 경고 `date_changed`(준비한 날과 오늘이 다름)를 쓰지 않는다. 그 대신 승인 시각에 2절 표를 다시 적용한다(자정을 넘겨 기한이 지났으면 경고 줄을 붙여 새로 승인).

### 4. 엔진 입력

- `start`·`prepareIssue`에 `issueDate`(YYYY-MM-DD, 선택)와 `items[0].quantity`·`unitPrice`(선택)를 받는다. 엔진도 2절의 미래·없는 날 규칙을 다시 검사한다(`bad_issue_date`).
- 발급 키(같은 건 판단)와 중복 경고에 작성일자가 들어간다. 같은 거래처·금액이라도 작성일자가 다르면 다른 건이다.
- `s19e`(되읽은 작성일자 = `$inputs.issueDate`)는 그대로 둔다. 2단계 전에는 홈택스가 오늘을 보이므로, 오늘이 아닌 작성일자는 게이트 전에 `assert.issue_date_mismatch`로 멈춘다. 그래서 1단계에서는 오늘이 아닌 작성일자 카드를 만들되 [홈택스에서 준비]를 막고 "지난 날짜 발급은 곧 열려요"를 보인다(설정 값 하나로 2단계에서 연다). 발급되지 않는 길로 멈추게 두지 않는다.

### 5. 2단계: 홈택스 칸 채우기(맥북 실화면)

- 로그인한 실화면에서 발급 버튼을 누르지 않고 칸만 채워 본다. 확인할 것: 작성일자 칸 id·입력 방식(달력 위젯인지, 바꾸면 품목 행의 월·일이 따라 바뀌는지), 품목 행 수량·단가 칸 id, 수량·단가를 넣으면 홈택스가 공급가액을 다시 계산하는지(반올림), 지난 과세기간·미래 날짜에 홈택스가 보이는 문구.
- H-01 패키지 2.4.0: `form.issueDate` 채우기(오늘이면 건드리지 않음), `item1.month`·`item1.day`, `item1.qty`·`item1.unitPrice` 채우기와 되읽기, 미리보기 대조. 패키지 서명·게시는 기존 절차(ADR-028)를 따른다.
- 패키지가 작성일자 채우기를 지원하면(매니페스트 기능 표시) 4절의 막음을 푼다.

### 6. 실패하면

- 모델이 연월일을 직접 쓰거나 범위 밖 값을 주면 기기가 버리고 날짜를 되묻는다.
- 수량이 소수면 1단계에서는 "수량은 정수로만 받을 수 있어요. 공급가액으로 말씀해 주세요."로 되묻는다.
- 홈택스 작성일자가 의도와 다르면 지금처럼 게이트 전에 멈춘다(N-26, 문구 "홈택스 작성일자가 정한 날(10월 31일)과 달라 멈췄어요. 아무것도 발급하지 않았어요.").

## 시험

- chat-core·엔진·main 단위 시험: 날짜 계산(말일, 윤년, 1~10일 경계, 자정), 곱·상한, 범위 밖·미래·없는 날, `amount`와 곱 불일치.
- 실모델 평가(`tests/chat-eval`) 사례 추가: "지난달 납품분 ○○상사 330만원", "10월 거 월합계로", "원두 10kg에 kg당 12,000원", "단가 5만원 3개 부가세 포함", "다음 달 1일로"(미래 거절), 고치기("작성일 25일로 바꿔 줘"). crusoe·parasail 두 공급사에서 잰다.

## 대표 결정이 필요한 것

- 발급기한(다음 달 10일)이 지난 작성일자를 경고만 하고 받을지(제안), 아예 막을지. 제안은 R14의 수정 발급 원칙과 같게 "막지 않고 경고"다.
