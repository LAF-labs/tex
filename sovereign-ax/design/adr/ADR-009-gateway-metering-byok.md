# ADR-009 게이트웨이 무저장 계량 + BYOK

상태: 채택 · 2026-10-28

## 맥락
구독에 모델 사용량을 포함하려면 계량이 필요하다. 동시에 프롬프트 본문을 우리 서버가 저장·열람하지 않아야 한다. 일부 사용자는 우리 서버조차 거치길 원하지 않는다.

## 결정
- 게이트웨이는 본문을 저장하지 않고 `usage`만 계량한다. 번들·툴셋 정의는 서버가 주입하고 클라이언트 파라미터는 화이트리스트로 제한한다.
- BYOK 모드: 사용자가 자기 OpenAI 키를 금고에 넣으면 공급사 직결. 계량은 로컬만.
- 공급사 계정은 `store:false`, 계정 ID 해시를 `safety_identifier`로, 캐시 키는 계정별 격리.

## 대안
- 클라이언트에 공급사 키 내장: 유출·남용 위험, 계량 불가. 기각.
- 게이트웨이가 프롬프트 로깅: 디버깅은 쉽지만 약속 위반. 기각(디버깅은 사용자 옵트인 진단 내보내기로).

## 결과
- 게이트웨이 장애 시 L1/L2 불가 → 플레이북은 L0 범위에서 진행하거나 핸드오프.
- 문제 재현이 어려울 수 있어 리플레이 하네스와 마스킹 미리보기에 투자한다.
