# ADR-044. 계좌 자동 연결(CODEF 공동인증서)은 소버린 규칙 2의 사용자 선택 예외다

> 상태: 채택(대표 결정 2026-11-12를 기록, 문서화 2026-11-16) · 구현은 이미 main에 있다(게이트웨이 PR #283, PC PR #285)
> 관련: [09](../../09-bank-matching.md) §4.4~§4.6·§9.4, [11](../../11-cash-flow.md), README 원칙 2(비밀값은 기기 밖으로 나가지 않는다), D05(금고), D09(클라우드 서비스), D19(공격표면), [ADR-020](ADR-020-design-review-issuance-auth-approval.md)(인증서 비밀번호는 사람이 입력), [ADR-040](ADR-040-engine-gateway-auth-scoped-device-token.md)(게이트웨이 범위 토큰)

## 맥락

- 09 §4.5 조건 9는 "CODEF 길을 켜기 전에 ADR을 먼저 쓴다"였다. 구현(#283·#285)이 먼저 들어갔고 이 ADR이 빠져 있었다. 이 ADR은 그때 정한 것을 한곳에 적어 범위를 고정한다.
- CODEF 개인·기업 수시입출 거래내역 API는 connectedId 방식이다. 공동인증서로 등록하면 **인증서 파일(der·key)과 비밀번호가 CODEF에 보관된다.** 우리 원칙 2(비밀값은 기기 밖으로 나가지 않는다)와 정면으로 다르다.
- 대표 결정(2026-11-12): "계좌연결은 API를 쓰되, 유저가 원할 경우에만", "그냥 공동인증서만", "연동 과정 자체는 우리 앱에서 끝내". 빠른조회 아이디를 모르는 사장님이 연동하다 지치면 안 된다는 이유로 팝빌(빠른조회)보다 CODEF(공동인증서)를 기본으로 골랐다.

## 결정

1. **기본은 파일 올리기다.** 자동 연결은 계좌마다 사장님이 켤 때만 쓴다. 앱이 켜기를 조르지 않는다.
2. **예외의 범위는 "은행 조회용 로그인 정보"뿐이다.** 홈택스·정부24 인증서 사용, 발급 서명, 금고의 다른 비밀은 이 예외에 들지 않는다.
3. **조회 API만 부른다.** 이체·출금 API는 계약·코드 어디에도 두지 않는다. 동의 문구에는 맡긴 공동인증서가 은행에서 조회 밖의 일도 할 수 있는 접근매체라는 점을 그대로 적는다(09 §9.4).
4. **로그인은 공동인증서 하나다.** 인터넷뱅킹 아이디·비밀번호 방식은 두지 않는다.
5. **connectedId는 조회마다 만들고 바로 지운다.** CODEF 쪽 보관 시간을 조회 한 번으로 줄인다. 지우기가 실패하면 PC에 적어 두고 다음 조회·[연결 해제] 때 다시 지운다.
6. **CODEF 키는 게이트웨이에만 있다.** 앱은 게이트웨이에서 짧은 토큰만 받고(`POST /v1/codef/token`), 등록·조회는 PC에서 CODEF로 직접 간다(`net/egress` 허용 목록). 인증서와 거래내역은 우리 서버를 지나지 않는다.
7. **인증서 비밀번호는 기본 매번 금고 창에서 묻는다.** 사장님이 [이 PC에 기억]을 고르면 키체인에 둔다(CODEF 봉인만 읽음, ADR-020 결정 2의 좁은 예외).
8. **가져온 거래내역은 PC에만 쌓는다.** 서버 색인·백업에 넣지 않는다.
9. **호출은 적게.** 앱이 켜져 있을 때만, [최신화] 간격·하루 상한, 같은 비밀번호 틀림 상한(09 §4.5).
10. **활동 기록에 남긴다.** 조회마다 계좌 끝 4자리·줄 수·"CODEF 경유".
11. **계약 전 할 일**: 개인정보처리 위탁계약(표준안), 유료약관 제14조 9항 사전 동의를 서면으로, 정식 단가, 엔드 유저 인증정보 보유 기간·유출 통지 절차(09 §4.6).

## 결과

- README 원칙 2 아래에 "사용자가 켠 계좌 자동 연결만 예외(ADR-044)" 한 줄을 더한다.
- D05 비밀 목록에 "PC 밖 보관(사용자 선택)" 등급을 둔다. D19에 CODEF·게이트웨이 토큰 유출, connectedId 도용 위협을 등록한다(설계 문서 갱신은 다음 설계 PR).
- 비용: CODEF 정식은 호출 건수 과금이고 단가는 상담으로 정한다(공개 단가 없음). 거래내역은 5,000건 단위로 1회 과금이다. 1인 사업자 계좌 하나를 하루 2번 조회하면 월 60회 안팎이다(가설). 단가를 받으면 19,900원 플랜에 넣을지(09 §11 결정 13) 정한다.
- CODEF 응답에는 상대 계좌번호 칸이 없다. 그래서 자동 연결 계좌는 맞추기 신호 S1(거래처 등록 계좌)을 쓰지 못하고 이름 신호에 기댄다(11 §2.3).

## 다시 볼 때

- 개인사업자 마이데이터가 열리고 우리가 쓸 수 있는 길(허가 기관 제휴 등)이 생기면, 인증서를 맡기지 않는 길로 바꿀지 다시 본다.
- CODEF 계약 조건(보유 기간·배상)이 동의 문구와 다르면 이 ADR과 문구를 고친다.
