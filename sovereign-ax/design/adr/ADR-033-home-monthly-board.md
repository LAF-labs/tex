# ADR-033. 홈은 "이번 달 판": ADR-019 결정 2를 대체한다

> 상태: 채택(2026-11-05, 결정 1·2) · 결정 3~5는 제안(사용자 확인 전) · 관련: ADR-019, ADR-020, ADR-021, ADR-032, ADR-034, 02 §3, 08 §3·§5
> 근거: 제품 정의 노트(2026-11-05 갱신, yulmu)

## 맥락

- ADR-019 결정 2는 "홈은 메인 대화"였다. 왼쪽 레일, 가운데 대화, 오른쪽 작업 패널이고, 대화 맨 위에 오늘 요약(M-02)을 한 줄로 고정했다.
- 세무사 꾸러미(ADR-032)와 급여대장(ADR-031)이 들어오면서 사장님이 매달 챙길 일이 늘었다. 기한이 있는 일(세금계산서 발급, 원천세 자료, 만료 서류)이 대화 속에 흩어지면 놓친다.

## 결정

1. **홈은 "이번 달 판"이다.** 해야 할 일을 기한 순으로 보여 주는 카드 목록이다. 카드는 네 가지다.
   - 발급할 세금계산서
   - 받아야 할 증빙
   - 세무사에게 줄 것
   - 만료가 다가오는 서류
2. **ADR-019 결정 2를 이 결정으로 대체한다.** ADR-019의 나머지 결정은 그대로다.
   - 결정 1: 대화 세션은 PC당 하나다.
   - 결정 3: 온보딩은 대화로 한다.
   - 결정 4·5: 타임라인의 원본은 PC 로컬 DB이고, PC가 꺼져 있을 때의 조회는 폰이 보관했다가 합친다.
   - 결정 6: 대화 안의 보안 규칙.
3. **(제안) 카드를 누르면 기존 확인 카드와 승인 바로 이어진다.** 승인 바의 위치와 근거(ADR-021)는 바꾸지 않는다. 판 카드에는 승인 버튼을 두지 않는다. 비가역 승인은 지금처럼 대화 열 하단 승인 바에서만 한다.
4. **(제안) 대화는 입력 수단으로 남긴다.** 지금 대화 맨 위의 "오늘 요약"(M-02)을 키워 판으로 만드는 방향이다. 판 아래나 옆에서 입력창과 단일 세션 타임라인을 그대로 쓴다.
5. **(제안) "세무사에게 줄 것" 카드는 세무사 꾸러미의 1·2·3층 상태를 요약한다.** 사업용 카드 내역이 오래되면(예: 마지막 최신화가 지난달) 표시하고, 거기서 [최신화]로 이어진다(ADR-032 결정 9를 이 ADR로 옮김).

## 대안과 기각 이유

| 대안 | 기각 이유 |
|---|---|
| 홈은 메인 대화 그대로, 오늘 요약 한 줄만 둔다(ADR-019) | 기한이 있는 일이 대화 속에 흩어진다. 세무사 꾸러미처럼 한 달 단위로 쌓이는 일을 한 줄로 보여 줄 수 없다 |
| 판 카드에서 바로 승인한다 | 승인 근거를 main 소유 승인 바 하나로 둔 ADR-021과 어긋난다. 판은 렌더러가 그리므로 장악되면 승인을 위조할 수 있다 |

## 결과

- ADR-019 상태 줄에 "결정 2는 ADR-033으로 대체"를 적는다.
- 02 §3, 08 §3(M-01·M-02)·§5·§13을 고친다.
- 판 화면의 배치(판과 대화의 위치 관계, 좁은 화면)는 디자인 단계에서 정한다.
- 작업과 공수는 D14 §2.6 M6-16이다.
