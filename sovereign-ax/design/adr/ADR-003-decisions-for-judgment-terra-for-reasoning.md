# ADR-003 판단은 Decisions API, 추론은 GPT-6.1 Terra

상태: 채택 · 2026-10-28

## 맥락
모델이 필요한 지점은 두 종류다. (a) "이 화면이 무엇인가, 성공했는가, 어느 작업인가"처럼 선택지가 정해진 판단, (b) 셀렉터 복구·자연어 인자 채우기처럼 열린 문제. (a)에 생성형 호출을 쓰면 출력이 통제되지 않고 느리며 비싸다.

## 결정
- (a)는 OpenAI Decisions API(`gpt-6-luna`, `POST /v1/decisions`). 정식 출시, 입력 $0.10/1M, 출력 무료, 요청당 질문 ≤ 400. 질문·임계값은 엔진 배포에 포함된 번들 카탈로그로 고정하고 플레이북은 참조만.
- (b)는 GPT-6.1 Terra(Responses API), 엄격 스키마 도구 3종 이하, 비가역 도구 없음, 출력은 구조화 JSON. effort low/medium.
- 공급사 간 다단 캐스케이드는 만들지 않는다. 어댑터 한 곳에 공급사 종속을 가둔다.

## 대안
- 단일 LLM(Terra)으로 모든 판단: 단순하지만 출력 통제·지연·비용에서 불리.
- 로컬 소형 모델로 판단: 비용은 0에 가깝지만 한국어 화면 판정 품질·유지 부담 미검증. Phase 3 실험.

## 결과
- 임계값 조정과 라벨 코퍼스 운영이 상시 업무가 된다(S7, 회귀).
- Decisions의 `refusal` 응답과 `unknown`은 항상 "자동 진행 금지"로 해석한다.
