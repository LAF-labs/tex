# D17. 후처리(guide) 모드 명세 (초안)

MVP의 정부24 서류 3종은 모두 이 모드로 출시된다. 원칙: **Chrome·CDP를 띄우지 않고, 포털에 어떤 요청도 보내지 않는다.** 사용자가 기본 브라우저에서 직접 발급하고, 하네스는 안내·파일 수집·메타데이터·만료 추적만 한다.

## 1. 흐름

1. 사용자가 작업 카드(예: 주민등록등본)를 누른다 → 하네스가 `shell.openExternal(포털 URL)`로 기본 브라우저를 연다(1회). 동시에 안내 패널을 띄운다.
2. 안내 패널: 플레이북 `guide` 변환본의 체크리스트(로그인 → 메뉴 → 입력 → 발급 → 출력), 각 단계의 입력값 복사 버튼(사업자번호·주소 등 비밀 아닌 값만; 30초 후 클립보드를 비운다, 값이 그대로일 때만), "출력/저장했어요" 버튼.
3. 파일 감시: 다운로드 폴더, 인쇄 출력 폴더(Microsoft Print to PDF 기본 경로), 사용자가 지정한 폴더를 감시한다. 작업 시작 이후 생성된 PDF만 후보. 정부24+ 비밀번호 PDF는 사용자가 비밀번호를 입력해 열고(비밀번호는 저장하지 않음) 복호화 사본을 보관함에 둔다.
4. 매칭: 후보 PDF를 `docparse`(별도 무권한 프로세스)로 추출해 서류 종류 키워드·발급일·성명/상호 일치로 현재 작업과 매칭한다. 애매하면 사용자에게 "이 파일이 맞나요?"를 묻는다. 매칭 실패 → `postprocess.file_not_detected`로 수동 선택.
5. 메타데이터: 발급일·유효기간을 규칙으로 추출(`doc_meta_check_v1`은 마스킹 후 보조). 실패하면 수동 입력 폼(날짜 2개).
6. 보관: `%LOCALAPPDATA%\SovereignAX\vault\{docType}_{yyyyMMdd}_{shortId}.pdf`로 이동(원본은 사용자 선택: 삭제/유지), DB 등록, 만료 규칙 적용, 백업 큐.
7. 완료·타임아웃·취소: "출력했어요" 후 2분 내 파일 미감지 → 수동 선택 안내. 30분 무활동 → 작업 자동 종료(기록만). 취소는 언제든.
8. 감사 로그: `run.started{mode: postprocess}`, `postprocess.file_detected{bytes, sha256}`, `artifact.saved`. 화면 텍스트·URL 없음.

## 2. 금지와 테스트

- 이 모드에서 금고는 Chrome을 기동하지 않고, 엔진은 포털 호스트로 어떤 네트워크 요청도 보내지 않는다. 자동 테스트: 실행 중 Chrome 프로세스 0, CDP 0, 포털 호스트 요청 0, `openExternal` 1회.
- 캡차·간편인증은 사용자가 브라우저에서 직접 처리한다. 폰 중계 없음.
- 화면 읽기(접근성 트리·스크린샷) 없음. 모델 호출은 저장된 PDF의 메타데이터 보조 판정뿐.

## 3. docparse 인터페이스

```ts
interface DocParse { extract(fileHandle, opts: {maxPages: 5}): Promise<{text: string; pages: number; hasTextLayer: boolean}>; ocr(fileHandle, lang: 'kor'): Promise<{text: string}>; }
```
별도 유틸리티 프로세스, 파일 핸들만 전달, 네트워크·키체인 접근 없음, 처리 시간·메모리 상한, 실패는 코드로만 보고.

## 4. 사용자에게 보이는 문구

- 카드: "정부24에서 직접 발급하고, 저장된 파일은 제가 정리·추적합니다. 운영기관 허락이 확인되면 자동 발급으로 올라갑니다."
- 설정 '운영 기준' 페이지에 포털별 수준과 공문 회신 상태.
