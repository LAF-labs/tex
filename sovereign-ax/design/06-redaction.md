# D06. 마스킹 계층

## 1. 목표

모델 공급사(TB-5)와 게이트웨이(TB-4)로 나가는 모든 바이트는 이 계층을 통과한다. 목표는 (1) 식별자·비밀 0건 유출, (2) 업무 데이터 최소화, (3) 판정에 필요한 구조·라벨은 보존.

## 2. 파이프라인

```text
a11y snapshot(page/frame) ─▶ scope cut(현재 스텝 서브트리) ─▶ prune(장식·반복·숨김 제거) ─▶ size cap(≤ 6KB L1 / ≤ 8KB L2)
  ─▶ entity detect(정규식 + 사전 + 체크섬 검증) ─▶ tokenize([RRN_1]…) ─▶ RedactedText(브랜드) + local map
  ─▶ (이미지 경로) crop ─▶ box-mask(엔티티 박스·사진 영역) ─▶ RedactedImagePart
응답 ─▶ detokenize(local map) ─▶ 엔진
```

## 3. 접근성 트리 추출과 절단

- 소스: Playwright 접근성 스냅샷 + 필요 시 DOM 보조(라벨·placeholder). 프레임은 `scope`가 가리키는 프레임만.
- 절단 규칙: `scope` 셀렉터의 서브트리. 없으면 `main`/`dialog` 역할 노드 우선. 숨김(`hidden`)·장식(`presentation`)·반복 행(표는 머리글 + 첫 3행 + 행 수)·스크립트 텍스트 제거.
- 노드 표현: `role name(state)` 한 줄 포맷, 들여쓰기로 계층. 예: `textbox "공급받는자 등록번호"(required, invalid)`.
- 크기 상한 초과 시: 깊이 우선으로 하위부터 접고 `…(+N nodes)` 표기.

## 4. 엔티티 탐지와 치환

| 엔티티 | 탐지 | 검증 | 토큰 |
|---|---|---|---|
| 주민등록번호 | `\d{6}-?[1-8]\d{6}` | **체크디지트로 배제하지 않는다**(2020.10 이후 뒷자리 임의번호) | `[RRN_n]` |
| 외국인등록번호 | 주민번호 패턴에 포함(5~8) | 배제 없음 | `[RRN_n]` |
| 운전면허번호 | `\d{2}-?\d{2}-?\d{6}-?\d{2}` | — | `[DLN_n]` |
| 여권번호 | `[A-Z]{1,2}\d{7,8}` | 문맥(여권) | `[PASSPORT_n]` |
| 건강보험증번호 | `\d-?\d{10}` 계열 + 문맥 | 보수적 | `[NHIS_n]` |
| 사업자등록번호 | `\d{3}-?\d{2}-?\d{5}` | 가중치 검증 | `[BIZNO_n]` |
| 법인등록번호 | `\d{6}-?\d{7}` | 체크디지트 | `[CORPNO_n]` |
| 전화번호 | 국내 형식(`010-1234-5678`, `01012345678`, `02-…`, `+82-10-…`) | — | `[PHONE_n]` |
| 이메일 | RFC 간이 + 한글 도메인(IDN) | — | `[EMAIL_n]` |
| 계좌번호 | 은행별 길이 패턴, **구분자 없는 10~14자리 숫자열 포함** | 보수적(의심되면 치환) | `[ACCT_n]` |
| 카드번호 | 16자리 + **마스킹 형태**(`1234-****-****-5678`) | Luhn 또는 마스킹 형태 | `[CARD_n]` |
| 주소 | 시도·시군구 사전 + 번지 패턴 | — | `[ADDR_n]` |
| 금액 | 숫자+원/콤마 | 옵션(기본 유지: 판정에 필요) | `[AMT_n]`(옵션) |
| 승인번호(세금계산서) | `\d{8}-\d{8}-\d{8}` | — | `[APPROVAL_n]` |
| 이름 | 사용자 사전(상호·대표자·거래처·세대원) + 2~4자 한글 + 호칭 문맥 | 사전 우선, 문맥 보수적 | `[NAME_n]` |
| 인증서 비밀번호·보안카드 | 탐지 대상이 아님 — **애초에 트리에 값이 없어야 함**(`type=password` 값은 스냅샷에서 제외) | 스냅샷 단계 필터 | — |
| 캡차 답 | `human` 결과 변수는 모델 입력 금지(타입 시스템) | — | — |

- **정규화 먼저**: NFKC, 전각→반각, 제로폭 문자 제거, 공백·구분자 변형(`-`, `.`, ` `, `–`) 통일 후 패턴을 돌린다.
- **입력값 기본 거부**: 접근성 스냅샷에서 모든 입력 요소(`textbox`, `combobox`, `spinbutton`, `searchbox`)의 **값**은 기본 제거하고 라벨·placeholder·상태만 남긴다. 값이 필요한 판정(readback)은 모델이 아니라 엔진이 한다. `type=password`·`secretSlot`·최근 타이피스트 대상은 값은 물론 길이도 남기지 않는다.
- **Fail-closed**: 스냅샷 추출·절단·치환 중 하나라도 실패하면 모델 호출을 하지 않고 핸드오프한다. 열린 채로 통과하지 않는다.
- **egress 트립와이어**: `egress.toModel()` 직전에 런타임으로 식별자 패턴을 한 번 더 돌려 걸리면 전송을 중단하고 보안 이벤트를 남긴다(브랜드 타입은 컴파일 장치일 뿐이다).
- 오류 메시지·URL 쿼리·파일 경로·스택 트레이스는 모델·텔레메트리로 보내지 않는다(코드만).
- 같은 실행 내 같은 값은 같은 번호(`[BIZNO_1]`)로 일관되게 치환해 모델이 동일성 추론을 할 수 있게 한다. 번호 매핑은 실행 종료 시 폐기.
- 사용자 사전: 프로필 등록 시 상호·대표자·주소, 거래처 등록 시 상호·대표자·이메일이 자동 등재. 사용자가 단어 추가 가능.
- 거짓 음성 비용이 더 크므로 패턴은 공격적으로, 검증은 "확실히 아닌 것"만 제외한다.

## 5. 이미지 마스킹

- 기본 비전송. 캡차는 모델에 보내지 않는다(사람에게만).
- L2 복구나 `doc_meta_check`에서 이미지가 필요한 경우: 스텝 `scope` 요소의 바운딩 박스로 잘라낸 뒤, 접근성 트리에서 엔티티로 판정된 노드의 박스를 검은 사각형으로 덮고, 얼굴/사진 영역(`img` 역할)을 전부 덮는다. OCR 기반 추가 탐지(로컬 Tesseract)로 이미지 안 숫자 패턴을 덮는다. 모든 처리는 로컬.

## 6. 미리보기와 감사

- 모델 전송 직전 페이로드를 `run_events.model.called`에 **길이·치환 건수·엔티티 종류별 카운트**로 기록. 본문은 로컬 임시 저장(실행 종료 후 24시간 보관, 사용자가 감사 로그에서 열람 가능)하고 자동 삭제.
- 설정에서 "전송 전 항상 미리보기 확인" 옵션(기본 꺼짐, 보안 민감 사용자용).

## 7. 테스트 코퍼스

- 합성 데이터: 유효 체크섬을 갖는 가짜 주민번호·사업자번호·계좌번호 생성기로 10,000건.
- 실제 화면 스냅샷(스파이크에서 수집, 테스트 사업자 데이터만)에 라벨링.
- 수용 기준: 식별자 재현율 ≥ 99.9%(합성), ≥ 99.5%(실제), 토큰 일관성 100%, 트리 절단 후 L1 판정 정확도 저하 ≤ 1%p.
- 회귀: 마스킹 규칙 변경 시 코퍼스 전체 재실행이 CI 필수.

## 8. 인터페이스

```ts
interface Redaction {
  snapshot(page: Page, scope: Scope, opts: {maxBytes: number}): Promise<A11yText>;
  apply(text: A11yText | string, ctx: RunCtx): {redacted: RedactedText; map: TokenMap; stats: RedactionStats};
  applyImage(png: Buffer, boxes: Box[], ctx: RunCtx): Promise<RedactedImagePart>;
  detokenize(text: string, map: TokenMap): string;
}
```
`RedactedText`는 모듈 밖에서 생성할 수 없는 브랜드 타입이며, `net/egress.toModel()`은 이 타입만 받는다.
