# 06. 개발·사업 가능성 검토 (Go / No-Go)

> ADR-035 반영 2026-11-05: §5의 G1은 Phase 1 착수 조건이 아니라 출시 게이트다. G1-a 통합 판정(코드로 닫는 조건)과 G1-b 출시 판정(실측·대외·지불의사)으로 나눴다.

## 1. 결론

**조건부 Go.** 기술은 검증 가능한 범위 안에 있고, 비용 구조는 넉넉하며, 시장과 타이밍은 유리하다. 가장 큰 불확실성은 기술이 아니라 **운영기관의 허락 여부와 세무사법·개인정보보호법 시행령 해석**이다. 기준 시나리오(정부24 허락 없음)에서 자동화 가치는 홈택스 작업에 집중되고 정부24 민원서류는 정리·만료 추적 가치만 남는다. 다만 공고문 36건 집계(07 문서, R9)에서 사업자 제출서류 요구의 39%는 홈택스 민원증명이고 정부24 전용은 4%라, 기준 시나리오에서도 자동화되는 서류가 수요의 중심이다(ADR-018). 이 기준으로 가격·재무를 다시 세웠고(01 §3·§5·§9), 아래 §5의 Go 조건이 충족되면 Phase 1에 착수한다.

### 3.2 지불의사와 단위 경제

- 대체재 비용: ASP는 월 0~22,000원(월 30~100건)이고 무료 옵션이 있어 **세금계산서 발급 단가로는 9,900원이 더 싸지 않다.** 경영지원 인력의 서류 업무(월 수 시간)와 만료 추적·리모트·주권이 지불 근거다. 인터뷰(Q5)에서 무료 ASP·홈택스 직접 발급 사용자를 별도 집단으로 분리한다.
- LTV: ARPU 16,000원 × 마진 0.8 × (1 / 월 이탈 5%) ≈ 25.6만 원. 이탈 8%로 보수적으로 잡으면 16만 원.
- CAC: 디지털 채널 3~6만 원 가정, 단체 라이선스·커뮤니티 채널은 그 이하. LTV/CAC 3~8 범위. 이탈률이 사업성의 핵심 변수다.
- 모델비가 사용자당 월 1,000원 아래라 가격 인하 여지가 크다. 경쟁 압력이 오면 7,900원도 마진 70%를 지킨다.

### 3.5 자금

12개월 소요 약 6~7억 원(5인 팀, 법률 자문, 인프라 소액). 시드 투자가 주된 자금원이다. 초기창업패키지(최대 1억 원)와 TIPS(운영사 투자 선행, 최대 8억 원)는 2026년 접수가 마감되어 2027년 공고를 기다린다. 손익분기는 유료 약 2,800명이며 기준 시나리오의 M12 목표(1,800명)로는 미달이다(01 §9). 정부24 허락 시나리오에서 2,500명.

## 5. Go 조건과 중단 기준

**출시 게이트(G1, ADR-035로 재정의. 2026-11-05 전에는 "Phase 1 착수 조건"이었다)**

Phase 1 코드는 2026-11-05부터 PoC 코드를 승격해 쓴다(ADR-035 결정 1). 아래 1~5는 그대로 두고, 판정을 두 단계로 나눈다.

| 단계 | 시점 | 조건 |
|---|---|---|
| **G1-a 통합 판정** | 2026-11-19 목표 | 4(S6) 전부. 2의 S7·S8·S1과 3의 S16 중 코드로 닫는 부분: 판정 하네스·번들 검증기·임계값·L0 승격 기준과 합성·리플레이 회귀(S7), 정책 상한·하한·카운터·쿨다운·차단 신호 집행 시험(S8), 리플레이·가짜 페이지에서 H-01 게이트 직전 완주와 verify 판정(S1), PDF 저장·메타 추출 시험(S16). ADR-035 결정 1의 승격 조건 |
| **G1-b 출시 판정** | M5-2 라이브 검증 뒤, 베타 초대(M5-3) 전 | 2의 실측 부분(S1 자동 구간 Windows 9/10·실거래 verify, S1a, S1b, S8 홈택스 50회, S7 실화면 300장 정확도 98%), 3의 S16 2/2, 1(대외), 5(지불의사). 아래 중단 기준 K1~K4도 여기서 판정한다 |

S7·S8을 코드 부분과 실측 부분으로 쪼갠 것은 제안이다(ADR-035 결정 3.2).

1. 대외: 공문 2건 접수, 개인정보위 질의 접수, 법률 1차 의견('세무대리 아님', '테스트 발급 방식 적법'), 모델 공급사 ZDR 신청 접수.
2. 홈택스: S1 **자동 구간 완주**(로그인 인증과 게이트 승인 외에 사람 개입 0회로 게이트 직전까지) Windows 9/10, 실거래 소액 발급 건은 `verify` 조회 일치. S1a 동작 차이 없음(또는 원인 규명 후 공문 협의 개시). S1b로 기본 인증 경로 확정. S8 홈택스 50회(상한 안에서 나눠) 차단 0건. S7 홈택스 화면 판정 정확도 98%.
3. 서류: S3(사람 조작)에서 정부24 5종 중 4종 이상 PDF 확보 + 파일 감지 성공. S16에서 홈택스 민원증명 2종 PDF 확보.
4. 금고: S6에서 금고 소유 파이프 + 기본 거부 허용 목록 중계 + 비밀 창 동작(S6·S6b~S6f), 다른 OS 사용자 접속 불가, 누출 0건.
5. 지불의사: **축소된 제품 설명**(정부24 직접 발급 + 자동 보관, 공동인증서 비밀번호 직접 입력, 갱신은 승인형)으로 인터뷰 20건, 9,900원 플랜 의향 40% 이상(ADR-034 한 플랜). 무료 ASP 사용자 집단은 따로 집계.

**중단·피벗 기준**
- K1: S1 자동 구간 완주율 70% 미만, 또는 S1a에서 홈택스가 차단·추가 인증으로 반응 → 홈택스를 `assisted`로 내리고 '보관·만료 추적·안내 + 입력 보조' 제품으로 재평가.
- K2: `postprocess` 포털의 베타 활성화율(보관 완료율 기준) 30% 미만 → 중단.
- K3: 축소 설명 기준 9,900원 플랜 의향 30% 미만 → 가격·세그먼트 재설계(세무사 요금 시기 포함).
- K4: S3와 S16이 모두 실패(정부 서류 PDF 확보 불가) → 보관함을 '수동 등록 + 만료 추적'으로 재정의하고 가격 재검토.
