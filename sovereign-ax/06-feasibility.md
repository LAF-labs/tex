# 06. 개발·사업 가능성 검토 (Go / No-Go)

## 1. 결론

**조건부 Go.** 기술은 검증 가능한 범위 안에 있고, 비용 구조는 넉넉하며, 시장과 타이밍은 유리하다. 가장 큰 불확실성은 기술이 아니라 **운영기관의 허락 여부와 세무사법·개인정보보호법 시행령 해석**이다. 기준 시나리오(정부24 허락 없음)에서 자동화 가치는 홈택스 작업에 집중되고 민원서류는 정리·만료 추적 가치만 남는다. 이 기준으로 가격·재무를 다시 세웠고(01 §3·§5·§9), 아래 §5의 Go 조건이 충족되면 Phase 1에 착수한다.

만들지 않기로 한 것과 이유:
- ASP(전자세금계산서 발급 대행사) API 연동: 건당 비용, 발급 데이터의 제3자 집적, "본인 데이터" 모토와 충돌. 불허 시나리오의 대안도 ASP가 아니라 반자동 모드다.
- 서버 측 브라우저: 데이터센터 IP·대리 발급 지위·비밀 노출이라는 세 가지 문제를 한 번에 만든다.
- 캡차 자동 해독·지문 위조·흔적 삭제: 05 문서.

### 3.2 지불의사와 단위 경제

- 대체재 비용: ASP는 월 0~22,000원(월 30~100건)이고 무료 옵션이 있어 **세금계산서 발급 단가로는 9,900원이 더 싸지 않다.** 경영지원 인력의 서류 업무(월 수 시간)와 만료 추적·리모트·주권이 지불 근거다. 인터뷰(Q5)에서 무료 ASP·홈택스 직접 발급 사용자를 별도 집단으로 분리한다.
- LTV: ARPU 16,000원 × 마진 0.8 × (1 / 월 이탈 5%) ≈ 25.6만 원. 이탈 8%로 보수적으로 잡으면 16만 원.
- CAC: 디지털 채널 3~6만 원 가정, 단체 라이선스·커뮤니티 채널은 그 이하. LTV/CAC 3~8 범위. 이탈률이 사업성의 핵심 변수다.
- 모델비가 사용자당 월 1,000원 아래라 가격 인하 여지가 크다. 경쟁 압력이 오면 7,900원도 마진 70%를 지킨다.

### 3.5 자금

12개월 소요 약 6~7억 원(5인 팀, 법률 자문, 인프라 소액). 시드 투자가 주된 자금원이다. 초기창업패키지(최대 1억 원)와 TIPS(운영사 투자 선행, 최대 8억 원)는 2026년 접수가 마감되어 2027년 공고를 기다린다. 손익분기는 유료 약 2,800명이며 기준 시나리오의 M12 목표(1,800명)로는 미달이다(01 §9). 정부24 허락 시나리오에서 2,500명.

## 5. Go 조건과 중단 기준

**Phase 1 착수 조건(G1, 모두 충족)**
1. 대외: 공문 2건 접수, 개인정보위 질의 접수, 법률 1차 의견('세무대리 아님', '테스트 발급 방식 적법'), 모델 공급사 ZDR 신청 접수.
2. 홈택스: S1 **자동 구간 완주**(로그인 인증과 게이트 승인 외에 사람 개입 0회로 게이트 직전까지) Windows 9/10, 실거래 소액 발급 건은 `verify` 조회 일치. S1a 동작 차이 없음(또는 원인 규명 후 공문 협의 개시). S1b로 기본 인증 경로 확정. S8 홈택스 50회 차단 0건. S7 홈택스 화면 판정 정확도 98%.
3. 서류: S3(사람 조작)에서 정부24 5종 중 4종 이상 PDF 확보 + 파일 감지 성공. S16에서 홈택스 민원증명 2종 PDF 확보.
4. 금고: S6에서 금고 소유 파이프 + 엔진 중계 구조 동작, 다른 OS 사용자 접속 불가, 누출 0건.
5. 지불의사: **축소된 제품 설명**(정부24 직접 발급 + 자동 보관, 공동인증서 비밀번호 직접 입력, 갱신은 승인형)으로 인터뷰 20건, 스타터 의향 40% 이상. 무료 ASP 사용자 집단은 따로 집계.

**중단·피벗 기준**
- K1: S1 자동 구간 완주율 70% 미만, 또는 S1a에서 홈택스가 차단·추가 인증으로 반응 → 홈택스를 `assisted`로 내리고 '보관·만료 추적·안내 + 입력 보조' 제품으로 재평가.
- K2: `postprocess` 포털의 베타 활성화율(보관 완료율 기준) 30% 미만 → 중단.
- K3: 축소 설명 기준 스타터 의향 30% 미만, 비즈니스 의향 20% 미만 → 가격(가설 B)·세그먼트 재설계.
- K4: S3와 S16이 모두 실패(정부 서류 PDF 확보 불가) → 보관함을 '수동 등록 + 만료 추적'으로 재정의하고 가격 재검토.
