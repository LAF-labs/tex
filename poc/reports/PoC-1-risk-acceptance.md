# PoC 계정 지정과 정지 위험 수용 기록 (초안)

> 근거: ADR-017 결정 5 · 대상 태스크: PoC-1 · 작성 2026-10-30 · AUDIT-D 반영 2026-11-03(§2 인증수단 행, §3 집행 주체 표·PoC-3 착수 조건, [ADR-022](../../sovereign-ax/design/adr/ADR-022-poc3-real-account-safety-baseline.md)) · **서명 전**

## 1. 지정

| 항목 | 값 |
|---|---|
| PoC 전용 계정(관계사 법인) | **(대표 지정 대기)** |
| 사업자등록번호 | 저장소에 적지 않는다. 대표가 보관 |
| 거래 상대(실발급 2~3건) | **(대표 지정 대기)** — 실제 공급이 있는 관계사 |
| 사용 기간 | 2026-10-29 ~ 11-26(PoC), G1(11-27) 뒤 재결정 |
| 사용 범위 | 홈택스 로그인, H-01 전자세금계산서 발행 + 이메일, H-04 납세증명·사업자등록증명 발급, S8 조회성 50회 |

이 법인은 테스트 전용 법인이 아니라 실제 영업 법인의 관계사다. D18 §1.3(테스트 사업자는 실제 영업 법인이 아닐 것)의 예외이며, 예외 근거는 ADR-017(테스트 법인 리드타임이 PoC 기간을 넘음)이다.

## 2. 수용하는 위험

| 위험 | 영향 | 수용 |
|---|---|---|
| 홈택스 이용 제한·접속 차단 | 그 법인의 세금계산서 발행·신고·증명 발급이 막힐 수 있다. 대체 수단(세무대리인·방문) 필요 | 대표 수용 |
| 실발급 세금계산서 오류 | 취소 불가, 수정세금계산서로만 상쇄. 거래처 신고에 반영 | 실거래 소액 2~3건으로 한정 |
| 테스트 발급 적법성(법률 질의 5번) 회신 전 실발급 | 회신이 "부적법"이면 소급 설명 필요 | 대표 수용(§4) |
| 인증수단 노출 | 인증서 비밀번호·보안카드 유출 시 법인 명의 도용 | 저장하지 않음. 금고가 요청할 때만 main이 여는 비밀 창에 매번 입력하고, 쓰지 않은 값은 5분 뒤 지운다(ADR-022, D-15(N-44)) |

## 3. 완화 조치

- 본인 회선 IP(사람)(05).
- 완화 항목과 집행 주체(ADR-022, D-04(N-01)·D-06(N-03)·D-09(N-14)):

| 완화 | 집행 |
|---|---|
| 하루 자동 실행 20회 이하(S8 제외) | 앱(`POC_BUILD`) |
| 하루 실발급 1건, PoC 누적 3건 | 앱 |
| 하루 로그인 3회 | 앱(PoC-3 로그인 구현 뒤) |
| 동시 세션 1 | 앱(단일 인스턴스·실행 1개) |
| 사용자가 정한 시간대 | 사람 |
| 차단·경고 신호 1회 → 즉시 중단·24시간 쿨다운 | 앱 |
| 추가 인증은 로그인 밖에서 연속 2회부터 차단 신호(로그인 구간 2차 인증은 세지 않음) | 앱 |
| 모르는 화면 연속 2회 보수 모드, 3회 쿨다운 | 앱 |
| 재개 판단·쿨다운 해제 | 사람(PM, `dev-reset-cooldown`) |
| 공문 채널 설명(`portal.blocked` 계열 2회) | 사람 |

- **PoC-3 착수 조건(코드가 강제)** (ADR-022):
  - 실 홈택스 시험은 `pnpm start:hometax`(하드닝된 셸)로만 한다. 디버깅 스위치를 켜면 앱이 뜨지 않는다(D-37(N-24)).
  - 실비밀 전에 같은 화면에서 테스트 비밀로 누출 스캔 0건을 확인한다(D-11(N-17)).
  - 전용 Chrome에서 Google에 로그인하지 않는다(메일 확인은 다른 브라우저). 로그인돼 있으면 비밀 창이 열리지 않는다(D-12(N-18)).
  - PC 레지스트리 `usagestats=0`과 `Crashpad\` 폴더 0을 확인한다(D-07(N-04)).
  - 화면 영상은 로그인·비밀번호 구간을 찍지 않고 `spikes\` 폴더에만 두며 12-31에 지운다(D-08(N-05)).
  - 앱 스모크는 임시 루트로만 돈다(D-38(N-57)).
- 커밋 게이트(발급 직전 사람 승인)와 원장은 PoC에서도 설계대로 동작한다(ADR-017 결정 4).
- 화면 산출물은 마스킹 후 별도 폴더, 2026-12-31 삭제(D18 §4).
- 정부24는 이 계정으로도 자동화하지 않는다.

## 4. 실발급 시점 (2026-10-30 결정)

D18 §1.2는 "법률 질의 5번째 항목 회신 전에는 실발급하지 않고 게이트 직전 드라이런만" 한다고 적었고, ADR-017 결정 5는 회신을 기다리지 않고 실발급 2~3건을 PoC 범위에 넣었다(PoC-6, 11-12). **ADR-017 문언을 따른다**: 회신 전이라도 실제 공급이 있는 관계사 거래에 한해 실발급한다. 공급 없는 발급·0원 발급은 하지 않는다. D18 §1.2·§1.3을 이에 맞췄다(v1.3.1).
