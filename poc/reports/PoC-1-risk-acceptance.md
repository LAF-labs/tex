# PoC 계정 지정과 정지 위험 수용 기록 (초안)

> 근거: ADR-017 결정 5 · 대상 태스크: PoC-1 · 작성 2026-10-30 · **서명 전**

## 1. 지정

| 항목 | 값 |
|---|---|
| PoC 전용 계정(관계사 법인) | **(대표 지정 대기)** |
| 사업자등록번호 | 저장소에 적지 않는다. 대표가 보관 |
| 거래 상대(실발급 2~3건) | **(대표 지정 대기)** — 실제 공급이 있는 관계사 |
| 사용 기간 | 2026-10-29 ~ 11-26(PoC), G1(11-27) 뒤 재결정 |
| 사용 범위 | 홈택스 로그인, H-01 전자세금계산서 발행 + 이메일, H-04 납세증명·사업자등록증명 발급, S8 조회성 50회 |

이 법인은 테스트 전용 법인이 아니라 실제 영업 법인의 관계사다. D18 §1.3(테스트 사업자는 실제 영업 법인이 아닐 것)의 예외이며, 예외 근거는 ADR-017(테스트 법인 리드타임이 PoC 기간을 넘음)이다.

## 2. 수용하는 위험

| 위험 | 영향 | 수용 |
|---|---|---|
| 홈택스 이용 제한·접속 차단 | 그 법인의 세금계산서 발행·신고·증명 발급이 막힐 수 있다. 대체 수단(세무대리인·방문) 필요 | 대표 수용 |
| 실발급 세금계산서 오류 | 취소 불가, 수정세금계산서로만 상쇄. 거래처 신고에 반영 | 실거래 소액 2~3건으로 한정 |
| 테스트 발급 적법성(법률 질의 5번) 회신 전 실발급 | 회신이 "부적법"이면 소급 설명 필요 | 대표 수용(§4) |
| 인증수단 노출 | 인증서 비밀번호·보안카드 유출 시 법인 명의 도용 | 저장하지 않음, 매번 비밀 창 입력 |

## 3. 완화 조치

- 본인 회선 IP, 하루 자동 실행 20회 이하, 동시 세션 1, 사용자가 정한 시간대에만 실행(D18 §1.4, 05).
- 차단·경고·추가 인증 신호 1회 → PoC 즉시 중단, 24시간 쿨다운, 재개는 PM 판단. 2회 → 국세청 공문 채널로 설명(D18 §3, ADR-017 조건).
- 커밋 게이트(발급 직전 사람 승인)와 원장은 PoC에서도 설계대로 동작한다(ADR-017 결정 4).
- 화면 산출물은 마스킹 후 별도 폴더, 2026-12-31 삭제(D18 §4).
- 정부24는 이 계정으로도 자동화하지 않는다.

## 4. 실발급 시점 (2026-10-30 결정)

D18 §1.2는 "법률 질의 5번째 항목 회신 전에는 실발급하지 않고 게이트 직전 드라이런만" 한다고 적었고, ADR-017 결정 5는 회신을 기다리지 않고 실발급 2~3건을 PoC 범위에 넣었다(PoC-6, 11-12). **ADR-017 문언을 따른다**: 회신 전이라도 실제 공급이 있는 관계사 거래에 한해 실발급한다. 공급 없는 발급·0원 발급은 하지 않는다. D18 §1.2·§1.3을 이에 맞췄다(v1.3.1).
