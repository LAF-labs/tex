# 대화 판정 chat_route_v1 실측: 받는 방식과 반응 (2026-11-19, ADR-057)

> 세트: `tests/chat-eval/route/cases.ts` 392건(가상 장부, 실제 고객 문장 없음). 이번에 30건 더함(맞장구 18, 감사+질문 6, 감사+일 4, 되물음에 맞장구 2)
> 러너: `tests/chat-eval/route/run.ts --target=v1` · 원자료: `route-v1.json`(같은 폴더, 사례 ID·고른 값·확률만)
> 실행: 맥북, OpenRouter, 대표가 키를 넣어 돌림. jev는 `typesafe/jev-1.14`(풀린 이름 `typesafe/jev-1.14-20261014`). 오류 0건, 비용 96원
> 라벨 고침 1건: "고마워요"(폰)의 반응만 라벨이 빠져 있었다(돕는 함수가 넷째 인자를 버림). 고친 라벨로 같은 결과를 다시 채점했다(모델을 다시 부르지 않음).

## 결론

**받는 방식은 바로 써도 된다.** 가장 나쁜 오류(질문이나 일을 반응만으로 닫아 사장님 말을 놓침)는 0건이다. 맞장구는 85%를 반응 하나로 닫는다. 일을 맡긴 말에 👀를 다는 비율은 78%로 초안 관문(80%)에 조금 못 미치지만, 놓친 것은 모두 반응 없이 평소처럼 답하는 쪽이라 해가 없다.

**act·domain은 초안보다 나빠졌다(둘 다 맞음 93.1% → 88.5%).** 질문 둘을 더하고 머리말을 2,000토큰 상한에 맞춰 줄인 탓으로 본다. 이번 PR은 act·domain을 기록만 하고 길을 좁히는 데 쓰지 않으므로 지금 영향은 없다. ADR-051 3단계에서 이 값으로 도구를 좁히기 전에 머리말을 되살려 92% 관문을 다시 넘겨야 한다.

## 받는 방식(ADR-057 7절 관문)

제품이 실제로 하는 일(`routeAck`: 문턱 0.8, 허용 반응, 세무 판단 0.5 아래)로 채점했다.

| 지표 | 값 | 관문(초안) | |
|---|---|---|---|
| 질문이나 일을 반응만으로 닫음 | **0%** (0/366) | 1% 이하 | 통과 |
| 맞장구를 반응만으로 닫음 | **84.6%** (22/26) | 80% 이상 | 통과 |
| 일을 맡긴 말에 👀 | **78.4%** (171/218) | 80% 이상 | 조금 모자람 |
| reply_mode 정확도 / 제품 동작 일치 | 92.9% / 86.5% | | |
| 보정 ECE | 0.052 | | |
| 지연 p50 / p95 | 0.42초 / 0.55초 | | |

- 일에 👀를 못 단 47건: 32건은 확률이 0.8 아래라 반응하지 않았고, 15건은 모델이 answer를 골랐다. 어느 쪽이든 평소처럼 답한다(점 셋만 돈다).
- 맞장구를 못 닫은 4건: "ㄱㅅ"(answer를 고름), "ㅇㅋ", "ㄳㄳ", 열린 카드에 "좋아 그대로 해"(확률 0.57~0.76). 모두 평소처럼 짧게 답한다. 줄임말(ack_slang) 갈래가 50%로 가장 약하다.
- 반대로 고른 2건: "종합소득세 신고 대신 해줘", "한빛상사 계좌로 돈 보내"(라벨은 answer, 앱이 하지 않는 일)에 👀를 달았다. 답은 "할 수 없어요"로 온다. 👀 뒤에 "못 해요"가 오는 것이 어색하므로, 다음에 머리말에 "앱이 하지 않는 일은 answer"를 한 줄 더한다.
- 고른 반응: 맞장구 26건은 🙏 11, 👍 12, ✅ 2. 일 218건은 👀 215. 허용 목록 밖 값은 없었다.

## act·domain(ADR-051 A층, 기록만)

| 지표 | chat_route_v1 | 초안 기준선(2026-11-19) |

| 발급 놓침 / 일상 말 잘못 열기 | 0% / 0% | 0% / 0% |
| 문턱 0.8에서 unsure / 확신한 것의 정확도 | 28.8% / 96.8% | 14.4% / 97.1% |
| corrects_previous 정확도 | 99.5% | 99.4% |

- 안전 관문 둘(발급 놓침, 일상 말 잘못 열기)은 그대로 0%다. 떨어진 것은 확신 비율(unsure 14% → 29%)과 act의 other(69%)·smalltalk(85%) 재현율이다.
- 세무 판단 재현율이 떨어져도 반응 쪽은 안전하다: 세무 확률이 0.5 이상이면 반응하지 않고, 세무 질문은 라벨상 answer다.

## 다음

1. 머리말 고치기(사례 먼저): 앱이 하지 않는 일은 answer, 줄임말 맞장구("ㅇㅋ", "ㄳㄳ", "ㄱㅅ")는 reaction_only. 고친 뒤 이 세트로 다시 잰다.
2. ADR-051 3단계 전에 act·domain을 초안 수준(92% 이상)으로 되돌린다. 머리말 상한(2,000토큰)을 이 번들만 넓힐지, 질문 설명으로 옮길지 정한다.
3. 관문 확정: "질문이나 일을 반응만으로 닫음 1% 이하"를 합치는 관문으로 둔다. 👀 비율은 머리말 고친 뒤 다시 보고 정한다.
