## 3. 하지 않은 것(기능 작업)

- 캔버스에 있지만 동작이 필요한 것: 내 차례 패널의 [브라우저 창 보기], 검색(명령 팔레트), [만료 알림 켜기], 설정 변경·보안카드 등록 창, Windows Hello 설정, 온보딩 대화, 새 PC 연결, 모바일.
- 서체 파일 번들: 렌더러에 네트워크가 없어 앱은 대체 서체로 보인다(PoC-9 §7 그대로). 미리보기 스크린샷은 IBM Plex Sans KR을 설치한 리눅스 컨테이너에서 찍었다(라틴 글자 대체 서체가 다를 수 있음).
- 승인 바(`approval-gate.ts` CSS·판정)는 건드리지 않았다.

## 4. 확인

- `pnpm lint` 통과. 셸 문서함 e2e(`shell-docs-e2e`, 리눅스 컨테이너 + xvfb) 41/41 통과(바꾸기 전과 같은 수).
- 단위 시험: 셸·가드(`shell-mock`·`shell-docs`·`guards`) 27/27 통과. 나머지 파일은 리눅스 컨테이너에서 39개 묶음 통과, 7개 묶음 실패였고 실패는 모두 설치된 Chrome·OCR 언어 데이터가 필요한 금고·엔진 시험(`vault: chrome not installed`, 시간 초과)이다. 이번 변경은 그 패키지를 건드리지 않았다. `playwright-relay`·`run-browser`는 Chrome이 없어 돌리지 않았다.
- 셸 e2e(`pnpm demo:e2e`)는 실행 Chrome이 필요해 리눅스 컨테이너에서는 돌리지 않았다. 셀렉터·문구(`data-run`·`data-act`·"초안과 같아요"·"메일로 보낸 것도 확인했어요" 등)는 유지했다. **Windows·macOS에서 한 번 돌려 확인이 필요하다.**
- macOS(2026-11-03, origin/main eda3933 병합 뒤): `pnpm build`·`pnpm lint` 통과, `pnpm test` 279 통과·0 실패(Windows 전용 3건 건너뜀), 셸 e2e(`pnpm demo:e2e`) 52/52, 셸 문서함 e2e(`shell-docs-e2e`) 41/41. 시험이 덮어쓴 `reports/raw/` 파일은 되돌렸다.
- 리뷰 반영: 확인 필요로 끝난 실행이 단계 사이에서 멈췄으면(진행 중 단계 없음) 끝나지 않은 첫 묶음을 "확인 필요"로 표시한다(`runSteps`). 전에는 그 묶음이 "할 일"로 떨어져 멈춘 곳이 안 보였다.
- 캔버스 후속(2026-11-03): 문서함 목록에서 유효 열을 빼고 발급일에 "(n일 전)"을 붙였다. 만료일 확실성(문서·추정·확인함)은 상세 패널 유효 칸에 보이고, 행에는 `data-expiry-tag`로만 남겨 문서함 e2e의 목록 행 4항목이 그것을 읽게 바꿨다. 설정 > 발급 인증은 등록한 인증 목록과 기본 하나로 바꿨다(바꾸기는 목업). macOS에서 `pnpm build`·`lint` 통과, `pnpm test` 279/0(3 건너뜀), 셸 e2e 52/52, 문서함 e2e 41/41. 미리보기는 바뀐 화면(11·12·16)만 맥에서 다시 찍었다(맥 서체).
- PR #23(보안 업그레이드, fa6fba1) 병합 뒤 다시: 설정 메뉴 "폰 연결"을 "기기 연결"로(ADR-020 결정 8). macOS `pnpm build`·`lint` 통과, `pnpm test` 384 통과·0 실패(3 건너뜀), 셸 e2e 61/61, 문서함 e2e 42/42.
- 입력창 위 칩(11-03, 캔버스 M-01 대기·되묻기): 빠른 실행 칩 대신 대기 때 많이 쓴 요청 2개(`data-prompt`, 누르면 바로 보냄, 데모는 빠른 실행 목록의 앞 둘), 되물을 때 채우기 칩(`data-fill`, 최근 금액은 이번 대화 완료 실행·지난 기록에서), 입력창을 누르거나 타이핑하면 칩 숨김, 카드에서 할 일이 있으면 요청 칩 숨김. 셸 e2e의 되묻기 단계는 채우기 칩이 보내지 않는지 확인하도록 바꿨다. macOS `pnpm build`·`lint` 통과, `pnpm test` 384/0(3 건너뜀), 셸 e2e 65/65(검사 3개 추가), 문서함 e2e 42/42. 승인 바 시간 판정 항목(습관 클릭·멈춘 커서)은 연달아 돌리면 가끔 한 항목이 떨어지고 다시 돌리면 통과한다(이번 변경과 무관한 부하 의존).
