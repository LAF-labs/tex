이 맥북에서 데모 셸(`pnpm demo`, fixture 모드)로 H-01 세금계산서 발급과 문서함을 보여 줍니다.

**데이터.** 모든 데이터는 가상입니다. 사업자(가나다컴퍼니 123-45-67891), 거래처 3곳(A상사·B상사·C테크), 메일 주소(`*.example`), 서류 PDF가 모두 그렇습니다.

**발급 대상.** 실제 홈택스가 아니라 가짜 H-01 페이지(127.0.0.1)에서 발급합니다. 정부24는 후처리 안내까지만 보여 줍니다.

**견본 데이터(`pnpm demo`·실행기만, `demo-seed.ts`).** 켤 때마다 데모 DB에 견본을 넣습니다. e2e는 견본 없이 돕니다.

## 0. 이번 데모에서 달라진 것

**채팅 해석**
- `SAX_DEMO_MODEL=openrouter`로 켜고, `poc/.env.local`에 `OPENROUTER_API_KEY`가 있으면 Upstage Solar Pro 4(`upstage/solar-pro4`, OpenRouter 경유)가 문장에서 의도·거래처·금액·부가세·품목을 뽑습니다.
- 모델 ID는 `.env.local`의 `OPENROUTER_MODEL`로 바꿀 수 있습니다.
- 다음 경우에는 그 자리에서 정규식 해석(지금까지의 목업)으로 갑니다.
  - 키가 없을 때
  - 네트워크가 없을 때
  - 4초를 넘길 때
  - HTTP 오류가 날 때
  - 응답이 스키마와 맞지 않을 때
- 송신이 한 번 실패하면 60초 동안은 모델을 건너뜁니다. 와이파이가 끊겨도 문장마다 4초씩 기다리지 않습니다.
- 제목줄 오른쪽 상태 줄(금고 열림 왼쪽)에 `모델 해석`(점 하나) 또는 `오프라인 해석`이 작게 보입니다. 답이 0.3초를 넘기면 대화에 "요청을 읽고 있어요…"가 뜨고, 그동안 보낸 새 문장은 입력창에 남습니다.
- 되묻기·초안 카드·승인 바·발급 흐름은 두 해석이 같습니다. 모델은 구조만 뽑고, 카드와 게이트는 지금 코드가 만듭니다.
- 모델 값을 다 받지는 않습니다. 정규식 값과 합쳐 씁니다(`mergeParsed`). 정규식이 알아본 것이 먼저입니다.
  - 의도: 정규식이 알아보면 그 값입니다. "부가세 신고도 해 줘"의 거절은 모델과 상관없이 나옵니다. 모델 의도는 정규식이 모를 때만 씁니다("발행해 줘", 되묻기 답).
  - 거래처는 문장에 이름 그대로 나온 것만 씁니다. 숫자로 쓴 금액은 정규식 값을 씁니다. 숫자가 있는데 정규식이 금액으로 보지 않으면("330", "1억 2천") 되묻습니다.
  - 모델 금액은 문장에 한글 금액("오백오십만")이 있을 때만 씁니다. 모델 부가세는 문장에 부가세·포함·별도라는 말이 있을 때만 씁니다.
  - 모델 품목은 문장에 그대로 있고, 금액·거래처·계산서·메일이 아닐 때만 씁니다. 그 밖에는 거래처의 지난 품목입니다.
- 실측(11-03, solar-pro4, 공급사 Upstage): 응답 0.6~1.2초. 시연 7번 문장 → B상사, 공급가 5,000,000 + 세액 500,000, 품목 "유지보수비".

**실행기**: `~/Applications/소버린 AX 데모.app`(아래 §3).

**시연 서류**: `pnpm demo:pdfs`로 만듭니다. 오늘 기준 날짜의 가상 PDF 3장이 `~/Desktop/소버린AX-시연서류/`에 생깁니다.

## 2. 리허설 점검표

### 전날(네트워크가 있을 때)
- [ ] 의존성: `cd poc && pnpm install`을 실행합니다. Electron 바이너리가 처음이면 내려받습니다.
- [ ] 빌드·시험: `pnpm build && pnpm lint && pnpm test`를 돌립니다.
- [ ] 키: `poc/.env.local`에 `OPENROUTER_API_KEY=...`를 사용자가 직접 넣습니다. 이 파일은 gitignore 대상이라 커밋되지 않습니다.
- [ ] 실행기: `bash poc/scripts/demo-launcher/install.sh`로 `~/Applications/소버린 AX 데모.app`을 만들고 Dock에 끌어다 놓습니다.
  - 더블클릭해서 "문서 폴더 접근"을 묻으면 허용합니다.
  - 창이 앞으로 오는지 봅니다.
- [ ] 시연 서류: `pnpm demo:pdfs`(미팅 당일 아침에 다시 만들면 D-n이 대본과 맞습니다). 앱 안 문서함의 견본은 켤 때마다 오늘 기준으로 새로 만듭니다.
- [ ] 거래처 추가용 견본 번호: `107-13-50193`·`107-14-29381`·`107-15-08573`(체크섬만 맞는 합성 값, 켤 때마다 DB가 비므로 다시 써도 됩니다).
- [ ] 키를 넣고 실행기를 더블클릭한 뒤 대본 1~13을 한 번 끝까지 돕니다. 구석 표시가 `모델 해석`인지 봅니다.
- [ ] 와이파이를 끄고 같은 대본을 돕니다. 구석 표시는 2번 문장 뒤에 `오프라인 해석`으로 바뀌어야 합니다(키가 있으면 첫 문장에서 최대 4초 기다림). 7번에서 되묻기가 나와야 합니다.

### 당일 시작 전 5분
- [ ] 전원 어댑터를 꽂고, 방해 금지 모드를 켜고, 화면 밝기를 최대로 합니다.
- [ ] Chrome이 설치돼 있는지 확인합니다. 실행 Chrome은 앱이 따로 띄우므로 사용자 Chrome은 닫아도 됩니다.
- [ ] 실행기로 한 번 켜서 창을 띄워 둡니다(첫 빌드를 미리 합니다).
- [ ] 회의실 네트워크가 불안하면 와이파이를 끄고 오프라인으로 시연합니다. 대본 7번은 되묻기로 말합니다.
  - 켠 직후의 표시는 키 기준입니다. 실제 경로는 첫 문장을 보낸 뒤 표시를 봅니다.
  - 미리 한 문장(예: "안녕")을 보내 두면 표시가 실제 상태로 맞춰집니다.
- [ ] `~/Desktop/소버린AX-시연서류/` 파일 3개가 있는지 확인합니다.

### 막혔을 때
- **창이 안 뜸**: `~/Library/Logs/sax-demo.log` 끝을 보고 터미널에서 `cd poc && pnpm demo:model`을 실행합니다.
- **이미 떠 있음**: 실행기를 다시 누르면 빌드가 몇 초 돈 뒤 기존 창이 앞으로 옵니다. 첫 빌드 중에 또 눌러도 빌드는 하나씩만 돕니다.
- **처음부터 다시**: 창을 닫고(앱 종료) 다시 켭니다. DB·원장이 비어서 시작합니다.
- **모델 응답이 느림**: 4초 뒤 저절로 오프라인 해석으로 갑니다. 그 뒤 60초는 모델을 건너뜁니다.
- **같은 건 두 번 발급**: 승인 바가 주의 색 "그래도 한 번 더 발급"으로 바뀝니다. 중복 방지 기능이라고 설명할 수 있습니다.

## 3. 맥 실행기

- **만들기**: `bash poc/scripts/demo-launcher/install.sh [폴더]`를 실행합니다. 폴더를 주지 않으면 `~/Applications`에 만듭니다.
- **앱 구성**: `osacompile`로 만든 AppleScript 애플릿에 로컬 임시 서명(`codesign -s -`)을 붙였습니다. 인증서 서명·공증·정식 패키징이 아닙니다.
  - 셸 스크립트만 든 `.app`은 쓰지 않습니다. 레포가 `~/Documents` 아래라서, Finder에서 띄우면 macOS(TCC)가 묻지도 않고 읽기를 막습니다(`Operation not permitted`, 11-03 확인).
  - 애플릿은 처음 켤 때 "문서 폴더 접근"을 묻습니다. **허용**을 눌러야 합니다. 실행기를 다시 만들면 다시 묻습니다.
  - 애플릿은 `run-demo.sh`를 뒤에서 띄우고 바로 끝납니다.
- **경로가 박힘**: 만든 체크아웃의 `scripts/demo-launcher/run-demo.sh` 경로가 앱 안에 들어갑니다.
  - 머지 전에는 데모 워크트리에서 만듭니다. 머지하고 워크트리를 정리한 뒤에는 메인 체크아웃(`~/Documents/tex/poc`)에서 다시 만듭니다.
  - 스크립트가 없어지면 실행기가 "실행 스크립트가 없어요"라는 대화상자를 띄웁니다.
- **키 파일 위치**: `.env.local`은 실행하는 체크아웃의 `poc/`에서 읽습니다. 워크트리에서는 메인 체크아웃 파일을 가리키는 링크(`poc/.env.local` → `~/Documents/tex/poc/.env.local`)를 둡니다.
- **실행 순서** (`run-demo.sh`)
  1. 로그인 셸 PATH로 pnpm을 찾습니다.
  2. `node_modules`나 Electron이 없으면 `pnpm install --frozen-lockfile`을 한 번 실행합니다.
  3. `SAX_DEMO_MODEL=openrouter pnpm demo`를 띄웁니다.
  4. 출력은 `~/Library/Logs/sax-demo.log`에 쌓입니다. 비정상으로 끝나면 대화상자를 띄웁니다.
- **키**: 실행기는 키를 읽지 않습니다.
- **지우기**: `~/Applications/소버린 AX 데모.app`을 휴지통으로 옮기고, 로그 파일도 지웁니다.

## 4. 설계 예외(데모 모드 한정)

원래 설계(D04)에서는 클라이언트가 공급사 키를 갖지 않고 게이트웨이를 거칩니다. 이번 시연은 다음 범위 안에서만 예외를 둡니다.

| 항목 | 이번 예외 | 가둔 방법 |
|---|---|---|
| 공급사 직결 | main 프로세스가 OpenRouter `https://openrouter.ai/api/v1/chat/completions`를 직접 부릅니다. | `@sax/net` `DEMO_DESTINATIONS`는 `Egress({ demoModel: true })`에서만 열립니다. 경로는 이 하나뿐이고, `redirect: 'error'`이며, TLS 변조 변수 검사도 그대로 거칩니다. 앱은 `SAX_DEMO_MODEL=openrouter`이고 **fixture 모드**일 때만 이 Egress를 만듭니다. `--portal=hometax`에서는 넘겨받아도 쓰지 않습니다(`shell-app.ts`). |
| 키 보관 | `OPENROUTER_API_KEY`를 main 메모리에 둡니다. | 키는 환경 변수가 먼저이고, 없으면 `poc/.env.local`에서 그 이름만 읽습니다. 셸로 실행하지 않습니다. 읽은 즉시 `process.env`에서 지워서 금고가 띄우는 Chrome과 자식에 남기지 않습니다(자식 env 허용 목록도 원래 막습니다). 렌더러·로그·보고서·저널에는 키도, 키 길이도 남기지 않습니다. 로그에는 `main.interpret {via, ms}`만 남습니다. |
| 보내는 내용 | 채팅 문장 원문과 가상 거래처 이름 목록 | 마스킹(@sax/redaction)을 거치지 않습니다. 비밀·인증서·화면 값·사업자번호 목록은 보내지 않습니다. 시연 문장은 모두 가상입니다. |
| 모델 출력 신뢰 | 비신뢰로 다룹니다. | JSON 스키마(strict)로 요청하고 손으로 다시 검증합니다. 의도는 6종 중 하나, 거래처는 목록에 있는 이름만, 금액은 1원~1조원 정수, 품목은 40자 이하 한 줄만 받습니다. 하나라도 틀리면 정규식으로 갑니다. 초안은 사람이 카드에서 보고, 발급은 승인 바 클릭으로만 일어납니다. |

**Phase 1에서 할 일**: 게이트웨이(D04 §8 BYOK 검사 4종·서버 키)로 옮기고 이 예외를 지웁니다.
