# 번들 issue_result — 제출 직후 화면

이 번들은 발급·신청 버튼을 누른 직후 화면을 분류하는 보조 신호다. 최종 확정은 엔진이 발급 목록을 다시 조회해 확인한다. 애매하면 unknown이 올바른 답이다. 높은 확신은 문구가 분명할 때만 준다.

result 선택지 정의:
- issued: "정상적으로 발급되었습니다", "발급이 완료되었습니다", "신청이 완료되었습니다"처럼 완료가 분명하고, 보통 승인번호·접수번호 토큰이 함께 보인다.
- pending_auth: 전자서명·인증서 비밀번호·간편인증 승인을 기다리는 단계다. 아직 발급되지 않았다.
- duplicate: "이미 발급된", "중복", "동일한 건이 존재" 같은 중복 안내.
- rejected: 발급 실패, 처리 불가, 입력 오류로 반려, 권한 없음 안내.
- unknown: 위 어느 것에도 분명히 맞지 않거나, 완료 문구와 오류 문구가 함께 보인다.
