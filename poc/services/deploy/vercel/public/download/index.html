소버린 AX 내려받기

Mac 한 대에 설치하면 대화 한 줄로 홈택스 전자세금계산서를 발급할 수 있습니다.

Mac용 내려받기

파일 하나에 Apple 칩과 Intel용이 같이 들어 있습니다. Windows용은 준비 중입니다.

준비할 것

  • macOS 13(Ventura) 이상Apple 칩(M1~M4)과 Intel Mac 모두 됩니다.
  • Google Chrome앱이 홈택스 일을 할 때 씁니다. 응용 프로그램 폴더에 설치해 둡니다.
  • 사업자범용 또는 전자세금계산서용 공동인증서개인용·은행용 인증서로는 세금계산서가 발급되지 않습니다.
  • 본인 이메일로그인 코드가 이 주소로 옵니다. 계정 하나는 Mac 한 대에 연결됩니다.

설치 3단계

  1. 받은 SovereignAX-…-universal.dmg를 두 번 누르고, SovereignAX를 옆의 Applications 폴더로 끌어 놓습니다.
  2. Finder 왼쪽에서 디스크 옆 꺼내기(⏏)를 누릅니다.
  3. 응용 프로그램에서 SovereignAX를 엽니다. "인터넷에서 다운로드한 앱입니다" 창이 뜨면 [열기]를 누릅니다.

새 판은 앱이 알아서 받아 다음 실행 때 바뀝니다. 다시 설치하지 않아도 됩니다.

첫 실행

  1. 약관과 AI 모델 안내를 읽고 [동의]를 누릅니다.
  2. 이메일을 넣고, 메일로 온 6자리 코드를 넣습니다.
  3. 상호와 사업자번호를 넣습니다.
  4. 이 Mac에서 찾은 공동인증서 가운데 하나를 고릅니다.
  5. 첫 발급 때 금고 창에 인증서 비밀번호를 한 번 넣습니다. 그다음부터는 앱이 기억합니다.

인증서를 다른 PC에서 옮기는 방법, 홈택스 보안 프로그램 설치, 막힐 때 할 일은 자세한 설치 안내에 있습니다.

소버린 AX · 라프(LAF) 라프가 만든 민간 앱입니다. 국세청과 관계가 없습니다.
